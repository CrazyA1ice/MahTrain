# MahTrain

四川麻将（川麻）牌效训练与人机对战项目。

> 当前阶段：基础判胡/牌效、四种单题、14轮单人训练、SQLite错题本已实现。**M3.1 新增真实四人碰杠胡响应规则子集**：一炮多响、胡＞杠＞碰、明暗补杠、抢杠胡、尾部补牌和已胡退出。正式番数支付、流局查牌和三名策略AI仍未实现。

## 项目方向

- **普通牌效训练**：一向听何切、听牌何切、14 轮独立摸切训练。
- **清一色训练**：13 张手牌听牌集合选择、14 张手牌最优何切或已和牌判断。
- **可解释牌效**：向听数、有效进张（牌种与剩余枚数）、概率及“局部最优切”：首版坚持不退向听，允许多个并列最优答案；退向听换更高收益暂缓。
- **人机对战**：1 人对 3 AI，多种难度、多局积分结算。
- **可配置玩法**：通过规则预设管理川麻的定缺、换三张、胡牌、续局和算分细则。

## 已实现的 Python 训练原型

- **统一理牌与高清牌面**：`src/mahtrain_core/presentation.py` 将同花色集中，固定 **万→条→筒**，组内按 **1→9升序**，重复牌相邻；排序不改变实际牌效、手牌张数或随机牌墙。
- **胡牌及部分计番**：`src/mahtrain_core/rules.py`，涵盖定缺、七对、金钩钓、天听（碰取消、杠不自动取消）等已验证子集。
- **牌效计算**：`src/mahtrain_core/efficiency.py`，向听数、有效进张、余张、下一摸概率与局部最优切。
- **四类单题训练**：`src/mahtrain_core/training.py`，固定种子出题、答案校验、提交后解析；`examples/training_quiz.py` 可交互体验。
- **连续14轮摸切训练**：`src/mahtrain_core/session.py`；独立108张实体牌墙、逐轮摸切、实时理牌、判题解释、正确率/进张损失/退向听次数。命令行入口 `examples/solo_14_rounds.py`。

### 本地可点击网页（四种单题 + 连续14轮）

```bash
git pull origin main
python web_server.py
```

浏览器打开 **http://127.0.0.1:8765**。 页面顶部新增**单题训练中心**，可选择「一向听何切／听牌何切／清一色选听口／清一色何切」及**基础、进阶、挑战**三档结构难度，点击原始牌面答题，提交后才公布正确答案。进阶与挑战题增加顺子、两面/边张/嵌张听口、双搭子和七对竞争；所有题目由既有牌效/胡牌算法验证。

当前默认采用仓库原有的[完整麻将牌面图](assets/tiles/640x420.jpeg)（第一行筒1–9、第二行万1–9、第三行条1–9）进行切片显示，单张按钮约**74×97**，图案铺满牌框，不再使用上轮的矢量重绘。

**单人14轮开局顺序**：输入种子 → 点击「先发牌·看13张手牌」 → 看清手牌后选择定缺花色 → 点击「确认定缺·开始训练」。如手中只有两门牌，会提示**天缺**并预选未持有的花色，仍需自行确认。单人训练仍不模拟换三张。**独立的四人开局演示**则已经支持先看牌、四家换三张后同时定缺。

网页可开启/关闭摸牌、切牌、杠牌及胡牌音效；合法胡牌自动弹窗，未打光定缺牌会提示剩余数量。原始牌面在牌框内居中。每轮提交后，网页下方更新切牌复盘、向听/有效进张/下一摸概率走势、当轮最优动作和具体解析，支持筛选并导出 CSV。

**错题重练与跨重启历史（v0.7）**：14轮结束（或提前合法胡牌）后，可点击答错回合重新作答并比较首次/重练切牌的牌效。每次**已结束**训练会自动写入本机 SQLite `data/mahtrain_history.sqlite3`。页面下方新增“本地历史训练与错题本”，可查看旧训练、累计正确率和阶段进步，再次重练旧错题，必要时删除单局记录。数据库文件受 `.gitignore` 保护，不会被 Git 正常跟踪。**进行中的局面暂不能断点续练**；没有多账户或云同步。详见[SQLite 历史 v0.7](docs/SOLO_TRAINING_V0.7.md)。

### M3.1：四人碰杠胡响应试验（非完整计分对战）

本地网页现在另有 **“四人血战 · 碰杠胡响应试验（M3.1）”**。在此可以操作0号座位，发牌并换三张后定缺；别人出牌时有胡、明杠、碰资格会提示你确认或“过”，轮到自己时可自摸、暗杠或补杠，副露锁定在独立区，杠牌从尾部补牌。多家合法点炮胡会记录为一炮多响，已胡者退出后续摸切；三家已胡时终止摸打。原始麻将牌面、万条筒1→9排序继续沿用。

**当前另外三家是遵循合法动作的固定脚本，不是真正AI。** M3.1 暂不计算番数、杠钱、抢杠收益、流局查花猪/查大叫，也未完成天听资格的整局历史核验。请不要把它当作已具备结算能力的正式血战产品。完整细节见[四人响应规则 v0.13](docs/FOUR_PLAYER_CLAIMS_V0.13.md)。

### M3：四人血战开局演示（非完整对战）

本地网页中的 **“四人血战 · 开局规则演示（M3预览）”** 使用同一套原始麻将牌面图。你操作0号座位，先看自己发到的13/14张牌，然后选择**3张同一门花色**换出；另外三家由固定脚本密封选牌。四家全部选齐后才真正交换，换后看牌并选择定缺，四家全部提交才揭示。之后可体验庄家先打、按座位轮流摸切的基础演示。

**注意**：其他三家不是策略 AI。演示中的碰/杠/胡响应被显式标记为**未实现、仅演示过牌**；未接入正式计番、点炮胡、多响、杠钱、血战赢家退出及查花猪/查大叫。此模式的种子在本机可复现，不能视作安全保密的对战随机协议。

无需启动网页也可以检查：


### 运行连续训练

```bash
# 在仓库根目录执行，默认14轮，手动出牌
python examples/solo_14_rounds.py --seed 17

# 自动选择最优切，观看完整训练与报告（若合法胡牌可提前结束）
python examples/solo_14_rounds.py --seed 17 --auto

# 简短体验两轮，指定定缺筒
python examples/solo_14_rounds.py --seed 17 --rounds 2 --missing-suit p
```

输入示例：`m9` = 9万、`s8` = 8条、`p7` = 7筒；胡牌由系统自动询问确认，不需自己输入 `win`。显示示例：`万[3 7 9 9] | 条[5 8] | 筒[1 3 9]`。

其他独立单题：

```bash
python examples/training_quiz.py --mode one_shanten --seed 9
python examples/training_quiz.py --mode tenpai_discard --seed 42
python examples/training_quiz.py --mode pure_suit_waits --seed 42
python examples/training_quiz.py --mode pure_suit_discard --seed 0
```

本地验证：

```bash
python -m unittest discover -s tests -v
```

**M2.7 新增：单题长期成绩与建议难度。** 单题首次提交答案后，立即把真实题目、所选动作与评分结果写入本机 SQLite；单题中心下方显示三档累计答题数/正确率、当前模式与难度的最近10题表现，至少完成5题再给升降档建议：≥80% 推荐上调、≤40% 推荐下调，否则保持。不同训练模式、难度互不混算，用户可通过按钮自行采纳，不会自动切换。近期单题列表可查看原题及解析，错误回合支持跨重启再次答题；重练不计入首次正确率。数据库从 v1 增量升级到 v2，之前14轮记录保持不变。详见[单题历史与建议 v0.9](docs/QUIZ_PROGRESS_V0.9.md)。

> **v0.8 历史阶段说明**：单题网页已接入，但单题答题历史尚未写入 SQLite；三档难度是结构类型区分，并非基于用户表现自动调整的自适应难度。正式四人血战与三档 AI 尚未实现。

**M2.8 新增：按错因强化单题。** 单题答错时根据真实评分数据识别退向听、同向听少进张、错过胡牌、误判胡牌、漏选或误选听口。单题中心下方展示该模式**最近最多30道首次错题**的各类频次，可点击“专项练习”；也可启用约75%优先出薄弱项题、约25%插入普通题的强化策略。只将通过算法验证存在对应易错决策的题称为专项，未找到则明示普通穿插题。原始牌面、14轮连续训练、SQLite成绩与手动推荐难度均保留。详见[错因分析与强化 v0.10](docs/ERROR_FOCUS_V0.10.md)。

**M2.9 新增：14轮整局错因报告。** 完成切牌后，页面底部逐轮复盘会列出当轮错因，并汇总整局的错过合法胡牌、退向听和同向听少进张次数，指出最常见的问题。点击相应弱项可跳到单题训练中心进行针对性练习；历史训练详情也会显示错因，旧 SQLite 记录只在读取时补充分类，不会改写原成绩。逐轮 CSV 新增错因列。具体见[连续14轮错因报告 v0.11](docs/SOLO_ERROR_REVIEW_V0.11.md)。

> **当前 v0.11 边界**：14轮错因只按当轮真实最佳动作与实际选择判定，不会用跨轮进张变化代替错误诊断；与单题专项共享类别但不混合统计。四人正式对战、完整算分和 AI 尚未实现。
