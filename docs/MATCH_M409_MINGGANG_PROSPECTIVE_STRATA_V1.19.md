# M4.09：碰／明杠自然选择的前瞻危险度分组与真实点炮结果（v1.19）

## 上一轮验收与新问题

M4.08 已经完成 [PR #108](https://github.com/CrazyA1ice/MahTrain/pull/108) 的专项和全量规则测试并合入主分支。真实自然测试：开发组 40000–40003 四座位共16局，合法碰／明杠双选项5次，挑战级实际明杠4次，其中1次杠后弃牌被胡而按账冲销；保留组 41000–41003 共16局，双选项2次，挑战级明杠2次，没有杠后弃牌被胡。上述频数不构成概率估计或新策略优势证据。

M4.07 只观测了公开危险指数，M4.08 只核对了实际明杠钱、点炮和权威账本。M4.09 的小切口是把**合法回应窗口出现时、AI 尚不知道补牌**的公开危险指数，和**牌局结束后**真实获杠、真实杠后弃牌、实际点炮／冲销的权威证据对应，而不把未发生的行动假想成实际损失。

## 预注册设计

- 固定公开危险指数分组为低 `[0, 0.25)`、中 `[0.25,0.5)`、高 `[0.5,+∞)`。该指数汇总至多三名活跃对手的启发式危险度，**总值可能大于1**，不得将其解释为0～1之间的点炮概率。该指数只是既有手牌弃牌种类在公开局势下的启发式读牌值，**不是点炮概率**；完全不知道尾墙摸到哪张牌，不能作为全可能补牌出口的严格风险边界。
- 在 `MingGangFollowThroughAgent.response` 阶段以自身授权视图记录公开弃牌索引、原先 `pass/peng/ming_gang` 决策与固定危险度分组。沿用原 `MahjongAgent("challenge")` 方法，不重写行动选择。
- 仅在整局结束以后由 `public_events` 的真实先后关系，以公开 `discard.index` 关联实际 `ming_gang` 事件，再由 `KongLedger` 唯一编号关联杠后弃牌及 `won_by`。
- 必须先通过 M4.08 的全事件逐笔杠钱核验，保证杠被胡时冲销金额、身份与多人胡牌的一次性撤销完全成立。输出只有行动前分组与行动后真实事件的**聚合频数和官方净分**，不输出出牌种类、对手暗手、补牌尾摸、牌墙、可反推身份摘要。
- 统计分母分层明确：`offer` 是合法可选窗口，`selected` 是原AI选择杠，`awarded` 是仲裁后真正获杠，`after_kong_discard` 是发生了实际杠后弃牌，`actual_ron` 是这些弃牌确实被胡，`awarded_final_cash` 是真实账面杠钱。被其他人抢先胡牌或杠的选择不计成已实现的风险敞口。

## 样本与报告

新开发组 **42000–42007**、独立保留组 **43000–43007**。每个初始洗牌种子四个坐席轮换：**每组32局，共64局完整108牌自然对局，16个独立洗牌种子**。本轮用单臂原始挑战级 AI 而不是重复两臂（之前验证过旁观者不影响动作）：可以在同等运行成本下增大自然样本覆盖。

`src/mahtrain_core/ai_minggang_prospective_strata.py` 负责权威因果时间顺序连接与聚合分组；`tests/test_m409_minggang_prospective_strata.py` 验证边界分箱、明杠实际奖励／冲销、多家同时胡只退杠钱一次、原行动被抢先与非杠回应的禁止误归因、实际108牌授权视图、32局报告结构；`examples/audit_minggang_prospective_strata.py` 保存真实JSON；CI运行新8/8独立种子并归档结果。

复现：

```bash
python -m unittest discover -s tests -p 'test_m409_minggang_prospective_strata.py' -v
python examples/audit_minggang_prospective_strata.py --cohort development --seeds 8 --output results/m409-development.json
python examples/audit_minggang_prospective_strata.py --cohort holdout --seeds 8 --output results/m409-holdout.json
```

## 不可越过的解释边界

**只观察到原AI自己愿意明杠的样本，未选择明杠者没有真实杠后点炮的结果。** 因此高中低风险分组下的自然 `actual_ron` 频数受到AI选择、存活、牌权仲裁、补牌种类和对手响应等因素共同影响，不等同于将所有合法窗口统一强制明杠后会发生的点炮率。没有无偏因果效应、置信区间或点炮概率校准，更不据此直接上线风险惩罚系数。

四坐席轮换属于同一个洗牌种子内的相关重复，不将64局误算成64个独立样本。关键是独立种子数和有实际明杠的**独立种子数**，而不是仅比较窗口的原始比值。

这轮不改变正式AI、人机对战页面、胡／碰／杠仲裁、108张牌及原始权威积分算法。CI完成前不宣称自然实验已通过。
