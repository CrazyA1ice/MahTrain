# M3.88 · 中央计分板内收、多周期完整历史与终局四家复盘

## 本轮范围

1. 经典 2D 固定黑色计分板：中央场次、庄家、余牌、四家净积分等所有文本强制限制在原始黑色看板内，超宽省略，不推动任何牌河或手牌。
2. 所有历史统计周期统一：全部、过去7天、过去30天、过去365天。**SQLite 服务端**使用 UTC 已完成对局时间筛选；积分曲线不再只返回最后 30 局，四座累计、场均、正负局数、按AI难度／底分分组同时依据同一周期计算。单次历史列表最多显示 5000 条；若超过这个限制会明确说明列表是截取，并不会谎称全量。累计图数值仍统计所选周期全部已保存有效对局；剔除不一致老账本显示数目。
3. 已完成对局的逐步复盘：旧版本只存公开历史，**不可能从旧牌河准确重建当时四家暗手**；新版本从真实规则引擎分别保存四家开局暗手、每个公开规则动作前后四家真实持牌。隐牌只在服务端保存，**到终局已正式结束**才进入 SQLite 归档的 `terminal_review` 并允许历史查看。对局进行中的 `private_view(0)`、`public_state()`、`public_steps` 与即时对手 AI 观察仍不含任何对手暗手。
4. 玩家每次实际出牌：取出牌动作前的**本人合法私有手牌 + 当时公开牌**，调用现有 `classic_hand_hint` 排序，并且只把当时允许合法选择的前三切、最优参考集合及玩家实际切牌名次留在终局归档。参考准则：定缺合法性 → 最小向听 → 未知有效张副本数 → 听牌时按规则番型加权。**没有使用未来牌墙或对手隐藏牌来生成建议**。总符合率 = 参考排序第一（含并列第一）的实际切牌巡数 / 成功评估的有效切牌巡数；不等价于胜率、分数EV、对手防守最优或完美信息最优。

## 真实数据与复盘历史边界

- 原数据库 `completed_matches` 表结构不变，终局 JSON 的 `version=2` 带有 `terminal_review.scope="terminal_replay_only"`。版本 1 仍维持原 `privacy=public_board_only` 且不添加猜测暗手。用户点击老牌局时会被告知其缺少此数据。
- 每个终局规则动作同时保留 `hands_before` 与 `hands_after` 四张牌阵（四位玩家），最多 2048 步；每张牌逐一经过 `^[mps][1-9]$` 白名单，不存任何未来墙、seed、对局令牌、AI 内部预测或私有合法操作列表。历史最多 2048 步的保护限制保持不变。
- 复盘视图只读取不可操作的历史 JSON，展示每巡四家真实手牌、已公开副露和牌河，不向用户提供历史回放作弊式的出牌或重启私有未来墙能力。
- 对算法无法解析的历史切牌，不伪造前三选项，也不会让可选的牌效评估失败阻断已正式执行的出牌；整局符合率的分母只包含实际有可核验候选的切牌巡次。
- 现阶段的赛后复盘推荐只对**0号真人座位**提供前三名及符合率；另外三家手牌是全部公开的，AI 各家自己的每巡前三候选评分与符合率尚未附加。需要时可根据同样的己方私有 + 当时公开信息协议拓展多座牌效评估，但不能用赛后四家全可见信息反向打分。

## 说明

统计只表示本地 SQLite 所保存的对局，不表示跨设备或被删除的历史。全周期累计曲线重新从该周期第一局的零基线累计；无法纳入的损坏历史从合法统计中剔除并显示数量。由于用户现在才要求保存真实暗手，旧的公开档案绝不可被当成完整赛后复盘。新的逐巡评分方法是具有明确公开信息边界的**牌效参考**，不是已经在真实对局中证明的全局期望收益最优。
