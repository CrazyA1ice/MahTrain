# M4.32：自然自对战的多决策点采集、双世界一致性与洗牌种子簇学习（v1.42）

## 目标和与上一轮的区别

M4.31 建立了“四名挑战级AI自然完赛→真实同向听合法切牌二选一→两个合法未来墙顺序内各打到终局→读取官方真实积分差”的基础。首次实际样本只有**2个自然决策点、1个训练动作、1个留出动作；留出方向匹配0/1**。因此软件链路可运行，但模型没有验证出更强的动作选择能力。

M4.32 **不修改原M4.31历史实验、不修改在线挑战级AI**，新增一个可复验的**多决策点**实验：在每一个原生随机洗牌种子产生的真实四挑战级对局里，按照对局时间顺序从**不同座位**分别记录最多2个符合条件的合法二选一动作点。每个点只允许玩家本人的合法授权 `private_view(seat)` 作为学习特征，研究者在进程内对**实体108张不变**的官方状态克隆，用相同的两个真实合法切牌动作和相同的未来墙排列打到牌局结束，对比权威净分。

## 实施规则

1. **自然采集**：每局4名 `MahjongAgent("challenge")` 继续依照正式 `FourPlayerOpening` 的换三张、定缺、碰杠胡、尾摸/抢杠及真实结算规则完整自然对战。只有真实轮到本家出牌、自己当前不能直接自摸且现有挑战级AI不先补杠、存在至少2种不增加最小向听数的合法弃牌，才可创建对照样本。每局最多2个且两个不能来自同一玩家座位。采集按自然时间先后，**不是所有自然牌局决策点的随机抽样**，不能据此估算机会总体频率。
2. **配对的完整真实结算**：对于每个合法决策点，冻结当时的整副实体牌局用于离线实验。比较“正式挑战级选牌”与“另一种同向听合法切牌”在原未来墙顺序及另一个独立重排的合法尾墙序列的完整终局结果。每个决策点恰好 `2种墙×2个动作=4局`，从权威计分器读取本家胡牌积分、杠钱、流局查花猪/查大叫和总净分，所有座位官方净分严格零和。
3. **标签的严格同号筛选**：若两个预设未来墙世界中，“替换动作−原动作”的实际终局净分均严格大于0，标为 `alternative_better_in_all_test_worlds`；两者都严格小于0标为 `original_better_in_all_test_worlds`；其余包含零差、相互矛盾的场景一律保留在完整训练记录供研究，但**不参与本轮受限训练**。因为这只测试了两种条件化未来墙，不代表真实未知世界总体期望，**两个世界同号也不是因果确定或动作Q值真值**。
4. **种子簇权重校正**：一个原始自然洗牌种子是一个独立统计单位。即使它产生2个不同座位的动作点、每点4场终局分支，它仍然只占**一个相关样本簇**，不能当成8个独立自然牌局。训练会先对同一自然种子内通过标签守门的动作级特征差与裁定回报做平均，再对彼此独立的训练种子簇平均，权重幅度严格限制在0.2以内，并且永远不自动部署。
5. **完全隔离的留出检验**：留出种子不能与训练种子重叠。冻结训练权重之后，再读取新的自然洗牌簇，在符合双墙同号的留出动作上统计预测方向一致数量；不通过、无法决断、标签不一致都需透明报告。不统计虚假的小样本显著性、总体动作胜率或净分EV，不因为结果负面而丢掉样本。
6. **防泄漏**：只从 `public_replay_frame` 输出对外公开牌谱，递归检查禁止包含自己的/对手的隐藏手牌字段、未来墙或种子。训练和留出私有样本仅保存参与动作本家的历史自家手牌和当时公开信息、两个动作的终局分账标签。包含全部真实暗手和墙牌的游戏对象**仅在进程内存**，从不导出。仓库已有 `data/selfplay/` Git 忽略规则，CI**仅上传脱敏总量统计JSON**。

## 复现和生成文件

从仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe examples\run_selfplay_multicheckpoint.py --seed-start 89600 --train-seeds 1 --holdout-seeds 1 --max-checkpoints 2 --out-dir data/selfplay/m432
```

运行结果在本机 `data/selfplay/m432` 中：

| 文件 | 用途 | 数据安全 |
|---|---|---|
| `public_challenge_replays.jsonl.gz` | 四挑战AI所有公开行动与公开牌局快照 | 无洗牌种子/他人暗手/未来墙 |
| `PRIVATE_train_action_labels.jsonl.gz` | 训练种子下本家合法决策、不同动作的双世界终局分账 | **本地私有** |
| `PRIVATE_holdout_action_labels.jsonl.gz` | 留出种子下相同结构的独立验证 | **本地私有** |
| `offline_consensus_model.json` | 严格双世界同号筛选、以原洗牌种子为簇单位拟合的受限权重 | **离线实验** |
| `PRIVATE_holdout_diagnostics.json` | 留出每个动作预测与真实条件化比较 | **本地私有** |
| `summary.json` | 独立洗牌簇数、捕获动作数、双世界一致标签、真实完赛分支数、留出方向匹配与缺失 | CI仅发布其中无隐私统计项 |

CI 实验选用1个训练、1个留出自然随机洗牌种子，以及每局最多2个不同座位合法决策点。总自然游戏2局，每个自然局面至多额外2×4=8局完整反事实终局对照，最多18场完整真实游戏。系统必须如实记录少于该上限的自然选择覆盖率，**不容许补造人工“自然”决策点**。

## 研究价值和下一步

M4.32 主要修正两项方法学薄弱环节：单局只能产生1个动作对照标签，以及多个同种子的动作/世界被误算为相互独立。它并没有直接解决“四挑战AI是否已经强于以前”的问题。只有当后续**增加独立自然洗牌数、扩展可合法观察条件下的更多隐藏世界和更多实际候选动作、验证不同对手与番型的策略泛化性**后，才能尝试将一个冻结的学习模型作为新的 AI 候选，与旧挑战AI独立、四座位均衡、真实完整终局较量。

本轮不更改计分规则、正式AI切牌、碰杠胡、用户牌桌/复盘功能，也不会虚报AI已增强。

## 首轮真实 CI 实验结果（2026-10-25）

[首次 M4.32 专项运行](https://github.com/CrazyA1ice/MahTrain/actions/runs/40159285992) 的 Python 3.11/3.13 专项测试及端到端运行**全部通过**，全部结果为真实引擎完赛及官方账本，并非编造或预测。

本轮使用 **1个训练自然洗牌种子89600、1个不重叠的留出自然洗牌种子89601**，四人均为挑战级AI。每自然种子按实际对局顺序最多选择2个不同玩家座位的合法双切牌决策点，每个点2种未来墙序×2个首步出牌动作，模拟至三家胡牌或流局正式结算。

| 真实实验指标 | 观测结果 |
|---|---:|
| 独立自然起手牌及四挑战AI完整对战 | **2局** |
| 自然发现的不同座位合法双候选决策点 | **4个** |
| 每点条件化物理墙内比较的真实后续终局对局 | 4场 |
| 配对真实完整终局分支 | **16场** |
| 原始自然局+反事实分支总完整对局 | **18场** |
| 两个未来墙下终局净分差严格同正/同负的决策点 | **1个** |
| 训练集合法且双世界严格同号的动作标签 | **1条** |
| 有训练标签的独立自然洗牌种子簇 | **1个** |
| 留出种子的自然双候选决策点 | **2个** |
| 留出种子中符合严格同号筛选的标签 | **0条** |
| 留出模型实际可评估的决策点 | **0个** |
| 留出方向预测正确数 | **0个（分母为0，不能计算正确率）** |

这组实测说明“**从自然对局多点采样**”和“**同一原始洗牌种子内保留相关性**”两项工程目标已实现。与此同时，采用更严格的两墙净分一致性条件后，模型实际上只得到1条训练标签，留出没有任何可用于方向测试的标签。因此绝不能报出“准确率0%”或宣称模型未通过一次方向预测：**这是没有可评价留出标签，而不是预测错误，也不是强度提升证据**。

此时不应放宽质量筛选门槛来强行获得正面结果；更合理的是增加独立自然洗牌种子和每点的物理合法未知墙排列数量，记录全量异质性，并在得到充分标签与新留出对局之后冻结学习策略进行真实终局对战。整个研发阶段在线AI仍保持不变。
