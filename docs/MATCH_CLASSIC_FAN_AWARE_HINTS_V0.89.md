# M3.78 · 经典 2D 听牌番值加权参考

## 本轮实际变化

上一轮 M3.77 的按需牌效参考，按照「最少向听数 → 有效牌未知张数上限」选出局部优先切牌。它不会区分同为听牌、但各听口可胡牌型番值不同的候选。M3.78 在**不改变原版 Majiang 固定 800×680 四人牌桌、不触碰服务器权威规则、也不增加 AI 每巡计算负担**的前提下，增加一项只读参考。

- Python 仍先用真正的四川 `effective_draws` / `winning_tiles` 确认切牌后向听数和有效张。
- **只有 0 向听**，才根据 `score_win` 对每一种公开未排除的听口，计算真实规则的基础牌型、当前房间 `fan_cap` 处理后的有效番和倍率。仅当当前对局已验证天听，且假设切牌后的**完整结构听口集合完全不变**时，才计入天听；不能因为“仍然听牌”就延续天听。
- 对该切牌各听口求和：`Σ(未知物理副本张数上限 × 2^有效番数)`。新的参考排序为：**最少向听 →（听牌时）番值加权上限 /（未听牌时）有效张上限 → 有效张上限 → 固定牌码排序**。相同指标并列推荐，不伪装成唯一全局最优。
- 在牌桌**下方**展示新列「听牌番值加权参考」，以及听口、理论牌型、有效番及倍率；尚未听牌的行展示“—”。原有完整手牌、碰杠胡、语音和终局收支完全不变。

## 严格解释限制

**这不是期望积分、和牌概率、真实牌墙剩余张数或放铳损失预测。** 对手暗手中可能拿着“未知副本”；本轮只按公开牌和自己手牌减去物理已知副本，不能知道究竟有多少张留在墙内；不把所有未知张数当作都可以摸到。特殊未来情景（杠上花、海底等）、自摸加底/加番支付、别人和牌导致的血战时序和打牌危险度都未入账。它是一个「牌型倍率 × 公开副本上限」的**局部比较辅助值**。

该功能只在玩家主动点击「查看当前牌效参考」时运行。API `match_hint` 保持 seat 0 bearer-token 认证、仅本人出牌回合调用、只读、不改变墙、AI、RNG或结算；新字段不会泄露任何隐藏牌。

## 自动验收

- `python -m unittest discover -s tests -p 'test_classic_hint.py' -v`：对对胡 1 番计分、真实 `fan_cap=0`、验证天听仅在原听口完整相同才保留、定缺限制、非听牌不臆造番值、授权和只读性质。
- `cd frontend_2d && npm run test:bridge && npm run build`：现有适配桥接和真实构建。
- 真实 Chromium `browser-hint.mjs`：检查牌型、番值、加权值和 6 列表格，且牌桌几何不变、旧提示随实际行动撤销。
- 其余既有四向56格牌河、原版手牌、中文碰杠胡、终局结算、两局真实 Python HTTP 对局仍在同一 CI 流程进行回归。
