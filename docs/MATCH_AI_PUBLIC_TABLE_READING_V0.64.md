# M3.53 公开场况读牌：定缺、牌河、副露、残局阶段

## 本轮目标

在 M3.52 “最小向听 → 听口剩余张数 × 支持的胡牌番数 / 非听牌牌型潜力”基础上，把**危险弃牌的判断**从“其他玩家公开两副同花色副露才有弱惩罚”，升级为公开可复查、每家单独估计的轻量风险指数；不改变四川血战到底的合法判定，不读取对手暗手、摸牌、真实牌墙或者私人随机种子。

## 模型输入与规则边界

输入全部来自当前授权 `private_view(seat)` 中的本家身份、公开 `missing_suits`、各家 `melds`、公开 `discards`、`won` 与剩余 `wall_count`：

- **定缺门安全性**：某玩家定缺花色等于要打出的花色，按当前项目的定缺胡牌规则，该玩家不能胡此张。这个判断只影响胡牌风险，不能推断其手中具体牌。
- **已胡退场**：血战中已胡的玩家不会再次和这次弃牌发生胡牌结算，风险贡献为零。
- **公开副露**：碰/杠组数增加，风险指数适度上升；至少两副同花色公开副露可能意味着该花色更值得警惕。暗杠不公开牌种，只计“多了一副”这一公开事实。
- **牌河**：观察指定玩家此前的公开弃牌花色与顺序。对某种牌曾经打过一次，仅将“再胡这张”的危险指数略微减低，**绝不能套用日麻振听、现物绝对安全等规则**。该人的定缺牌如果最近还在继续打，可能表示定缺尚未打净，谨慎减少指数。
- **巡目/牌山**：牌墙≤24张进入后期；≤12张进入危急阶段，同样的弃牌总体应更谨慎。牌山多少只是一个公开阶段信号，不代表某家必听。
- **多家计分**：逐家分别计算，再将尚未胡且能胡该花色的玩家的指数求和；允许一炮多响。

`read_discard_threat(tile, view)` 输出 `risk_index`、活跃潜在威胁家数、因定缺可排除的家数和各家 `danger` 指数。它们**不是概率、不等于放铳率**，参数目前是待实验标定的可解释启发式。

## 如何影响 challenge

只在达到**最小向听数的合法候选**中排序：

```text
初始行动价值 = 听牌时 Σ(未公开剩余有效张数 × 支持的胡牌倍率)
             或未听牌时 有效进张 × 弱牌型潜力因子

风险调整价值 = 初始行动价值 × max(0.72, 1 - 弱公开风险惩罚)
```

最坏也只把评分乘到 0.72，避免弱证据被当成“确定会放铳”；原 `challenge_no_pressure` 消融档仍完全跳过本风险乘子，用于配对区分风险项贡献。诊断器应复用决策的评分缓存，不要第二次进行所有候选的向听枚举；回合早退时缓存必须失效。

## 已加的自动测试

- 与自己定缺门一致的玩家不能胡该花色；已胡者不计入潜在胡牌风险
- 随牌墙减少改变同张牌的风险指数
- 其他玩家曾经打过同种牌也 **不保证安全**
- 公开同色两副副露可提高对应花色的风险；不通过暗杠牌种推断隐藏信息
- 注入虚构 `opponent_hands`、`future_wall`、`private_draw` 不影响风险指数
- 相同听口数和番值下，更少潜在合法胡牌者的弃牌应胜出

## 后续阶段建议

下一轮才适合在已通过成组评测的基础上增加**校准的对手听牌概率**：生成观测相同、私密分配不同的合法隐藏牌样本，以四川血战到底的实际规则做短步 rollout；要按座位与独立种子对照，记录平均净积分、放铳率、最高尾部损失、单步 p50/p95 和真实效果置信区间。现阶段的轻量风险指数不得被标示为已经学习到真实的条件概率或确立 AI 胜率提升。
