# M4.33：自然自对战多独立洗牌种子队列审计（v1.43）

## 问题来源

M4.32已用正式四挑战级AI、真实108张四川血战规则从两次独立洗牌的四个自然合法动作点完成16场配对终局模拟。但4个决策点只有1个在两个未来墙排列下积分差严格同向，且属于训练种子。留出种子虽有2个合法决策点却没有任何同向标签，不能推断模型预测成功率，更不能证明AI变强。

M4.33首先将研究样本扩大到预先固定的2个训练自然洗牌种子、2个互不重叠的留出洗牌种子，针对牌谱合法性、真实官方结算、隐藏信息和独立性进行审计，而不是挑选分数更好的牌谱。

## 实际新增代码

- src/mahtrain_core/ai_selfplay_cohort_audit.py：逐个验证自然种子簇、完整真实终局账本、净分三项分账、强制弃牌对照，拒绝丢失/重复/改写种子或训练留出重叠。把同一种子下的多个决策点和两墙四臂都作为相关样本，只计算一个独立洗牌簇。
- examples/run_selfplay_cohort_audit.py：复现真实四人挑战级AI自对战、保存完整可公开牌谱和本地私有训练/留出记录，导出纯聚合安全审计JSON。完全不依赖外部数据库、收费API或付费训练服务。
- tests/test_m433_selfplay_cohort_audit.py：真正运行自然牌局以及配对终局作为测试来源，检查108张牌和账本结构，并刻意篡改假分数、模型晋升声明、隐私字段与种子划分来验证失败关闭。
- .github/workflows/m433-selfplay-cohort.yml：Python 3.11/3.13独立专项单元测试，独立4种子端到端完整实验，只上传无私人手牌、洗牌种子、牌墙信息的安全聚合工件。

## 本地运行

在仓库根目录执行：

~~~powershell
.\.venv\Scripts\python.exe examples\run_selfplay_cohort_audit.py --seed-start 89720 --train-seeds 2 --holdout-seeds 2 --max-checkpoints 2 --out-dir data/selfplay/m433
~~~

产生以下文件：

| 本地文件 | 用途 | 安全边界 |
|---|---|---|
| public_four_challenge_replays.jsonl.gz | 每局四挑战AI完整公开牌谱 | 可公开复盘 |
| PRIVATE_actor_train.jsonl.gz | 训练玩家本人真实决策与两墙四臂官方得分 | 仅本地 |
| PRIVATE_actor_holdout.jsonl.gz | 独立留出玩家本人真实动作得分 | 仅本地 |
| PRIVATE_offline_model.json | 当前小样本离线受限模型 | 只用于研究 |
| PRIVATE_holdout_diagnostics.json | 留出具体判定 | 仅本地 |
| safe_aggregate_audit.json | 不含玩家暗手、洗牌种子、未来牌墙和决策细节的统计量 | 可公开的聚合研究报告 |

## 计量和决策原则

每个自然洗牌种子最多采集来自两个不同座位的合法同向听二候选动作点；每点两个合法未来墙×两个强制出牌动作，分别按真实规则打到终局。4个独立自然洗牌种子共4次自然对局，最多32场配对分支，即最多36场真实终局，不能把32场相关分支算作32个独立自然洗牌样本。

模型标签只有两个预先固定墙世界下净分差严格同正或同负才进入受限训练，反向和零差仍保留并纳入覆盖率统计；留出不足5个可评分的动作点时输出null而不是编造0%或100%准确率。即使超过5个，仍只能称条件化探索方向一致性，不能推出真实总体Q值、因果动作价值或强度提升。

所有直接用于对局行动的AI只接收其本家合法 private_view，而不接收对手暗牌、真实未来墙或游戏内部真值；完整实体牌局仅研究进程内存可用。公开牌谱只来自已经过滤的公共回放。数据目录 data/selfplay/ 已被Git忽略，GitHub CI仅上传安全聚合工件。

## 后续技术路线

需要扩大到多个十至数百个独立自然洗牌簇，考虑缓存与并行运行、更多合法条件未知世界采样、训练多个候选模型，并最终在全新的独立随机种子和均衡座位上真实对战，比较权威胡牌、杠钱、流局与最终净分。当前代码不调整正式挑战级AI、碰杠胡选择、牌桌UI、计分规则或在线用户模式，也不证明新AI已经增强。


## 首次 GitHub 实验真实结果（2026-10-25）

本次 [M4.33真实四种子实验](https://github.com/CrazyA1ice/MahTrain/actions/runs/40160681146) 的专项Python3.11/3.13单元测试、四自然洗牌种子真实对局、匹配分支终局以及隐私审计均**全部通过**，所有对局按真实当前规则结算、真实保存安全回放与本地私有样本。

| 核验指标 | 已观测结果 |
|---|---:|
| 独立自然洗牌种子簇 | 4（训练2、留出2） |
| 四挑战AI完整自然对局 | 4场 |
| 自然合法双候选动作点 | 8个（训练4、留出4） |
| 两个墙序×两个动作完成的真实终局分支 | 32场 |
| **全部真实完整结算对局** | **36场** |
| 训练端两墙严格同向的动作点 | **0条** |
| 留出端两墙严格同向的动作点 | **0条** |
| 形成训练标签的独立洗牌簇 | **0个** |
| 可评分的留出动作点 | 0个 |
| 可报告留出方向准确率 | **无（null；分母为0）** |

**此结果是本轮重要的负向发现，不是执行失败，也不能被表述为AI已经学会或变强。** 四个自然独立洗牌源确实提供了8个可对照的合法动作，但将“两个特定未来墙都得到同号终局积分差”规定为硬门槛后，八个动作没有一个可用于学习和验证。改用其他隐藏世界或增大牌局样本可能改变筛选通过率，因此0/8不能外推到自然全部状态，更不代表其它候选切牌与原策略必定等价。

后续研究应把动作的条件化净分分布完整保留，引入更多合法一致视角的未知牌世界，报告均值、方差、分量异质性与不确定性；在未经严格独立留出验证前，不能任意撤销硬门槛然后把训练结果当作实力证据。尤其应先核查“改变一次切牌→胡牌／流局状态大范围分叉”的高方差问题，必要时改用对比式采样、方差缩减技术和更多基于自然牌谱的候选覆盖。线上挑战级AI仍完全不变。
