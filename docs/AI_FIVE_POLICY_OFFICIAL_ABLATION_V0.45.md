# MahTrain M3.33：五策略正式积分与进张/压力组件消融（v0.45）

本轮直接扩展已有的 M3.10—M3.13 五策略、五轮不完全区组多种子实验，不重新构造另一套麻将对局。保留原胡牌事件、牌效比率、公开副露弱风险（“压力”）平局规则的影子选择诊断和原报告 CSV；新增基于用户确认的**流局方案 A**的正式净积分分析。

## 五策略的真实控制关系

| 策略 | 规则 |
|---|---|
| baseline | 独立牌形基线，不调用项目的向听/有效进张评估器 |
| advanced | 优先最低向听，平局按稳定牌序 |
| challenge_no_ukeire | 最低向听，去除有效张排序，保留公开副露弱压力平局规则 |
| challenge_no_pressure | 最低向听，按有效张排序，关闭公开副露弱压力平局规则 |
| challenge | 最低向听，按有效张排序，再按公开副露弱压力规则处理并列 |

每个初始洗牌种子运行五局，每局上场4种策略、1种休息。五轮之后，每种策略在0、1、2、3号座位均出现一次，单种子每策略**恰好4次座位出场**。五局因初始种子相同，按一个相关簇处理；不同策略的选择会改变后续行动与牌墙分叉，不能视为严格反事实。

房间系数100、封顶3番、无独立模拟杠钱，与现有规则引擎保持一致。每局服务端 `partial_win_balances` 和 `official_settled_balances` 必须四席整数零和；正式得分为**合法胡牌付款 + 真实牌山耗尽时仅未胡玩家间的查花猪/查大叫（方案A）**。如某个种子的五轮中有一局流局无法核验正式赔付，该种子**整组五局被排除**；原来的胡牌事件与原始切牌质量统计仍能查看，但正式积分与对应决策质量比较严格限定到完整有效的同一批种子。

## 新的积分、决策与风险描述

每策略报告有效座位出场、正式净积分总额及每次出场平均分。**同一已核验种子**下同时统计真实切牌数、最低向听切牌率、局部最优切牌率、实际切后有效张均值、已发生放铳责任事件/百次切牌。有效张由项目内部牌效评估器利用自身牌和公开可见牌计算，**不是预测将来摸到牌的概率**；放铳事件/100弃牌仅是事件率，不是经过校准的对手危险度或放铳概率模型。

对照共5项：完整挑战－关闭压力、完整挑战－关闭进张、关闭压力－进阶、关闭进张－进阶、完整挑战－独立基线。汇总并列正式积分差、最低向听率差、有效张均值差、观察放铳事件率差。逐独立种子计算正式积分差的正/负/平次数，以及“最低向听率更高但官方净积分更低”的种子数。无合格种子或无切牌的指标设为 `null`，不能伪装成0%性能。

仅在**至少5个有效独立种子**时进行固定随机种子的整簇 bootstrap，报告探索性的配对正式分差范围。即使5个有效样本也不足以声称任一弱风险规则或有效进张排序已被证实提高收益，更不是对真实麻将玩家的胜率测试。

```bash
python examples/benchmark_ablation_ai.py --seed-start 30 --seeds 5 \
  --json-out results/m333.json \
  --csv-out results/m333-decisions.csv \
  --contrast-csv-out results/m333-contrasts.csv \
  --pressure-csv-out results/m333-pressure.csv \
  --official-csv-out results/m333-official.csv \
  --html-out results/m333-report.html
```

打开 `m333-report.html` 可查看既有 M3.11/M3.12 可视化和新增 M3.33 两张正式积分与配对背离对照表。所有离线 HTML、官方 CSV 和新的 JSON 子树**只包含经过允许的聚合字段**；不输出暗牌、完整私有动作轨迹、未知未来牌墙或未打出的影子候选牌。官方 CSV 只包含合格独立种子下各策略正式积分、真实出牌计数与切牌指标。被排除的种子不生成“0积分”行。

GitHub Actions Python 3.11/3.13 运行全部单元测试、1种子正式比分验证，并在额外工作流里执行5种子真实完整对局、离线 HTML 和官方 CSV 校验。固定测试涵盖轮换公平性、四席及总积分零和、完整种子剔除、重复/缺失旋转、混合房间规则、恶意改写积分、错误类型、没有有效分样本时不伪造数值，以及重复执行 bootstrap 的确定性。

下一轮可在**固定更大种子规模**下针对公开副露压力规则加入可控的按牌局特征分层统计；前提是可靠证明分层指标不暴露任何暗手信息。当前不能因一次或五次种子对照就自动改变正式 AI 默认策略。
