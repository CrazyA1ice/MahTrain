# M4.28：延迟补杠根番、尾摸与抢杠风险的权威规则边界实验（v1.38）

## 研究缘由

M4.27的24个定向合法补杠检查点中，同一授权局面的现行挑战级策略与仅去除严格守门条件的离线策略出现5次分歧：2次有效进张数量减少，3次有效进张和番值代理都没有改善。然而当前牌效模型在**尚未听牌**时基本以有效进张数量作为价值代理，因此**不能直接把代理没有改善等同于补杠没有真实根番收益**。但反过来，也不能据此主张无钱的延迟补杠一定值得做；抢杠和尾摸以及回合后的收益有显著不确定性。

本轮只搭建规则正确性与未知信息边界的离线实验，**不变更已上线AI，不新增收益阈值，也不声称已经计算真实净分期望**。

## 三个可独立审计的组成部分

1. **完成胡牌条件下的根番**：使用现有权威 `score_win`，构造明确注明为假设的四副牌加将完成牌形，唯一变量是公开副露为三张碰还是四张补杠。对同一13/14有效牌结构的11张隐手，补杠后一张形成四张根，原始番数+1，并逐个验证番数上限对最终倍率的影响。**这不是从M4.26当前尚未听牌的10张手牌推演真实胡牌**，只是验证“如果以后某次胡牌且最终牌型如此，根番将按什么规则计分”。
2. **杠后尾摸和无钱杠**：在原24个构造检查点的同一真实时间线上，由玩家0持有上巡摸到但没有立即补杠的第四张，再经过其他三家真实摸牌及弃牌、本家下一巡真实摸牌。随后实际调用权威 `declare_kong`、依次处理抢杠响应、尾摸、真实零和杠钱账本及108张实体牌守恒。旧牌不属于当巡新摸的第四张，即使有合法补杠权，也**不能收杠钱**。额外报告根据本家与公开已见牌计算的下一次有效进张副本数／未知副本数，这只是**未知物理副本均匀抽取的代理比率**，不是获得真正未来尾牌、下几巡赢牌概率或经检验的净积分EV。
3. **抢杠的不可辨认性（rob-risk envelope）**：对于同一个玩家可见局面，把其他三家的暗手与尚未摸到的墙牌重新分配成另一个真实108张实体牌守恒的隐藏世界。在**玩家0完全相同的 `private_view` 和 `public_state`**下，构造某个对手合法听其补杠第四张的物理证据，让权威 `rob_options` 给出`hu`；在能够从剩余实体副本拼出该类合法听牌时，通过权威 `respond_rob_kong` 实际实施；**如果这种限定牌型无合法实体证据，就记录“本次未找到证据”，既不能虚构牌，也不能据此宣称抢杠概率为0**。对照另一个“所有人都选择过”的分支：
   - 过牌分支：补杠升级成功，尾摸发生，权威杠钱为0；
   - 合法抢杠分支：被抢的第四张按胡牌结算，补杠不升级、不尾摸，权威杠钱依然为0，点杠者承担规则规定的胡牌支付。
   
   **两个分支不是由公开信息得知的风险概率分布**。我们有意选择一个对抗性隐藏世界，仅用于证明“同样公开信息可以隐藏真正可抢杠的对手”；不能把“24/24可以构造抢杠”解释成“自然真实比赛抢杠概率100%”。实验中检查对手隐藏牌必须从未知牌池合法调拨，不可有第五张、重复付钱或偷看真实未来墙。

## 固定验证范围与输出

保持上一轮预先确定的24个已碰目标牌与两类手牌形态，按4个集合每组6例分别验收。所有测试只记录构造编号、目标碰牌、牌型分组、假设胡牌根番加成、公开有效进张副本／未知副本数、两个真实权威分支的杠钱、胡牌支付与尾摸布尔结果。原始对手暗手和未来墙**不进入线上AI，也不导出到审计JSON**。

## 后续何时可以优化正式AI

这轮增加**可证实的规则边界**，不能回答“下一巡保留第四张与立即补杠谁的长期期望积分更高”。这需要额外定义不泄露真实墙牌的可校准对手行为模型、逐分支独立多次完赛和正式胡牌、杠钱、流局联合净分评估；干预选择规则必须预先冻结，并使用独立留出种子判断是否值得替换线上AI。不得用本轮人为对抗世界的条件化风险结果直接调阈值。

## 实体牌约束与无证据分支修订

首轮 GitHub CI 发现：在部分集中型手牌中，补齐指定抢杠顺子所需的相邻副本已经不在任何未知牌池里，因此构造器不能保证每个案例都存在它限定的“三刻子一对子加待补顺子”证据。修订后的 `_rob_witness` **仅从真正剩余实体牌中选择**；无法构造时返回空，并跳过抢杠分支。这种空结果是“本特定手牌家族未找到证据”，**不是证明对手抢杠不可能或风险为零**。最终审计分别统计找到合法抢杠证据的案例数以及没有找到该形态证据的案例数，禁止将后者解释为安全率或频率。
