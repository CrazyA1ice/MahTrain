# M4.04 · 碰、明杠、过牌统一合法行动候选排序及完整终局对照

## 为什么从稀有抢杠转向全行动比较

M4.03 的24个独立初始洗牌种子、96局完整自然四川麻将（全部12项CI通过）仅观察到31个不同可补杠候选，无任何潜在合法抢杠胡正例。不断扩大稀有抢杠自然样本尚不足以显著改善玩家可见的 AI 对战体验。

本轮针对你的“出现碰、杠、胡选择时应计算是否行动、选择哪种行动”的要求，在**不篡改线上策略**的独立离线评估中，直接比较一次出牌后同一合法操作窗口里的所有 `pass/peng/ming_gang`。已有线上 `_challenge_kong` 会遍历比较每个合法暗杠和补杠，与“不杠”比较牌效；真实合法 `hu` 或抢杠 `hu` 在当前策略中优先接受。这两个成熟且涉及权益的行为暂不改变。

旧 `_challenge_claim` 可能在 `ming_gang` 通过75%保留门槛时马上返回，尚未比较同时合法的 `peng` 是否具有更佳的后续牌效；旧算法对“碰后马上必须弃掉哪张牌”的影响也只在等向听时做局部判断。**M4.04离线统一候选表**会评估：

- `pass`：当前真实13张有效牌的向听数、公开已知剩余有效张与按可胡番数加权的下一摸收益代理。
- `ming_gang`：真实移除自己三张对应牌并公开副露，对手打出的同一张牌从原公开牌河移至副露后只计算一次；计算杠后的13有效牌代理值。保留原挑战级至少75%的有效张／价值门槛，并保护天听原听口。
- `peng`：真实取自己两张和对手的公开弃牌组成碰后副露，**列举所有必须立即弃牌的合法候选**，严格优先打光定缺门、先筛最低向听，再根据有效张和潜在成牌番值选出最有利的后续切牌。向听变好时允许碰；若只是持平则必须有明显有效张收益并且仍未听牌。严格禁止通过碰牌破坏已确认的天听资格。
- `hu`、抢杠 `hu`：依旧由权威规则引擎提供合法选项后优先执行，不进入可以拒绝的代理排序，不拿未来牌墙或对手暗牌改变此决策。
- 自身 `an_gang/bu_gang`：保留 M3.79 已存在的**所有合法候选＋不杠**排序，以及补杠与抢杠真实规则处理，研究对象只做机会数和选择数统计。

排序先比较合法行动结束后的**真实向听数**，再比较依赖公开已知牌的下一摸番数加权牌效及剩余有效张。它是**一阶牌效启发式**，不是对最终完整四川血战牌局的“最优期望收益”证明。明杠即时杠钱、摸尾牌、可能被多人抢杠胡等复杂因素尚不具备可校准概率，不能伪造“真实胜率”或给未来结算预先设定正数奖励。

## 独立对局试验

种子**开发32000–32003／独立保留33000–33003**，每组4个独立初始洗牌种子、四座位轮换，分别模拟原挑战级和新的仅碰／明杠候选联合排序离线代理。每组为4独立洗牌种子×4轮换×2种策略＝**32局真实完整终局牌局**，两组合计64局、32个成对座位位置；其他3个AI仍为原进阶／基础／牌形基线。双方从同一初始洗牌和座位开始，但改变碰杠后会导致后续手牌和对手行动路径不同，所以**真实终局净积分是整套路径差**，不能声称一张给定牌后的后续隐牌事件绝对相同。

- 必须使用真实规则引擎，正式108张牌守恒，结算包含胡牌、杠钱、流局查叫/花猪。每次检验 `official_net = win_points+kong_points+exhaustive_points` 且全桌账本零和。
- 明确统计“同时存在碰与明杠选择”的真实窗口数、新旧动作真正分歧次数、按动作类型选择次数、AI真正合法胡和本家杠候选数。
- 单元测试保留通用胡牌保护、已认证天听保护、多种候选同时合法的统一排序、碰后合法弃牌、多座位与只读公开信息授权，避免把测试假想明杠与自然模拟混淆。
- 分组与种子必须**先在代码中固定**，保留组若没有实际差异必须如实报告；不能换一个能赚钱的种子，也不能根据开发组后验终局去调整排序门槛，再称另一组是独立保留验证。
- 每个独立初始种子的四座位先平均正式净积分，再对4个独立种子取均值。每组**仅4个独立种子**，不输出伪装的置信区间；只有两组均出现足够真实行动分歧且正式净积分改善，才考虑后续**更大未筛选种子的线上候选**研究。
