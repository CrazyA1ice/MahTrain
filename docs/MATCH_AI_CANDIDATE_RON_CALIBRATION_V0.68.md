# M3.57：针对具体弃牌的真实点炮标签与样本外校准

## 与 M3.56 的区别

M3.56 只标注“目标玩家是否已经听牌”。听牌并不意味着任何弃牌都会被胡。本轮扩大为**本家准备打出的某张具体牌，被某一个仍在场的对手合法胡牌的事件**，以及该事件按当前规则产生的胡牌倍率。离线标签通过服务端当前可信手牌与 `winning_tiles`、`score_win` 得出；在线预测只能访问当前观察者已经授权的 `private_view` 中的**自己手牌**和公开局面。

本轮只新增**离线研究/评估模块**，没有把不稳定的概率输入正式挑战 AI 的每一切。不偷窥其他座位暗手或牌墙，不扩大浏览器能看到的私人信息，不增加正常对局耗时。

## 样本定义与法律规则

- **观测单位**：一次真实自对局决策前的 `(观察者, 某活跃对手, 本家某一种合法待切牌)`。候选牌必须存在于本家手中；如果本家仍持定缺门麻将，只采样该花色的强制切牌。
- **真实结果**：目标对手必须有13张等效牌（副露每组占3）；目标已经胡牌/14张待出手牌则不纳入样本。验证如果本家此时切出候选牌，目标是否能够立即依法荣和。合法胡牌则标签1，同时由规则 `score_win` 算出当前番数倍率；否则标签0，倍率0。杠钱、未来摸牌、查大叫等并不包含在此**立即点炮**损失定义中。
- **定缺胡牌限制**：某对手定缺花色等于待切花色，依本项目规则不能凭该花色胡牌。这是一条**明确规则**，而不是统计推断。预测模型和基线均对此类候选给出0点炮风险，不错误引入日麻振听。
- **多家胡牌**：样本先按目标玩家分别标注，之后才能在同一个真实状态对多个目标的预期倍率求和，不能把“对手是否听牌”代替“能否胡某张”。
- **隐私保护**：仅可信离线回调 `_sealed_target_payoffs` 读取真实暗手；`public_candidate_features` 只读取公开牌河、副露、定缺、牌山和本家手牌。输出文件只写聚合指标、模型相对基线的差值和每个**测试洗牌种子**的差值，不写单条预测、真值或任何对手牌种。

## 初始实验方案

**公开特征**（含截距共15维）：牌山进度、对手副露/牌河、非定缺弃牌比例、近期定缺弃牌、副露花色集中度；候选牌花色、是否为目标定缺花色、对手同花色副露、对手此前打过同种牌、对手同花色河牌比例、其他玩家公开同种弃牌密度。所有特征固定并可以从当时合法可见信息重建。

**基线**：只依据定缺硬约束和训练数据中“可胡花色”的总体点炮率预测，使用平滑先验；条件平均番数倍率由训练集真值确定。

**候选模型**：仅对可胡花色样本拟合小规模带 L2 正则的逻辑回归（标准库实现），同一独立洗牌种子的样本总权重相等，不能从真实暗手生成特征。不能因为点炮为稀有事件就在训练中虚构均衡正反例。

**评价**：Brier Score、Log Loss、5个概率段的校准频率和 Expected Calibration Error；另外报告 `p(点炮) × 训练正例平均倍率` 对真实立即点炮倍率的平方误差，以区分概率准确性和预期积分损失。报告分别列明总行数、点炮正例数、可胡花色行数、正例数；数据按洗牌种子，而非逐行随机拆分。测试集只被用于评估，不参与拟合或选阈值。

**CI**：4个独立训练洗牌种子 + 3个独立测试洗牌种子，快照抽样步长6。比上一轮2+1种子增大，但样本高度相关，**仍不足以说明模型可靠或带来棋力提升**；尤其需同时看每一个测试种子的得分差方向，不能只看全样本平均。

## 研究结果的合规解释

即使本轮样本外 Brier 更低，也不能直接断言真实对局净积分提高。要进一步达到“每一切期望收益最大”，仍需要：

1. 大量真实/模拟对局的独立种子、不同玩家策略、位置轮换与置信区间；
2. 单步决策 p50/p95 耗时及“实际点炮损失”验证；
3. 从被动合法胡牌标签推广到“目标会选择胡牌”的策略行为估计；
4. 与 M3.52/3.53/3.55 固定种子座位匹配对照；跨策略泛化确证后冻结模型，才可选择性接入上线策略或有限预算的多步信息集搜索。

所有模型与 CI 研究输出均**不是**已经校准可用于实盘的点炮概率。
