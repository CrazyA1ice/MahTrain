# MahTrain 单人14轮训练与可视化交互 v0.2

> 当前有效的**单人训练实现说明**，替代旧版 v0.1。本版本使用已有血战规则 v0.4 的已确定子集，**不代表四人血战正式规则引擎已经完成**。代码完全基于 Python 标准库与原生网页 HTML/CSS/JS，不需要额外 pip 安装。

## 一、理牌（已改为升序）

- 花色顺序固定 **万 → 条 → 筒**。
- 每种花色内按 **1 → 9 从小到大**，相同牌紧挨排列。
- 只改变**可视排列**，不会重新洗牌、改变牌张数、修改听口或影响向听/牌效计算。
- 适用四种独立出题、14轮单人训练、命令行和本地网页。
- 示例：`万[1 3 3 9] | 条[2 7] | 筒[1 5 8]`。

## 二、连续训练的新决策状态机

```text
开始：初始13张、墙剩95张、指定/自动选定缺门
  → 摸1张（普通摸牌从墙前端）
  → 自动判胡？
       是 → 弹出“是否胡牌？”
            确认 → 记录合法自摸，提前结束并出报告
            放弃 → 检查可开暗杠
       否 → 检查可开暗杠
  → 暗手牌内有非缺门的四张同牌、且墙中有可补的牌？
       是 → 弹出“是否开暗杠？”
            开杠 → 从暗手牌移除这四张，锁入独立杠区
                   → 从墙尾补一张 → 返回“自动判胡”
            不开 → 跳过该次杠选项，进入切牌
       否 → 切牌
  → 用户点击暗手牌的某张牌出牌 → 才公布正确动作、解释和进张
  → 将该张牌加入公开弃牌 → 下一轮；最多14轮
```

提示遵循 **胡牌优先于暗杠**。一次杠后的补牌**不增加训练轮数**。若连续补牌后还形成另一个四张同牌，系统可继续检测新的暗杠。已确认胡牌由程序主动弹窗，不再让玩家把 `win` 当作普通切牌选项。放弃可以胡的牌继续出牌会判为非最优动作。

## 三、杠区及实体牌

- 当前单人训练只支持**暗杠**：自己手里的四张相同牌，确认后移入界面右侧的独立杠区。
- 杠区每副显示**四张牌**和“暗杠·已锁定”标识；四张牌从可点击的暗手牌和切牌候选中删除，不能再次操作。
- 开杠后固定从**牌墙尾部**补摸一张；普通回合摸牌则从墙前端取得。
- 四张杠牌仍计入自己的**全部已知物理牌**，牌效计算会扣除相应副露枚数；无论开杠多少次，108张实体牌总数保持不变。
- 补牌导致直接胡牌时，记录 `win_type: kong_bloom`；此处只识别事件，暂不做四人杠钱结算。
- 本模式**不模拟对手出牌**，所以不提供明杠、碰后补杠、抢杠或杠上炮。正式四人模式再接这些真实动作与收付款逻辑。
- **定缺花色暗杠边界尚未在血战规则中明确**；本单人原型暂不主动提示该花色的暗杠，避免在尚未确认时把有争议的动作误判为合法。此限制需在完善正式规则时单独确认。

## 四、操作方式

### 本地网页（新增）

在本地 MahTrain 仓库根目录执行：

```bash
git pull origin main
python web_server.py
```

然后在本机浏览器打开：

**http://127.0.0.1:8765**

功能包括：训练种子与定缺、点击“开始新训练”、手牌自动升序理牌、点击“摸下一张牌”、点击麻将牌切牌、自动胡牌确认弹窗、暗杠确认弹窗、**独立杠区**、每轮反馈、公开弃牌、训练成绩报告。页面复用 `assets/tiles/` 下的已有真实牌图（少部分扩展名虽为 png，字节实际上是 JPEG，服务器已自动适配 MIME）。

网页仅监听 `127.0.0.1`，数据保存在本地 Python 进程内；浏览器只持有会话随机令牌，不持有未来牌墙、种子和未提交的最优答案。关闭 Python 进程后，内存会话不保留。这不是可部署公网的生产服务，不具备账户、多用户隔离持久化、WebSocket、认证和四人联机等功能。

### 命令行

```bash
# 手动练习，胡牌/暗杠时都会主动询问 y/n
python examples/solo_14_rounds.py --seed 17

# 不等待输入：自动同意胡牌，并按局部最优切自动出牌
python examples/solo_14_rounds.py --seed 17 --auto

# 演示连续开暗杠、尾牌补摸（仍按条件发生，不强制伪造可杠局面）
python examples/solo_14_rounds.py --seed 17 --auto --auto-kong
```

## 五、测试、接口和验收

- `src/mahtrain_core/presentation.py`：`sort_hand`, `grouped_hand`。
- `src/mahtrain_core/session.py`：`SoloTrainingSession`，`public_state()`，`draw_next()`，`decide_win(accept)`，`decide_kong(tile_or_None)`，`submit(discard_tile)`，`report()`。
- `web_server.py`：本机 HTTP JSON 服务，`/api/action` 实际调用可信 Python 会话；`web/index.html`、`web/app.js`、`web/app.css` 展示交互。
- `tests/test_win_kong_prompts.py`：固定实体牌例测试自动判胡、拒绝胡牌、暗杠迁移、尾牌补摸、杠上花、杠区锁定。
- `tests/test_web_app.py`：本机 HTTP 服务、图片真实 MIME、静态资源、会话数据不暴露暗墙/答案、提交后的反馈。
- `tests/test_solo_session.py`：理牌升序、实体牌守恒、连续14轮与重现性。

运行：

```bash
python -m unittest discover -s tests -v
```

CI 额外执行 `node --check web/app.js`、四种单题公开输出、单人连续14轮及自动杠流程冒烟测试。
