# M4.41：全新独立洗牌种子的保守牌效约束对照（v1.51）

## 研究动机

已收到用户 M4.40 安全审计：M4.39 两组原始洗牌共10场真实对局，原冻结候选140次切牌机会中改切61次，全部使可见有效进张减少，平均-8.98361张；其三项特征的**冻结权重全为负**。模型评分优势逐项平均为：有效进张数 0.002470492、下一摸进张概率 0.000600726、有效牌种数 0.000553195，总和 0.003624413。对应原M4.39真实配对积分差为-230；样本只有2个原始洗牌簇，不能由此证明因果或显著性。

因此采取一个预先固定、无需训练新权重的实验性保守基线：在沿用原挑战级代理选牌、冻结模型特征和最低向听数规则的情况下，如果冻结模型首选切牌比原挑战级切牌**更少有效进张张数**，直接退回原选择。它只在研究性影子候选中启用；不修改已上线的 challenge，不动态调阈值。

## 正式协议

每个新原始自然洗牌 seed 运行9场真正完整的官方结算对局：

1场：四名原挑战级AI的基准对局。
4场：原冻结模型（无保守约束），分别轮换四个座位，其他三家全是原挑战级AI。
4场：同样冻结权重，但对影子切牌附加“有效进张不许减少”硬性否决，四座位轮换，其他三家全是原挑战级AI。

两个候选策略始终与**同一原始洗牌seed中的同一个原版基准局**比较；四个座位不被虚称为4组独立样本。报告中保留两个候选对原挑战级的实际净积分差、胡/杠/流局构成、保守门槛拒绝的改切次数、真正被接受的改切次数。整个模型/门槛在实验前冻结，不利用之前 M4.37/M4.39 的结果优化权重。

### 为什么增加原冻结候选作为对照？

为了知道新的新洗牌种子是否仍出现原先的负向现象，以及保守约束是否成功防止这种局部改切，而不是只因为全部退回原挑战级就给出“AI实力提升”的错误结论。

**若保守策略接受改切为0，则它与正式Challenge的结果完全相同是预期现象，不代表候选AI优于Challenge。**

## Windows本地执行

拉取仓库主分支，然后在根目录执行：

~~~powershell
cd D:\ChatGPT\MahTrain
git switch main
git pull --ff-only origin main

python examples\run_local_guarded_shadow_trial.py --train-dir data/selfplay/m434-smoke --prior-m437-dir data/selfplay/m437-shadow-2 --prior-m439-dir data/selfplay/m439-actor-2 --seed-start 91500 --seeds 2 --out-dir data/selfplay/m441-guarded-2
~~~

这将用两个**新的原始洗牌种子**共进行18场真实完整对局。过去的 M4.37和M4.39比赛均不重复执行。程序验证新的seed区间不与 M4.34 训练/留出区间，以及指定的M4.37和M4.39批次重叠。

**91500、91501只是假定未曾使用的新种子示例**；如果在其他实验中已经用过，请选没有使用过的新区间（程序无法检查未提供的其他历史计划）。

不慎中断后，用同样命令加 --resume；只复用已完整保存且核验通过的整个**九局原始洗牌簇**。如某个新簇在打到一半时中断，该簇会从头进行，不会把未结算的部分局当作完成。

成功后查看安全汇总：

~~~powershell
Get-Content data/selfplay/m441-guarded-2/safe_guarded_frozen_shadow_trial.json
~~~

**只需上传这个 safe JSON**。以下私有数据不能上传到公开GitHub：

- PRIVATE_guard_trial_plan.json：冻结模型指纹、训练目录、对照目录、新seed。
- PRIVATE_nine_game_seed_clusters：每个种子的九局真实官方结算对照及检查和，带具体shuffle seed。
- 原M4.34/M4.37/M4.39的PRIVATE模型和对局文件。

这些默认保存在被 .gitignore 排除的 data/selfplay 下。

## 解释边界

本轮同一洗牌种子可以形成配对比较，但因为改变切牌会改变后续博弈轨迹，两个候选的实际终局差是**完整策略对局差异**，不能推断到具体哪一手的因果收益。两个新种子也不足以报告显著性，至少应扩大到事先确定的充分独立种子批次，然后在新数据上检验；绝不能把四座位轮换当作4个独立seed。

完全回退到原挑战级属于**安全退化行为**，不是模型学习成功。后续应在原M4.34训练集内修正负方向目标及单调先验，再拿一个全新、未被观察过的真正独立评估集检验。
