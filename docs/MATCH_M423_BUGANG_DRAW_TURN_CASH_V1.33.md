# M4.23：补杠当巡杠钱限定与挑战级 AI 调整（v1.33）

## 用户确认的新规则

玩家已碰出三张同牌，后来摸到同牌第四张，**只有摸到第四张的这一巡就完成补杠，才能获得补杠钱**。如果选择保留第四张，到以后某巡再合法补杠，仍然构成四张杠，仍然从牌墙尾部补牌，但**不收取补杠钱**。

“番数仍然正常加一番”按本项目已经确认的**四张相同实体牌形成一根时增加的根番+1**执行，由 `score_win()` 的根数及房间封顶统一计算。这里不额外发放“每次杠动作固定+1番”；杠上花、抢杠等其他事件番依原规则另算。原始番可能高于房间上限，实结按 `fan_cap` 截断。

## 规则引擎变更

- `FourPlayerOpening.declare_kong`：在清除本家最近一次真实摸牌标记之前，依据 **`_drawn_tiles[seat] == tile`** 判定本次补杠是不是刚摸到第四张的当巡。首次庄家起手持有的第4张不被当作新摸牌。
- 补杠后的抢杠响应是异步的；当巡资格必须在申请补杠时冻结到 `_pending_kong.cash_eligible`，不能在抢杠响应结束后根据已经清空的摸牌标记重新判断。若抢杠胡成立，补杠不成功、不产生该笔杠钱。
- `KongLedger.declare` 新增可信 `cash_eligible` 布尔参数（默认 True，兼容历史调用）；仅补杠允许 False。延迟补杠产生公开审计事件：`status=not_payable`、`amount_per_payer=0`、`reason=delayed_bu_gang_no_cash`、`cash_eligible=false`，**不产生付款流水和余额变化**。后续如果该杠引发杠上炮，原来的 void 事件操作也不能凭空产生反向退款。
- 明杠、暗杠不受本时效规则影响。所有实际实体牌、真实尾摸、被抢杠的来源牌、胡牌番型计算以及108张守恒检查都保留。

## 挑战级 AI 的对应改进

`MahjongAgent("challenge")` 仍然保证所有选择来自引擎合法 `kong_options`，只访问本座位私有当前摸牌和公开牌，不读取其他家暗手或未来牌墙。

原挑战级把补杠按照是否退向听、公开有效副本数和牌型价值与“暂不杠”的最佳弃牌比较。当补杠为**非本巡摸到的第四张**时，其杠钱收益变为零，因此在**同向听**的候选中提高选择要求：补杠后的有效进张和公开番值代理都不能下降，并且至少有一项严格增加才考虑补杠。若补杠能严格改善向听，仍允许原逻辑接受；当巡有杠钱资格者仍遵循原75%保留门槛。该改动是可解释的启发式，不是已通过独立多种子实战证实的最优策略，不能据此宣称更强或者提升胜率。

## 页面与操作提示

- 玩家补杠选择区明确写“当巡补杠·可收杠钱”或者“延迟补杠·不收杠钱”，确认弹窗中再次提示。即使房间未计价，“可收”也需要以房间配置的杠钱底分为前提。
- 杠钱流水明确记录“延迟补杠不收杠钱”，不把零收入冒充已计价杠钱。
- 经典 2D 操作建议列明延迟/当巡补杠区别和可能被抢杠的风险。
