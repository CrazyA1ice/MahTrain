# M3.51 杠钱正式净额、海底/河底加番及固定牌桌（v0.62）

## 用户需求和新规则

- **当局收益**：人机对局的明杠、暗杠、补杠即时结算，直接加入四家“已入账积分 / 本局合计 / 历史正式净额”：
  - 明杠由放杠者向杠家支付 **2 × 杠钱底分**；
  - 暗杠由其余未胡玩家各付 **2 × 杠钱底分**；
  - 补杠由其余未胡玩家各付 **1 × 杠钱底分**；
  - 杠上炮发生后，准确按原杠事件编号冲销本次杠钱；抢杠未成立的补杠不扣钱。
- **旧开关的作用**：原“启用独立杠钱模拟”控制是否给独立账本定价。若不勾选，原先的每局收益只计胡牌与正式流局赔付，因此玩家会发现杠钱不变。
- **本轮改为“自定义杠钱底分”**：不勾选时杠钱默认采用当前房间系数作为底分，并正常入账；勾选后才使用另填的杠钱底分，仍正常入账。对局创建时固定本局所选底分，不会中途随设置变化。
- **历史兼容**：旧版已完成对局的“试验杠钱”不追溯计入，不能无依据改写用户以前的胜负；新归档明确标记 `kong_included=true`，同时核验胡牌、杠钱、流局的四家零和合计；战绩曲线显示所有新旧对局按当时采用的正式计价约定所得分数。
- **海底捞月 / 河底摸鱼**：确实从物理牌墙摸走最后一张（含杠后尾部补摸）并自摸胡，则海底捞月 +1 番；摸走最后一张后切出该牌造成点炮/一炮多响，则每名胡者河底摸鱼 +1 番。不是只见墙剩 0 就加番；按原始番计算，再受房间现有“番数封顶”控制。
- **AI**：1 / 2 / 3 号默认全为“挑战”，允许玩家在开局前自行调整。
- **固定尺寸**：牌桌占据预留固定网格行，牌河中弃牌换行仅增长内部滚动内容，不再改变牌桌整体高度、中央碰杠按钮位置或玩家坐标。手机个人手牌仍可水平滑动。

## 回归关注点

1. 无胡牌、有杠钱时，桌内也必须显示本局积分与收益；
2. 同一笔杠上炮冲销后，最终净额不得重复计算，四家合计必须为零；
3. 末张自摸和末张点炮分别加一番，点炮中的多人胡分别加番；此前已被吃掉的牌不能再据“牌墙=0”触发海底；
4. 旧版归档既有试验杠钱保持原样，新版正式杠钱随 `settled_b0` 和公开战绩进入 SQLite，不保存他家暗手或牌墙顺序；
5. 牌河分行过程中牌桌高度稳定，窗口变窄时可响应式改变大小但**不随摸切动作变高**。

## 规则边界

当前采用 M3.3 已实现的明杠2、暗杠各2、补杠各1倍计价方案，用户可以单独设置底分。这是本地人机模拟的明确计分约定，不主张四川全部地区都使用相同杠钱规则。既有番数上限仍生效，超过上限的末张 +1 番不会额外提升封顶后支付倍率。
