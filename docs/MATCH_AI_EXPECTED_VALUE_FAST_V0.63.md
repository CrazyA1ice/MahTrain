# M3.52：挑战档期望切牌与高速回放（2026-10-18）

## 已确认的瓶颈

- 旧挑战策略以最小向听、有效进张张数和少量公开副露压力作词典序比较，未对各听牌实际可得番值求期望；牌型高价值机会被进张数量覆盖。
- 原默认回放每帧450毫秒，`showPublicMotion` 返回 `announceFrameWait`，回放控制器必须同时等定时器和语音 promise 完成，语音引擎无 `onend` 时还需2.5秒 watchdog。每个 AI 公开动作又作为一次 HTTP 续步请求，体感会明显迟滞。
- 本轮取消**语音等待屏障**，改为语音播报后立即让渲染控制返回；视觉仍保留 180ms 默认帧宽以便辨认摸切、积分变化。语音可能因连续快动作被后续语音覆盖，属于快节奏优先的取舍；玩家仍可选 450/900ms 或关闭播报。出牌名仍播报具体牌；碰、杠、胡只播相应一个字。

## 本轮挑战档评分

每次先为所有合法切牌计算精确的 **切后向听数** `S(t)`，只比较达到最小向听数的候选，保留“不主动退向听”的既定约束。每个候选切出的牌计入可见信息，不能错误地重复当作未知牌。

- **听牌 `S=0`**：逐张遍历真正能胡的听口，使用当前规则引擎算支持的最终番数 `f_i`（含根、纯色/七对等牌型与已验证的天听，但不凭空假设将来海底等事件），并计算未知的物理剩余张数 `n_i = 4 - 已知张数_i`。基础分数 `EV(t)=Σ n_i × 2^f_i`，再乘弱风险修正。该分数是**下一摸机会的相对期望权重**，而非包含抽到此张概率、点炮与自摸收付款方、全局对局胜率的货币收益。
- **未听牌 `S>0`**：仍以向听改善所需的有效进张总数为主体，用较小系数对已成对子（七对潜力）、刻子（对对胡潜力）以及同色比例（清一色潜力）做启发式修正。尚未完成的牌型不按最终实际番数结算。
- **公开场况风险**：只有对手至少公开两副同一花色副露，且该花色不是其定缺门时，才赋予弱风险系数；牌墙较少时提高系数。该推断只是概率信号，不能认定为他家听牌，更不能偷窥暗牌。

## 非最优性的明确边界

这是一次可审计、固定计算量的**单步价值函数升级**，不是全局最优策略。真实最优行动需要动态考虑后续摸打次数、对手进度、预计放铳概率、自摸/点炮不同赔付、弃牌可用性和多玩家收益；目前无需训练网络，性能成本与传统牌效算法同阶。番数封顶继续从本局规则读取。

## 下一阶段真正的读牌与场况推断

1. **公开信息特征**：逐家跟踪已弃牌顺序、碰杠、定缺、已胡座次、牌山剩余、上一张摸切/手切标记与时间；维护公开计数矩阵，不读取他家手牌。
2. **条件化隐藏牌采样**：对108张实体剩余牌采样，限制对手定缺清空状态、已公开的碰杠与已胡事件，禁止使用实际服务器牌墙或暗手。相同可见观测不应因隐藏牌实值变化而改变策略。
3. **对手建模**：估计每家听牌概率、听口概率、预期最大番、预计放铳损失。优先使用可解释的手切/摸切序列、缺门打净进度、公开副露和晚巡倾向，之后由自对局数据标定概率，不依赖简单主观倍数。
4. **确定化 Monte Carlo / 信息集 MCTS**：对候选切牌采样多个合法隐藏世界，统一按照四川血战规则进行短期滚动模拟，评分 `E(本局最终净收益) - λ·尾部亏损风险`。预算按单步延迟上限动态分配，先筛除退向听动作再对前3～5个候选重点搜索。不同隐藏样本、种子与座位轮换做配对对照。
5. **正式验收指标**：至少记录每步决策耗时p50/p95、整局净积分、每座胜率、放铳率、平均实收番数、听口剩余张数、主动退向听率、不同难度强弱排序，置信区间用成组种子计算，严禁只凭单局感觉称“最强”。
