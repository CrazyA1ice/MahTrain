# M4.49：仅以行动者可见信息，对碰／过真实分支做分层诊断

## 从已完成的真实对照出发

用户提供的 M4.48 安全报告：24个新独立原始洗牌，18个自然出现首次可碰但原Challenge选择过牌的局面；24场自然基准、72场完整分支，总计96场真实终局。24簇平均强制碰减过净分 -30.83，胡牌 -35.42，杠钱 +2.5，流局 +2.08；方向为8簇碰更有利、9簇过更有利、7簇相等。簇级Bootstrap探索性区间 [-137.34,+64.01] 跨零，18个有碰机会的种子有7个在两世界下盈亏方向不同。与更早M4.47的8簇 +20分不一致。

这支持继续保留正式Challenge碰牌规则，不能把已看过的盈利或亏损用于调参，也不能在M4.47、M4.48这两个曾经看过的测试集上宣布某种可推广的条件策略。M4.49转而检查：**行动者在碰牌前看到的结构特征是否有助于描述分歧来源**，但不训练新的碰牌政策。

## 实验固定定义

每个全新自然shuffle，只选择原Challenge真实第一处“合法可碰、原版选择过”的响应；若没有就保留缺失记录，而不是按结果挑选事件。记录该名行动者正常private_view中的5个事先定义的粗类标签：

- 碰牌后按合法最优向听立即切一张，向听比过牌前改善/相同/倒退；
- 在上述最佳向听的假想切牌中，最好的有效进张比过牌前增加/持平/减少（只用行动者暗手与公开牌的牌效评估，不使用未知墙顺序）；
- 公开剩余墙牌数量：early≥40、middle 20～39、late小于20；
- 对手已经公开的副露副数：0／1／至少2；
- 当时已验证天听：yes/no。

该“碰后最优切”属于**在决策前的可见牌效代理**，并不是未来打出了这张牌的事实；其进张不是胡牌几率、风险校准值或已证明的行动价值。

对每个局面，在**完全相同真实状态和四家AI历史随机状态**下，分别使用世界0原墙、世界1固定重排的尚未摸取墙，每个世界强制pass和peng，各走一场完整四川血战麻将并核算全部胡/杠/流局净分。世界0强制pass必须与不修改的Challenge自然基准官方四座位分项逐个相同。每个原shuffle最多一处检查点，不会根据结算来选择最佳样本。

预先固定新24个原shuffle种子。完成24场自然基准与最多96场完整分支，只有**原始shuffle**是真正独立统计单位。分层只做描述，不拟合阈值、不改挑战级AI；某个标签分组独立种子少于3时，安全JSON仅发布数量，不显示终局收益和方向，避免暴露太细的小群记录。哪怕分组均值正面，也不能把它直接选为在线碰牌行动规则，因为那仍是在新测试集上做了事后模型选择。

## 历史来源和保密

本轮会核验M4.48的24个真实终局已结算私有SHA分片，重算原M4.48摘要核对胡/杠/流局、收益方向和簇级Bootstrap区间，同时反向核验M4.47、M4.46以及更早M4.34训练/留出与M4.37/39/41/42/43/44的历史seed区间。避免重新用过的历史种子。实验计划冻结源码SHA、模型来源、原seed起点、样本量，不允许修改实验规则后直接续跑。

原shuffle整组结束才会保存私有原子分片，--resume仅复用完整SHA通过的已结算簇；中断半截的重跑。保存的私有JSON只有实验类别、终局净额和源种子，没有原始手牌或未来墙序列。可上传的safe JSON仅包含聚合计数与至少3个独立seed的分组收益；不泄露种子/手牌/牌名/模型权重/私人来源路径。
