# MahTrain M2.5 本地训练历史与 SQLite 错题本（v0.7）

> 当前为本机单用户训练原型，血战规则仍采用独立的 v0.4 草案。本版完成**已结束训练的持久化**、跨重启历史成绩查看、旧错题重练和本地进度摘要；不是在线账户或云同步服务。

## 一、新增能力

- 每次完成14轮，或提前确认合法自摸结束，自动将该次**完整已评分报告**保存到本地 SQLite。不会保存未提交回合、未来牌墙、洗牌种子、临时令牌或未完成训练。
- 同一个随机种子可以重复训练；每次都会分配新的随机 `archive_id`，因此新成绩不会覆盖以前的成绩。
- 打开浏览器页面时，底部的“**本地历史训练与错题本**”展示最近40局历史及累计局数、完成轮数、回合正确率、历史错误数和**最早最多5局 vs 最近最多5局**的平均局正确率。样本少时不应将波动误认为确定性进步。
- 点击某局“查看历史报告”可以展开该局逐轮切牌/胡牌选择、最优选项、向听/有效进张/概率和判题说明；在旧报告的错误回合点击“重新练这道题”，可以重新以相同手牌（包括冻结的暗杠区）作答、看旧答案/新答案对照。
- 历史错题重练次数与最近一次重练结果同步写入数据库。关闭服务再打开，仍可继续复习这些错题。
- 可以选择“永久删除这局及重练记录”，点击二次确认后删除 SQLite 中该局和关联重练记录；不可撤销。

## 二、训练流程与安全边界

`web_server.py` 用 `MAHTRAIN_HISTORY_DB` 环境变量指定 SQLite 文件；默认位于仓库根目录的 **`data/mahtrain_history.sqlite3`**。数据库文件及 SQLite 的 WAL/SHM 文件在 `.gitignore` 中排除，不应提交至 GitHub。数据只保存在**运行这个服务的电脑**上，不会自动同步到另一台设备。

具体的服务器过程：

1. 玩家先发13张牌，自己看牌后选择定缺；服务器持有完整108张实体牌墙。
2. 每轮摸切按原有 Python 判胡/牌效算法计算并反馈。只有训练真正结束时，才将冻结的回合分析数据存到 SQLite。
3. 原本 `retry_list/retry_question/retry_submit` 仍可针对刚结束的本局使用，但计数和答案现在由 **SQLite 存档**接管，因此重启后仍可访问。
4. `GET /api/history?limit=40` 返回历史列表及累计摘要；`GET /api/history?archive_id=...` 返回**已结束**该局的完整复盘与存档重练状态。
5. `POST /api/action` 中的 `history_retry_question` 仅返回真实错误回合的暗手牌、暗杠区及合法候选动作，**不提前返回标准答案**；`history_retry_submit` 根据**原先冻结的同一回合分析标准**重新评分，并写入新尝试记录。
6. `history_delete` 删除单局及关联重练记录。所有写入使用 sqlite3 参数化 SQL；表通过 SQLite 外键绑定。无需安装第三方依赖。

### 必须区分的限制

- **仅已结束的训练保存**；进行到第7轮时关闭 Python 服务，不会保存该未完成局的进度，也不能直接从第8轮恢复。
- 历史是**本机共享**的，不支持账户登录、不同用户/浏览器隔离；能够访问本机服务的使用者可以查看或删除这些数据。服务仅监听 `127.0.0.1`，不要将端口暴露到公网。
- 原训练的正确答案在首次练习后已经公开，错题重练是自我检查而不是考试防作弊机制。
- 重练只改变错题尝试记录，不改变原14轮游戏和牌墙，不新生成历史牌墙，不读取AI隐藏手牌。
- 修改原始算法后的新版本，历史重练**沿用已冻结的当时结果**，所以不会无声地因后续版本升级改变旧题的标准答案。真正的版本迁移需另行开发。
- 本地 SQLite 文件未经加密。要备份或迁移历史，应先正常结束服务，再备份该数据库文件。

## 三、本地运行

在仓库根目录：

```bash
git pull origin main
python web_server.py
```

本地浏览器打开 `http://127.0.0.1:8765`。开始一次14轮训练，结束后刷新底部“本地历史训练与错题本”。停止服务（`Ctrl+C`）后重启，已结束的训练记录仍会出现。

自定义存储文件：

```bash
# Windows PowerShell
$env:MAHTRAIN_HISTORY_DB = "D:\\MahTrainData\\my_training.sqlite3"
python web_server.py

# macOS/Linux shell
MAHTRAIN_HISTORY_DB=~/mahtrain_data/history.sqlite3 python web_server.py
```

注意更改数据库路径就会看到该路径中的另一组历史；原有数据不会自动迁移。

运行自动测试：

```bash
python -m unittest discover -s tests -v
```

专门测试：

- `tests/test_history_store.py`：跨数据库重新打开、重复种子单独归档、只归档完成局、跨重启重练计数、删除级联、数据验证。
- `tests/test_web_app.py`：走本地真实 HTTP 接口，从训练结束归档 → 清掉内存会话 → 重开 SQLite → 查看历史 → 旧错题答对 → 删除，保证原报告不变。
- GitHub Actions：Python 3.11 / 3.13、网站 JavaScript 语法、原有单题/14轮完整冒烟测试。
