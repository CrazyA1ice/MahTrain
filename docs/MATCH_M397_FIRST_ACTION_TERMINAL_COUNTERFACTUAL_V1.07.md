# M3.97 · 挑战级首次碰杠机会的单步反事实、全局终局收益追踪

## 研究问题与安全边界

M3.96 已将碰、杠、胡、过加入实时行动参考，但那只比较**当次公开信息**、向听和进张代理值，没有真正求得整局积分期望。M3.97 单独做一个完全离线的、不能通过 HTTP/浏览器调用的成对反事实实验：**仅在指定种类的首次合法可选操作**改变挑战级一个座位的动作，其余回合所有玩家使用原本相同的 AI 策略，然后走真实四川血战规则直到三家胡牌或牌墙耗尽，检查权威零和正式结算。

## 冻结三个动作选择方案

仅研究两类在程序中预先固定的真实操作机会，不能事后挑一个收益最好的局面当代表性样本：

- `claim`：挑战级第一次有**碰或明杠**合法可选机会，但已经可以**胡牌的窗口排除**，绝不压制一炮多响/合法抢杠胡。各候选是 `过`、合法明杠、合法碰牌。
- `own_kong`：挑战级在自己应出牌时第一次可选择暗杠/补杠；如规则引擎已确认可自摸胡，则该机会排除，避免研究干预偷偷阻止即时合法自摸。含多个合法杠牌时逐项区分，但安全输出只有 `an_gang#1`、`an_gang#2` 等顺序标签，不公开暗牌牌名。

两类分别跑三种确定、冻结的策略：

| 策略 | 首次真实合法操作机会 | 后续全部操作 |
|---|---|---|
| `baseline` | 原挑战级真实选择 | 全部仍按原挑战级 |
| `force_pass` | 强制当次“过/不杠” | 全部仍按原挑战级 |
| `force_active` | 强制合法列表中按明杠、碰或首个可杠动作优先排序的第一个非过选项 | 全部仍按原挑战级 |

**如果强制方案本身就是原策略选择，就重用原局结果，决不伪造“干预成功”。** 如果种子和座位没有该类操作机会，记“未覆盖”，不能拿0差额证明两个策略一样。只允许改变首次操作，未来任何机会不得持续接管挑战级 AI。

## 配对机制和官方结算

- 每个相同种子和座位轮换的对照从同一个真实洗牌/换三张/定缺/对手策略开始，且在发生被干预动作前校验完全相同的**授权决策视图签名**：自身暗手、公开牌、当前局面、现有副露和规则给出的合法选项。签名留在可信对象内，不能导出为逆向猜牌标识。
- 首次干预以后的路径允许变化；包括别家的响应、碰杠次序、尾部摸牌、抢杠胡、胡牌、杠钱和流局分账均通过正式规则引擎执行。反事实差只证明**这个已发生的给定种子世界**的结果差，而不是精确的在线概率或者条件必然收益。
- 必须核验108张牌守恒、所有权威结算账户零和、总正式净积分＝胡牌分＋杠钱分＋流局分；并分别导出胡牌事件/点炮事件/杠事件差及完整行动步数。
- 分组固定：开发种子14000—14001、**独立保留**15000—15001；每种子四席轮换，`claim` 与 `own_kong` 两类**不当作独立洗牌样本**。每组2个独立洗牌种子×4席×2类=16目标位置。是否确实有对应机会、干预是否改变动作均独立报告。
- 主指标按单个独立种子的四座位平均正式净积分差，再跨两个种子求均值。只有2个种子，结果强制 `interval_95pct=null`，不得用独立操作次数/轮换席位伪装成置信样本。
- 如果没有独立保留组重复收益，或者干预极其稀少，不对正式在线挑战级 AI 作改动，不声称“最优策略得到证明”。

## 下一轮

若在保留组出现真实的净积分正向证据，需要另行预注册**更多独立真实种子**、抽取覆盖更多杠牌场景的未筛选样本、严格区分抢杠与杠钱，然后可考虑把训练组学到的**公开局面特征**作为线上受限启发式；绝对不能把这次真实未来墙牌或完成结果“喂”给直播操作推荐或 AI。

### 官方得分账本与路径归因

日志已验证全局正式净积分差由权威三本账相加，不是自行估算的番数：

- 开发组“首次碰/明杠→过”：**8个座位位置累计净积分差 -802**，其中胡牌差 0、杠钱差 -2、流局差 -800；1次额外胡牌事件同时伴随1次额外点炮，不能单看胡牌事件次数判断盈利。
- 保留组“首次碰/明杠→过”：累计 **+400**，其中胡牌差 +300、杠钱差 0、流局差 +100；胡牌事件净少1次，仍然可以有更高正式净积分。
- 开发组“首次碰/明杠→积极”：累计 **-200**，其中胡牌差 -100、杠钱差 0、流局差 -100；保留组累计 **+100**，来自胡牌差 +100。
- 开发组“自身杠→积极”：累计 **+3**，全部来自正式杠钱分账，未改变胡牌和流局净积分；保留组完全**没有自身可杠机会**，所以所谓0分差不能作为独立验证。

上述结果显示，**某一次碰杠的长期收益变化可以主要来自远处的流局分账，不一定来自即时胡牌或杠钱**。但这仍是给定随机初始牌堆世界的配对路径差，不具备充足样本量来证明某类行动在未知牌墙下总体更优。

### 结论和上线策略

研究成功识别了强制改操作会引发正式终局现金流变化，却没有给出足够一致的独立收益。两组各只有2个独立种子；暂不拟合或改写线上 AI 碰杠政策，也不称“可完整计算碰杠全局最优”。下一轮应提高**未筛选独立种子数量**，对自身杠的低覆盖率另做预先固定的更大规模自然对局，分析对手明副露、牌山阶段、定缺残留与公开高危牌等**事前可观测**特征是否预测真实策略收益，杜绝对结果做事后选种子。
