# MahTrain M3.10：挑战档有效进张与公开弱风险规则消融（v0.22）

## 目的与设计

M3.9 的完整挑战档在最小向听数相同时，优先选择公开信息有效进张枚数更多的切牌；若再并列才采用公开副露花色压力的弱风险规则。**M3.10 不把同源算法评出的局部最优当作真实获胜能力**，而是控制其他操作规则不变，单独关闭这两部分切牌规则。

对照五种策略：

| 策略键 | 比较对象 | 切牌规则 |
| --- | --- | --- |
| baseline | 独立牌形基线 | 本家同牌与邻牌形状，不调用向听或有效进张评估器 |
| advanced | 进阶 | 最小向听，完全并列按牌序 |
| challenge_no_ukeire | 消融 A（仅公开弱风险） | 最小向听，关闭有效进张排序，并列时公开副露弱风险 |
| challenge_no_pressure | 消融 B（仅有效进张） | 最小向听、公开有效进张；不使用风险平局规则 |
| challenge | 完整挑战 | 最小向听、公开有效进张、公开副露弱风险平局 |

两种消融都继承挑战档的换三张、定缺、胡碰杠和独立随机种子；只更改切牌平局裁决，不读取对手暗手或后续牌墙。“仅风险”只是弱启发式，并非已验证的安全牌识别。

## 赛制与口径

每个独立洗牌种子运行五个四人对局：策略按 (seat + rotation) % 5 轮换，rotation=0..4。每次一位策略休赛，其余四位入座。**同一洗牌种子的五场对局是一组相关观察，不是五个独立样本**。五场后每位策略恰好占据四个座位各一次，因此四座次暴露数相等。

报告包括每策略胡牌事件、放铳责任、真实切牌最低向听率、局部最优率，以及下列同组差值：
- 完整挑战 - 关闭公开弱风险：估计风险平局规则的附加作用。
- 完整挑战 - 关闭有效进张：估计有效进张排序的附加作用（两种方法均使用风险排序，但排序层级不同）。
- 仅有效进张 - 进阶；仅弱风险 - 进阶：提供两个组件各自相对基础向听排序的差异。
- 完整挑战 - 独立牌形基线：维持与 M3.9 的独立规则型参照。

这些不是严格的独立反事实：多名策略在同一场中相互影响，且移除有效进张会改变风险规则被触发的机会。因而只能表述为**在该轮换赛制内的整局策略差异**，不能将差异直接解释为孤立因果效应。

切牌评价仍由项目内部同源牌效评估器计算，胡牌事件属于草案规则下的实验日志，不是正式血战结算后的胜率。杠钱、流局花猪查大叫的最终计价边界尚未确认。

## 运行与文件

仓库根目录下运行：

    python examples/benchmark_ablation_ai.py --seed-start 11 --seeds 1

生成结构化报告：

    python examples/benchmark_ablation_ai.py --seed-start 11 --seeds 5 --json-out results/ai_m310.json --csv-out results/ai_m310.csv

支持 1～50 个独立洗牌种子，每种子五场，运行时间和种子数近似线性相关。CLI CSV 以 UTF-8 BOM 导出每独立种子、每策略的原始计数；JSON 额外给出比较值和审计边界。网页维持既有 M3.9 入口，M3.10 当前先提供命令行与 CI 验收，不在网页误标正式胜率。

小于五个独立种子时只给出描述性差异，intervals=null。达到五种子时基于**整组五场**进行固定伪随机种子的配对重抽样（默认400次），提供探索性分位区间。区间不是正式胜率置信区间，若区间跨零不应声称优势稳定。

## 验收条件与后续

- 检验开关生效：有效进张同分时独立测试压力排序、有明显进张差异时测试“仅风险”与完整版不同，且关闭进张版本不触发有效进张评价函数。
- 验证五轮中每种策略对每个座位曝光一次、同一独立种子整体重抽样及结果可复现，强制小样本区间为空。
- 用真实四人闭环动作检查108张实体牌守恒、胡牌零和临时流水与公开回放不泄漏暗手。
- GitHub Actions 同时执行 Python 3.11/3.13 单测与单种子 M3.10 冒烟，存档 JSON/CSV。**单种子冒烟仅用于程序验收，不是实证胜率结论。**

下一阶段应在明确正式计价规则之后运行不少于五个、最好更多相互独立的种子，对“胡牌事件／放铳／局部最优”的差异分别讨论，并尝试引入真正外部独立策略，不把单一内部裁判的100%局部最优解读为实战保证。
