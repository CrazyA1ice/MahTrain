# MahTrain M3.10：挑战档公开进张与弱风险规则消融（v0.22）

> 本轮属于可复现的实验工具，不更改普通人机对战中的入门、进阶、挑战三档。当前四川血战结算仍是草案，任何胡牌事件率均不是正式胜率。

## 受控变量

两种新增策略仅供实验：

| 策略 | 向听优先 | 公开有效进张排序 | 公开副露弱风险平局项 |
| --- | --- | --- | --- |
| challenge 完整挑战档 | 是 | 是 | 是 |
| challenge_no_ukeire 去进张排序 | 是 | 否 | 是 |
| challenge_no_risk 去弱风险项 | 是 | 是 | 否 |

换三张、定缺、合法碰杠胡、随机种子和信息权限与原挑战档一致。消融公开有效进张时不调用 analyze_discards 作切牌排序，保留向听并列时的公开副露压力；消融弱风险时，仍使用向听和公开进张，最后按固定牌序打破并列，不调用压力函数。两个变体不是新的普通难度，也不会读取其他玩家暗手或后续牌墙。

## 对照实验设计

每个独立洗牌种子使用两个分别报告的四人分组，每组进行四次座位轮换：

- baseline 组：独立牌形基线、完整挑战、去公开进张、去弱风险。
- advanced 组：进阶档、完整挑战、去公开进张、去弱风险。

每种子共 **8场**，各策略在各组中占过四个座位。两组使用同种子，但第四个对手不同，不能直接比较两个组的绝对胡牌率、将8场视作8个独立样本，或把两组拼成正式实力榜。**只有同组内比较才有共同的对手组成。**

每组输出参与数、胡牌事件数、放铳数、最低向听率、局部最优切牌率、完整挑战减去各对照者的三项率差，以及逐种子聚合计数。正差值表示完整挑战在本批样本中的数值较高，不能单独证明实力更强。评价牌效仍是本项目同源评估器。

至少5个独立种子时，按每组四轮为一个完整种子簇、400次固定随机种子的配对重抽样，给出探索性区间。样本较小时不输出区间。这些区间不代表真人胜率的可靠置信区间。

## 使用方法

仓库根目录执行：

~~~bash
python examples/benchmark_ai_ablation.py --seed-start 11 --seeds 1
~~~

运行5种子并导出报告：

~~~bash
python examples/benchmark_ai_ablation.py --seed-start 100 --seeds 5 --json-out results/ai_ablation.json --csv-out results/ai_ablation.csv
~~~

最多支持50个独立种子（共400场），实际运行可能耗时较长。CSV采用UTF-8 BOM以便 Excel/WPS 阅读。JSON和CSV均为实际运行后输出的聚合数据，不含暗手、未来牌墙或逐动作私人轨迹。

## 验收与限制

- tests/test_ai_ablation.py 验证两个消融信号的代码级隔离、四座位平衡、种子聚合及异常输入，并实际运行一场108张牌守恒的合法四人局。
- CI在 Python 3.11 与 3.13 下分别执行单元测试和一个种子8局的冒烟对照，上传相应JSON与CSV。
- 原M3.9独立基线、网页三档人机对战、牌效训练仍保持原功能。本轮CLI优先，没有新增网页操作入口。
- 尚未解决正式杠钱、流局花猪/大叫结算，也未验证大量对局下的显著优势或真人表现。不要把胡牌事件计数包装成正式比赛胜率。
