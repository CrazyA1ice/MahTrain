# M4.12：冻结明杠改碰候选的跨独立洗牌复验与证据门槛（v1.22）

## 为什么这轮先不修改挑战级 AI

M4.11 的 [PR #111](https://github.com/CrazyA1ice/MahTrain/pull/111) 已通过专项、64场完整自然配对实验和 Python 3.11/3.13 全量验证并合入主分支。原挑战级选择明杠的真正合法双选项窗口很少：开发组46000–46003，只有**1次**按固定门槛0.25把明杠改为碰牌，所对应的完整比赛正式净积分合计 **+1**（来自杠钱分账）；独立保留组47000–47003 **0次真实改选，净差0**。一次收益，且无法在保留组产生任何真实干预，绝不足以证明策略优越。

本轮**绝不调节0.25阈值，也不根据M4.11的成功种子定向挑样**。完整原挑战级及 M4.11 已冻结的 `risk_peng` 两臂原样重跑，新增事前固定、互不重叠的新自然洗牌区间：开发组 **48000–48007**，独立保留组 **49000–49007**。每种子四座位、每座位两臂，合计 **16个独立洗牌、64个座位配对、128场完整权威比赛**。前序试验的洗牌种子均未用于此次新增区间。

## 以独立洗牌为统计单位的核对

研究评估 `evaluate_block` 会逐一核对：
1. 两条配对臂均实际完成对应座位的完整游戏；四座位旋转不得重复或缺失，同一初始洗牌仍只算**1个独立种子**。
2. 每场权威收益 `official_net = win_points + kong_points + exhaustive_points`；候选-原始差值必须精确对应两条官方账本，并严格汇总到种子、分组与全部账目组件。
3. 无实际策略干预的对局必须净积分和其他官方指标完全相同，且仍满足上一轮执行过的真实公开完整轨迹一致性保护。不能把“本来没有机会改选”的牌局解释为候选有效。
4. 原始臂不允许做任何策略改选；实验臂的真实改选计数、种子内计数、总计数必须一致。非法缺位、非整数账面成绩、错误种子、错误报告门槛和同一洗牌多座位重复统计均拒绝。
5. 写出的 M4.12 JSON **仅保存每洗牌种子的汇总指标、组别官方分账及通过/拒绝原因**。不输出原始每局的牌河／暗手／补尾牌、完整轨迹或行动身份；原 M4.11 成对对局内部用于验证的逐位置数据不在本轮归档中。

## 保守且预先声明的“继续研究”门槛

每个独立组必须**同时**符合以下前置条件，才能算作“有资格继续做更大规模新种子试验”，**并不表示可以上线**：

- 该组至少 **8次**真实策略改选（不是合法可选窗口数量）。
- 改选覆盖至少 **4个不同初始洗牌种子**，不是同一洗牌的多座位重复。
- 至少 **3个独立种子**完整对战四座位平均正式净积分差为正，且正收益种子数必须严格多于负收益种子数。
- 开发组和独立保留组**同时**满足全部条件；任何一组不满足都记录具体原因，判定证据尚不足。
- 门槛仅决定是否值得继续独立试验，不声称置信区间、胜率显著性、动作局部因果价值、校准的点炮概率，也永远不会在代码内启用正式 AI。

这些覆盖度与方向性条件只是初步研究门槛，不构成统计显著性或上线门槛。即使两个组都达到条件，还需更严格、独立的新实验和运行时间核验。本轮不部署策略、不把启发式危险指数理解为0～1概率。

## 研究边界

实验风险只用当前本人可见牌桌，原始危险指数是活跃对手多项启发值之和，可能超过1，**不是点炮概率**。配对策略在少量合法碰＋明杠双选项中改选碰，之后游戏轨迹随之改变；完整比赛积分差是**整个路径的结果**，不是单个响应动作的无偏因果回报。不要在未来回顾测试中更改阈值、挑选带正向差异的种子或混用开发、保留组。任何 CI 未完成的组不得宣称“完整通过”。

正式 AI、麻将牌面、对战页面、108牌数量、血战胡牌／杠钱／流局权威结算，以及用户的出牌体验全部保持原样。
