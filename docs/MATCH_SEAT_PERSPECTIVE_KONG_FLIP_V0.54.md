# MahTrain M3.42：左右家视角理牌与暗杠翻牌（v0.54）

## 桌面四家视角

- 上家（屏幕左，3号）手牌与副露的牌面朝西；下家（屏幕右，1号）朝东。左右两侧的理牌采用他们**自己从左到右**的视觉次序，不沿用坐在下方的0号玩家视角：左家由屏幕上方向下方排，右家反向由下方往上排。
- 侧边副露同步转为竖列，并按坐席方向朝向玩家；侧边牌河也改成面朝所属玩家，不再倒着朝牌桌中心。延续现有四面定缺标识和牌背颜色偏好。
- 本轮优先处理 **桌面** CSS，不改移动端牌桌密度和滑动体验。

## 暗杠公开方式

与本轮用户确认的显示规则一致：**四张同样牌种中三张盖住、一张翻开**。仅对正式宣告的暗杠，把牌种作为公开信息传给四人牌桌和合法公开回放；绝不将对手暗手、暗摸到的牌或未来牌墙传给客户端。

公共标识：`{"type":"an_gang","tile":"m9","revealed":true}`。此标识代表正式宣告后仅一张明牌的披露，不代表四张均正面。前端只翻第4张；出于座位朝向，实物仍呈一组四张副露。自己暗杠也不再显示四张明牌。

历史兼容：早期对局存档的暗杠没有 `revealed` 标识；即使存在无可信标识的 `tile` 字段，清洗器和前端仍会将其置空。历史隐牌仅显示四张盖牌，不虚构旧档案未公布的暗杠种类。新的公开档案则按白名单存储已经声明可翻的一张合法麻将牌。存档与逐步回放均不保存或渲染其他三张暗牌的身份。

## 不受影响

仍然只消耗四张真实麻将，暗杠后照规则尾摸并通过原有牌数审计；不变更暗杠计分、碰杠胡的仲裁与定缺规则。自摸加底／加番、实时公开支付、已胡退出和方案 A 流局规则保持不变。
