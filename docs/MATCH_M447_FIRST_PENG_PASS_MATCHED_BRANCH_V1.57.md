# M4.47：首次自然“可碰却过”局面的原状态碰/过双分支终局对照

## M4.46 的真实依据

20个独立原始洗牌种子、100场完整对局中，原Challenge的候选响应共1794次，可碰104次，可碰却过36次。研究性等向听+1/2张进张碰牌规则，28次因听牌或向听限制被排除，另8次因额外进张不满足被排除，实际改碰0次；20个原始shuffle所有结算差均0。这说明继续追加该固定候选的5局对照并不能在样本中提供新的行动效果证据。

## 新一轮M4.47实验问题

本轮**不训练策略、不强制调整碰牌门槛、不改变正式挑战级AI**，改为研究真正出现过的合法行动分歧：对于自然挑战级对局首次出现的“当前玩家合法能碰、原Challenge响应过”的位置，在完全一致的到达状态下分别执行“过牌”和“碰牌”，以后保持四家Challenge真实决策流程，打到整局结束，比较真实官方净积分。两个分支共享同一个游戏状态、同一组四家AI已经前进到该时刻的随机数状态。

每个原始shuffle最多取**第一次**这样的合法机会，不能根据该动作以后谁输赢挑最有利的机会；若没有机会，则整簇保留零覆盖记录，不伪造行动收益。

为初步检查末尾未来牌墙波动，每个局面设定2种固定未来墙安排：
- 世界0：完全保持原始自然牌墙不变，强制过牌分支的完整官方四座位净积分及胡/杠/流局分项必须逐座位与未经修改的自然挑战级局一致，否则运行失败。
- 世界1：在内存中按固定种子对尚未摸取的牌墙进行排列变化。变更只发生在动作决策后的未来墙顺序，当前行动者的正常private_view和公开状态必须逐项保持一致。世界1内，两个分支使用完全相同的新墙排列。

每个发现局面的原shuffle最多额外运行2组乘以2行动=4局完整终局对照；如果其他人同时胡牌/杠牌获得较高优先级，研究代理本次强制声明peng未必最终成功，实验将单独统计成功碰牌的分支对照和被其他合法争夺动作盖过的分支。只能将结果解释成**条件在当时完整已实现状态和固定后续世界的有限双分支结果**，不能将其当成未知他人暗牌下的策略常态期望、无偏单动作因果或新策略强度证明。

原牌墙实际完整四人血战由FourPlayerOpening完成，检查108张实物、四家净余额的win/kong/exhaustive全部零和。未来真实对手响应、后续碰杠胡和弃牌仍由现有Challenge agent和真实规则引擎完成，不用预估/伪造未来得分。

## 隔离、保密、可恢复

从原M4.34训练源及原M4.46冻结计划检查模型指纹、原M4.45和M4.46所有已结算五局私人检查点SHA与相关安全汇总，再向上核验M4.37/39/41/42/43/44的历史种子区间。必须使用**完全新的自然洗牌种子**，不在这些历史训练/探索/评估里重复。当前首次研究预先固定8个独立原始shuffle：建议92800~92807。如用户还运行了其他未记录实验，也要自行排除种子重叠。

研究进程中的真实游戏内存拷贝包含尚未公开的手牌与墙序，但只用于**真实规则引擎**，绝不作为AI的私有输入或导出。私有文件仅含已完成4局分支的终局净额、首个行动者座次、真实原种子；不写入碰牌牌面或对手手牌；安全JSON只含独立seed簇数量、可碰过牌出现簇数、完整回合和分支次数、真实总净积分差、胡/杠/流局分项、分支是否真实接受碰牌、seed簇正/负/零数量。没有具体洗牌ID、手牌或未来墙。

每原shuffle整组完全结束后才原子保存一个含SHA-256校验的私有分片；支持--resume，验证且完整完成的shuffle不会重复运行。计划额外锁定研究模块源码SHA-256，若用户修改源码或换seed/来源参数，就不能沿用旧私人评估数据。

## Windows PowerShell本地运行

在仓库根目录更新：

~~~powershell
cd D:\ChatGPT\MahTrain
git switch main
git pull --ff-only origin main
~~~

随后运行8个全新原始shuffle：

~~~powershell
python examples\run_pong_pass_branch_rollouts.py --train-dir data/selfplay/m434-smoke --prior-m446-dir data/selfplay/m446-pong-20 --seed-start 92800 --out-dir data/selfplay/m447-pong-pass-8
~~~

如果遇到中断，在完全相同命令后追加--resume。若某个shuffle的局面和分支没有全部结算则整簇重做，不将未完对局的分数写入可分享安全文件。

结束后查看并**仅上传**：

~~~powershell
Get-Content data/selfplay/m447-pong-pass-8/safe_pong_pass_branch_rollouts.json
~~~

不要上传PRIVATE_m447_pass_peng_branch_plan.json、PRIVATE_m447_original_shuffle_branches、旧M4.46完整分片、原seed、权重、对手暗手等。
