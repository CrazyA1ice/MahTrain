# M4.40：冻结评分方向与改切有效进张减少的逐项核验（v1.50）

## 研究起点

用户完成 M4.39 的全新独立原始洗牌簇 2 个、真实完整对局10场。安全结果：140次出牌机会中61次候选改切，61次均减少本家可见有效进张，平均每次约-8.98361张；原始洗牌簇配对平均真实官方净积分差-230。**这说明当前模型的实战切牌方向存在强烈可疑的偏向，但不能用两个种子作统计显著性或因果结论。**

回看原 M4.35 学习器和 M4.36 评分器可知，冻结学习器只学习三项权重：可见有效进张张数/40、下一摸进张概率、有效牌种类数/27。各项越大代表在同一向听级别下越有利于快速进张，却**没有正权重、单调性或不退有效进张的硬约束**。如果条件未来牌墙的少量离线积分恰好与牌效负相关，学习的某些权重可能为负，评分器就会偏向更少有效进张的切牌。M4.39 的61次同方向改切使这一机制值得优先检查。

## 本轮实现（M4.40）

1. **只读已有 M4.39 私有真实数据**：检查完整原始种子簇、SHA-256、行动者逐手记录、已结算官方账本与原安全聚合一一一致，不运行任何新麻将对局。
2. **从 M4.34 TRAIN 分片精确复现并校验 M4.35 原冻结权重**：核验其SHA-256等于 M4.39 开局前冻结的权重指纹，不从 M4.39 已发生结算中训练或调阈值。
3. **重构每个真实改切的完整三项模型评分差**：完全沿用原始 7 位特征舍入逻辑，将每个模型正 margin 拆为三项贡献；只要保存的 margin 与根据冻结模型算出的值不一致，拒绝输出审计结果。
4. 安全 JSON 中提供三项权重的正/负/零符号（不公布精确权重）、各特征对模型分数正/负/零贡献次数、各特征每次改切平均贡献、改切造成可见有效进张减少/持平/增加的计数。
5. 报告记录简单的假设：**如果未来给候选 AI 增加“不允许减少当时可见有效进张数”的保守门槛，历史上多少次候选改切会被禁止**。这只是对原记录的资格筛选，不是重新跑过终局结算的真实对照，不应声称历史的 -230 分会改善为多少。

本轮没有改变在线挑战档、冻结模型权重、历史评估输出，也没有把过去两批已经看过的种子伪装成新的检验数据。

## Windows 执行（复用已有数据，无新对局）

在 MahTrain 根目录：

~~~powershell
cd D:\ChatGPT\MahTrain
git switch main
git pull --ff-only origin main
python examples\audit_frozen_score_geometry.py --train-dir data/selfplay/m434-smoke --actor-evaluation-dir data/selfplay/m439-actor-2 --report-dir data/selfplay/m440-geometry-2
~~~

成功后查看并仅分享安全汇总：

~~~powershell
Get-Content data/selfplay/m440-geometry-2/safe_frozen_score_geometry.json
~~~

- M4.39 的原真实 seed、对应切牌和特征留在本机 PRIVATE 目录；M4.40 的安全报告不包含这些内容，也不会输出精确冻结权重值。
- M4.40 会重新**读训练记录计算出同一权重**，但不会训练新模型、修改冻结结果或额外运行对局。
- 输出目录必须新建/空，不能指向训练或评估目录。出现模型指纹不匹配、记录缺失或评分差不一致时直接失败，不静默修复历史证据。
- 若用户曾更换本地 M4.34 训练文件导致原冻结模型发生变化，须保留原始数据核对，不要为了让检查通过而用已看过的测试对局重新训练覆盖模型。

## 下一轮：预注册的新种子对照，而非盲目改线上 AI

若 M4.40 验证了模型评分偏向减少有效张，可设计 **M4.41 实验性保守门槛**（候选必须满足至少不减少本家可见有效进张，或者维持原挑战级切牌）与原冻结候选/原挑战级在完全新洗牌簇下进行真实对照。注意原挑战级本身以有效进张作为重要排序目标，因此保守门槛可能让大量局面直接退回基线，表现不差不代表获得“新强度”。必须分别报告主动改切覆盖率与净积分，并保留训练集、历史观察集和新测试种子分离。
