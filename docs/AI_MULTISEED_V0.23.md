# MahTrain M3.11：多种子消融稳定性与离线报告（v0.23）

> 本版本保留 M3.10 的五策略、四座次轮换以及真实四人状态机，不修改胡牌、杠钱、定缺或训练界面，重点回答：某个随机种子是否主导了挑战档与两个消融版本的表现差异？

## 统计单位与新增指标

独立单位是**洗牌种子**，不是局数或玩家出场。一个种子对应五场相关四人对局：五个策略轮流休赛，每个策略在该种子内占据四个座位各一次。25局、五个独立种子，不能当作25个独立样本。

在 M3.10 原有整组 Bootstrap 区间基础上，新增：
1. **逐种子策略差值**：单独汇总每个种子的五场，计算策略之间胡牌事件比例、最低向听率和局部最优率的差值。
2. **正负方向频数**：逐独立种子统计正、负、相同和未定义的次数；比一张总和指标表更便于观察结果一致性。
3. **留一种子敏感性**：不少于5个独立种子时，逐一去掉完整种子分组，在剩余组中重新累加分子分母计算各项差值，报告最小值、最大值和是否跨零；这不是统计显著性检验。
4. **离线 HTML 报告**：SVG 柱状图、逐种子差值表和敏感性表，无 JavaScript、网络依赖、对手暗手或秘密牌墙信息。

## 实际运行（至少5独立种子以探索性区间为目标）

在仓库根目录：

~~~bash
python examples/benchmark_ablation_ai.py \
  --seed-start 11 --seeds 5 \
  --json-out results/m311.json \
  --csv-out results/m311_policy.csv \
  --contrast-csv-out results/m311_contrasts.csv \
  --html-out results/m311_report.html
~~~

- JSON：所有聚合统计、独立种子、整组 Bootstrap（不少于5种子）、方向次数和留一法范围。
- policy.csv：逐种子逐策略的胡牌事件、放铳和切牌计数。
- contrasts.csv：逐种子 × 五组策略对照，每项差值列后缀为 _delta_pp（百分点），使用 UTF-8 BOM 以方便 WPS/Excel。
- report.html：浏览器本地直接打开，无需启动 web_server.py；图表只展示聚合统计，不可从中复原暗手或牌墙。

命令行支持1至50个独立种子。少于5个时，intervals 与 seed_analysis.leave_one_seed_out 都是 null，不呈现虚假统计区间。5个种子仍只是*探索性技术验收*，不是充分的胜率统计样本量。

## CI 及数据解释边界

Python 3.11/3.13 原有全量单元测试、单种子五策略对照继续保留；本轮新增 Pull Request 上独立的 Python 3.11 五种子×五场=25局任务。验证5独立种子、20次每策略出场、108实体牌守恒、完整敏感性/区间结构，并上传 HTML、CSV、JSON。

同一洗牌种子下的四人策略仍相互影响，因此差值不能视为严格的组件独立因果作用；切牌局部最优仍由项目内部同源裁判评分。胡牌事件比例不是完整川麻计分后的胜率，杠钱和流局赔付规则仍为未定草案。

下一阶段可以扩大独立种子数、引入外部独立对手并确认最终计分规则，再讨论具备实战意义的整体积分指标。
