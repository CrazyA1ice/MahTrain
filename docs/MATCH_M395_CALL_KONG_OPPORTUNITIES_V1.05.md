# M3.95 · 挑战级 AI 可选碰杠机会：明确策略的离线消融与场况覆盖

## 起因

M3.94 的48局正式对战中，挑战级 AI 的237次出牌无一低于“单步向听、有效张与番值权重”的**公开信息参考**。该结果不能证明整局博弈能力最优，因为**是否碰、何时杠、是否承担抢杠风险与其他玩家的博弈反应**不在切牌榜单的衡量范围内。

M3.79/M3.80 既有实验表明挑战级改进碰杠后较旧策略更多副露，但首次四个种子与独立八个种子的净积分差方向相反。M3.95 不重复把“新策略比旧策略”当作结论，而是固定两项更可解释的消融策略，量化出牌以外的真实可调整机会及其正式净积分。

## 三种冻结策略

所有策略具有**完全相同的挑战级**换三张、定缺、切牌、合法胡牌与普通 pass 规则；仅挑战级这一座位的候选碰杠可选决策不同。

| 离线策略标识 | 修改 | 不修改 |
|---|---|---|
| `baseline` | 无，正式挑战级当前原始行为 | 原策略全部 |
| `no_tie_peng` | 如果原挑战级决定碰牌，但精确四川向听比较发现碰+合法切牌**没有降低向听**，改为 pass | 进张决定普通切牌、真降向听的碰、明杠、自身暗杠补杠、合法胡牌 |
| `no_kong` | 如果原本在弃牌响应中明杠则 pass；在自己轮到出牌时，主动暗杠和补杠均不执行 | 进张决定普通切牌、原挑战级碰牌、合法胡牌 |

本轮不是上线新AI；两项消融是为检验因果机制的**固定干预定义**，不声称永远不杠、少碰一定更强。

## 可复核的公开场况类型

`CallKongResearchAgent` 只记**粗粒度场况分类**，不收集候选具体牌、其他三家暗手、未来墙牌、真实牌墙、自己的暗手或私有随机种子：

- 触发类型（公开弃牌碰杠窗口、自己可选择杠牌窗口）
- 对照动作类型（碰、明杠、暗杠、补杠）和消融后的动作类型
- 墙牌数量阶段：早期、后期、最后阶段
- 本座公开副露数量、其他座位已经副露的人数和还未胡牌的对手数

每个被干预的动作计入正式聚合计数；展示用的例子最多保留12种类别，**并非可重现私人牌序的牌谱**，也不代表独立样本量。没有干预时例子为空，不能人为填入“成功案例”。完整对局的净积分和赢家来自正式状态机，跟场况类别的相关性不得直接解释为某次碰杠的收益因果效应。

## 固定的配对与独立保留组

默认预先固定开发种子12000—12001和保留种子13000—13001。每组2个独立随机洗牌种子、各四席轮换，且每个座位在**相同初始牌堆**分别运行三种冻结策略，合计 **16组初始牌局位置×3种策略＝48局完整实战模拟**。

- 包含108张物理牌守恒、胡牌/杠钱/流局方案A完整计分，验证三本权威零和账册且逐席 **总净分=胡牌分+杠钱分+流局分**。
- 主要指标是按独立种子先做四席平均，再按组均值汇总的**挑战级正式净积分差**。
- 次要指标是胡牌得分、杠钱分、流局分、胡牌事件、点炮事件、生效杠数；机会与干预次数是覆盖统计，**不是收益样本**。
- 每组仅2个独立种子时不构造表面精确的95%置信区间，字段明确返回 `null`。若要估算置信区间，必须另外预注册至少8个**新**种子，再整种子聚类统计。
- 干预后摸牌顺序、碰杠与尾墙路径可不同；只保证初始牌堆、座位和非干预的决策**策略**相同，而非整个轨迹相同。

## 研究边界

本研究检验两个保守的**具体策略假设**，而不是通过挑选对自己有利的种子或场况宣称 AI 更强。若干预次数为0，必须输出“没有检验到该机制”，不称策略等价。若净积分升降不一致，仅表示在这些种子中有不同结果，不能直接上线改动。只有足够独立的种子、稳定的收益与牌局安全核验之后，才可考虑对线上挑战级做受控的策略升级。

### 真实结算归因限制

开发组 `no_tie_peng` 的正向净积分差 +37.5 来自种子12000，其四座位平均胡牌净入账差 +75，点炮事件四座位平均差 -0.25；但**另一组真正独立保留种子未发生任何被改变的碰牌决策**，所以不能称为外部验证成功。

开发组 `no_kong` 的 -75.375 源自种子12001（-150.75），涉及胡牌净额 -200、杠钱净额 -0.75、流局净额 +50 的四席平均变化；保留组来自13001（-25.5），包括胡牌净额 -25 和杠钱净额 -0.5。它们是两次**取消明杠后的整局结算差**，不是可以独立归因给那一张明杠的即时损益。

虽然 `no_kong` 控制确实经过开发组的8个自身可杠窗口，但该实验轨迹中原挑战级在这些窗口并没有选择暗杠或补杠，因此**并无一次真正抑制自身杠动作**。绝不能把自身可杠机会和实际取消动作混为一谈。

本批每组只有2个独立初始牌堆种子，程序正确地输出 `interval_95pct=null`，**没有**人为生成看似精确的置信区间。代码与工作流没有修改线上挑战级碰杠行为。下一轮若研究自身杠收益，应先确认真实策略执行暗杠/补杠的足够样本，另用未筛选的种子独立检验，不允许把定向寻找高频杠牌场景当作总体净积分估计。
