# M3.43：暗杠翻牌与语音播报一致性（v0.55）

承接 M3.42 的「三张盖牌＋一张公开翻牌」显示规则。现在语音也应当只针对已经**真实公开**的那张翻牌报出牌种。

- 新暗杠：例如1号AI暗杠后，牌桌翻出一张七筒，语音说「1号暗杠七筒」。其他三张仍是牌背。
- 旧历史和未授权事件：若无正式公开标志，即使有人伪造了 `publicTile` 也只能说「暗杠」，不能宣读藏牌。
- 杠后补摸仍然只更新真实牌山／手牌数量，绝不说补摸具体牌种。
- 普通打牌继续**只念牌名**，不添加出牌人身份前缀；碰杠胡其他播报照旧。
- 播报由原先的显示→语音 Promise 门控执行，仍须声音与最低画面时间都结束才执行下一家，关闭语音仍能立即进入下一回合。
- 牌种名称使用固定的1至9与万／条／筒映射，拒绝非法牌种。前端只通过 M3.42 公共播放白名单给语音传递 `exposedKong=true`，不信任原始内部事件与历史未公开字段。

新增回归：无标记不能报牌、已标记可报一张、非法字符串绝不报牌、复合暗杠＋尾摸只报公开暗杠；实时播放分组保留已经验证的翻牌标记，牌背、个人手牌和牌墙不泄露。
