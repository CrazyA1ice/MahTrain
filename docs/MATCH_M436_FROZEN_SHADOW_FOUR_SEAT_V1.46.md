# M4.36：冻结离线训练权重与正式挑战级AI开展独立四座位实战（v1.46）

## 从已有研究走向真正的对局验证

上一轮M4.35已合并 main。用户在Windows本机完成M4.34：4个原始自然洗牌种子、4场自然对局和16场真实动作分支，总共20场完整结算。M4.35保留训练组中两个条件化未来墙积分差不一致的合法样本，利用有限幅度收缩做离线模型。**这些回报只能描述同一原始洗牌及固定对手暗手下的两个不同未来牌墙排序；不能宣称算法已变强。**

这轮M4.36才首次让冻结的离线模型作为**仅供独立实战对照的候选动作排序器**加入真正的完整四人牌局，与未改动的 MahjongAgent("challenge") 在全新随机种子下对比官方净分。

## 技术边界与评分口径

1. **冻结训练权重**。读M4.35产生的 PRIVATE_uncertainty_offline_model.json，严格核查模型协议、权重数量、每维上下界、模型不允许上线标志；重新从M4.34私有训练原始洗牌分片拟合一次，并要求精确一致。**此步骤只用训练集分片**，绝不读取留出真值调优权重。
2. **防数据泄漏**。新的评估 seed-start 和种子数不能与旧M4.34的**整个训练及留出原始种子区间**相交；重复或交集一律报错。候选AI在每一步也只能收到引擎正常授予本家合法 private_view；**不会收到真实未知未来牌墙、对手暗手或离线评价答案**。
3. **四人对局一律真实完整运行**。每个新的独立原始洗牌种子总共跑五场：一场四名正常挑战级AI原策略基准局；另四场分别把0号、1号、2号、3号位置的一名挑战级替换成冻结离线候选，其余三人仍为原始挑战级AI。所有座位沿用完全相同的起手牌生成种子，分别打到第三名胡牌或流局，按原官方胡牌、杠钱及查花猪/查大叫账本记净分。
4. **只修改合法同向听切牌选择，不触动其他行动**。换三张、定缺、吃（不允许）、碰、杠、胡依旧原挑战级AI；先获得原挑战AI的合法切牌结果，在同最小向听数的候选合法弃牌中，对比M4.35冻结模型的自身三维牌效特征差。模型建议的收益分数严格超过原策略才改变这一次弃牌；无合法备选、模型无训练权重或分差为零时总是保留原策略。旧挑战级AI本身及所有线上 difficulty 配置不变。
5. **统计独立性**。同一原始洗牌生成的五场对局具有强烈相关性；它们合计只算**一个**独立洗牌簇。统计每个座位候选局相对原对局同座位的真实净分差，并按四个座位平均后得到该原始洗牌簇的配对指标。再按不同独立自然种子簇聚合，减少单一发牌位置的混杂。若候选策略未产生真实切牌改动，应报出零改动、零真实差异，不能宣称更强。
6. **严格结论边界**。单一实验种子只提供五个相关对局，不能报告胜率显著提升。20个种子也只是展示探索性趋势的最低报告门槛而非充分证据。本研究暂不支持真实策略自动晋升，仍需独立重复、稳健性、不同基线、足够种子和明确的统计检验。

## Windows 本地运行

若已合并main，可直接：

~~~powershell
cd D:\ChatGPT\MahTrain
git switch main
git pull --ff-only origin main
~~~

**第一步：冻结你已有 M4.34 批次的模型**。如果之前已经执行 M4.35，则不用重复；未执行可用：

~~~powershell
python examples\run_local_uncertainty_analysis.py --out-dir data/selfplay/m434-smoke
~~~

**第二步：用全新种子做真实四座位对比**，先从2个独立新种子开始：

~~~powershell
python examples\run_local_shadow_headtohead.py --train-dir data/selfplay/m434-smoke --seed-start 90100 --seeds 2 --out-dir data/selfplay/m436-shadow-2seeds
~~~

它将真实运行2组×(1基准+4个候选座位)=10场完整四人四川血战对局，**不会修改旧M4.34的已经采集好的牌局及标签**。

输出：

| 文件 | 用途 | 私有性 |
|---|---|---|
| PRIVATE_frozen_benchmark_plan.json | 原训练目录、冻结权重哈希与新评估种子 | 只留本机 |
| PRIVATE_four_seat_paired_matches.jsonl.gz | 每个新原始洗牌下五场真实对局的官方积分对照、每座位候选选择改动次数 | 只留本机 |
| safe_four_seat_shadow_summary.json | 公开安全聚合：独立评估簇数、真实完整结算局数、四座位平均净分差、候选改动次数、样本不足标志 | 可供结果验收 |

**不使用已有训练/留出种子区间作为新评估集**。示例 90100 是与烟雾训练计划 89800..89803 不重叠的新种子。如果 M4.34 训练来自其他范围，必须将评估范围调整为完全不重叠。不同批次请更换输出目录：当前程序若发现输出目录已有文件，会拒绝覆盖，以免错误比较前后模型。

较大规模示例：把 --seeds 调到20，输出改为新的目录。20个独立种子将实际完成100场四人完整对局；它们仍然不能保证检验具有统计显著性。尚未实际运行该规模，注意CPU资源。实验上限100个新原始种子，每种子5场真实完整对局。

## 为什么仍未把模型接入正式AI

即使得到了某组正向真实净分差，仍有小样本波动、不同位置、相同原始种子的相关性、有限特征与训练世界范围不充分等限制；**未经多轮冻结外部验证，不自动替换线上强度**。本轮的研究贡献是终于引入可以实测的、可独立复现的真实四座位闭环对抗平台，而不是直接宣布完成“更强AI”。
