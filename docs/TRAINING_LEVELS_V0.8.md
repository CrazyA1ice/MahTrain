# MahTrain M2.6：四种单题统一网页与三档结构难度

> 本页为 **单题训练引擎 / 网页版本 v0.8**。四川血战规则仍使用独立的 v0.4 规则草案（未发布正式对战计分）。14轮连续训练、单人暗杠、历史 SQLite 和错题重练功能继续保留。

## 一、已接入网页的四种训练模式

| 模式 | 出题形式 | 判题原则 |
| --- | --- | --- |
| 一向听何切 | 14张手牌点击切牌 | 必须切后最小向听恰好1，在不退向听层级最大化有效进张，全部并列切法有效 |
| 听牌何切 | 14张手牌点击切牌 | 切后向听0，按有效待胡牌张数确定最优，全部并列有效 |
| 清一色选听口 | 13张同花色手牌，多选所有可胡牌种 | 必须选全完整听口集合，漏选/多选单独提示 |
| 清一色何切/识别已胡 | 14张同花色手牌，点击切牌或确认胡牌 | 已成胡牌时应胡；否则采用同向听层最大有效进张的局部最优切 |

网页继续使用原始完整麻将牌图 `assets/tiles/640x420.jpeg`（不是重新生成的矢量麻将图），花色按万→条→筒归组，内部1→9升序。

## 二、结构难度：基础 / 进阶 / 挑战

`src/mahtrain_core/training_levels.py` 构造目标牌形：

- **基础 basic**：仍保留旧版的刻子、孤张、简单清一色题形作为入门内容，也确保老接口调用不会被新难度强制改变。
- **进阶 intermediate**：更多使用实际顺子、相邻双搭子竞争、两面听、边张听和嵌张听。
- **挑战 challenge**：在顺子/搭子与多类待牌结构之外增加七对听牌与七对竞争等13张构造，适当提升结构辨识复杂度。

生成过程**不是单纯给随机牌标注难度**：先构造13张候选，必要时抽取第14张，再严格通过既有 `shanten_13()`、`winning_tiles()`、`is_legal_win()` 以及全部可切牌的向听分类检验，确认一向听/听牌模式真实满足目标层级；不合格则重新生成。所有牌种物理数量最多4张，胡牌必须满足定缺。

“难度”目前仅基于**题目来源结构和预设生成组合**，尚未实测人类难度分布，也没有依据用户正确率自动升级。尤其一副牌可能出现其他胡牌解释或额外听口，标准答案始终以原胡牌/牌效算法为准，而不是强行以模板中的某个等待形态认定正确答案。

## 三、答案隔离与接口

- `POST /api/action` 的 `quiz_new` 接受服务端校验的 `mode` 和 `difficulty`。服务器随机生成私有题目种子，记录会话令牌，仅把不含种子与标准答案的公开题目发给浏览器。
- `quiz_answer` 必须传题目对应随机令牌和真实候选答案；服务器重新用保存的模式、难度与私有种子生成题目并核验原题号，评分后才返回最佳切牌、正确听口、牌效与题形解释。
- 题目只允许**成功提交一次**；重复提交或试图选择手中不存在的牌会被拒绝。非法请求不消耗该题。
- 清一色多选必须完整匹配；单张切牌全部并列最优都算正确。
- 训练页不直接访问隐藏的私有种子、牌墙、完整答案；浏览器提交的是用户选择而不是自报得分。
- 当前单题会话仍然只保留在本机 Python 服务内存，**本次尚未将单题做对/做错入库 SQLite**，历史记录系统目前仍专门归档完成的14轮连续训练。

## 四、体验方式

```bash
git pull origin main
python web_server.py
```

打开 `http://127.0.0.1:8765`，在页面顶部的 **“单题训练中心”** 选择四种模式、基础/进阶/挑战，然后点击“生成训练题”。按牌面选择切牌；对于清一色听口题，点击每一种听口牌面，可以多选或取消。点击“提交本题答案”后看到解析，再生成下一题。

命令行继续支持原模式与新难度：

```bash
python examples/training_quiz.py --mode one_shanten --difficulty intermediate --seed 9
python examples/training_quiz.py --mode tenpai_discard --difficulty challenge --seed 42
python examples/training_quiz.py --mode pure_suit_waits --difficulty challenge --seed 12
python examples/training_quiz.py --mode pure_suit_discard --difficulty basic --seed 0
```

自动测试：

```bash
python -m unittest discover -s tests -v
```

测试覆盖3个难度×4种模式的可重复性、实体牌4张上限、真实向听分类、胡牌合法性、并列答案、旧接口兼容、篡改难度ID、HTTP私有种子及一次性提交限制，并继续运行原先所有单人14轮、SQLite、暗杠和复盘测试。
