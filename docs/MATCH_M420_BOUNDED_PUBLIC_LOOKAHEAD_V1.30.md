# M4.20：基于公开牌的有限步摸切前瞻与完整积分配对实验（v1.30）

## 研究目标

M4.19（[PR #119](https://github.com/CrazyA1ice/MahTrain/pull/119)）在16个独立自然洗牌、64场原Challenge比赛中发现：143次一向听多切选择里，143次原选都有并列最多的公开未知有效进张，143次处于有效张数／原加权番值代理／公开风险的三目标Pareto前沿。故单纯寻找更多当前有效张数的M4.18候选完全无法触发，但不代表原AI在后续摸牌、下一轮听牌质量和整局收益上已最佳。

本轮增加**最多一次未来假设摸牌和一次假设再切牌**的离线研究算法：给定当前真实合法14张本家牌和公开记录，比较原挑战级首选与一张经过预筛的合法等一向听替代牌；对每一候选，在原13张状态枚举少量「尚未公开的可能有效摸牌种类」，模拟这些牌被摸入后最佳合法切牌，再计算该假设13张听牌的合法可能胡牌张数及由**原规则** `score_win` 确定的番值倍率。不知道真实墙尾，也不读取他人暗手。额外支出须限定、测量并报告。

**这是截断的两步代理，不是两巡真实搜索、上听/胡牌概率或可兑现查大叫现金预测**：样本分支未覆盖所有不利摸牌；第二次假设切牌忽略期间其他玩家反应及点炮风险，所得是乐观的结构性下界/上界都不能严格宣称，只可按相同预算比较预定义候选。完整真实收益仍由两臂相同洗牌的最终胡／杠／流局账本核验。

## 冻结计算预算与决策门槛

- 原挑战级算法先以 `MahjongAgent('challenge').discard(view)` 确定合法最低向听切牌及 `_last_discard_scores`。只对**严格一向听且至少两种合法等向听切牌**执行研究。
- 当前公开牌墙至少 **12张**；核实天听保持原动作。备选为原已经计算、按原挑战评分排序中第一个同时满足有效张数保留≥**70%**、公开风险指数增幅≤**0.12**的其它合法切牌。
- 每次最多展开 **2种首切（原选与一张备选）×各6类有效摸牌**，有效牌类型按当下公众未知副本数由大到小、牌序稳定排序；不能对数据评估后再挑分支。所有分支仅是手牌结构上的**假设牌**，不读取真实未来牌墙。每条分支中的第二次切牌遵守定缺优先，计算规则层精确向听，只有可达到零向听时才按该假设听牌的公开未知胡牌副本数×官方有效番值倍率计分。
- 分支代理为上述有限分支的「第一摸未知副本数 × 假设第二摸可能胡牌副本数×倍率」合计，**尚未归一化成可校准的两步概率**。只有备选数值相对原选至少 **1.12倍**，且两边代理均正，才允许离线候选不同切牌。
- 每个自然对局中该座位最多研究 **2个一向听多候选窗口**；超过预算不计算且保留原动作。原策略对照臂执行同样诊断，但其实际切牌绝不替换；这样可对照评估开销。
- 附带记录：展开过的首切数量、可能摸牌类型分支数、假设第二切枚举数量、本人离线计算总毫秒及最大单次毫秒、最终真实改切数、覆盖多少独立洗牌种子。不会上传原暗手、对手暗手、未来牌墙或完整对局动作轨迹。

本轮算法并**没有**进行任何全局真实对局概率采样。时间测量仅来自GitHub CI执行环境，用于发现爆炸性成本，不是用户本机性能承诺。即使研究候选达成更高代理，也不等于能更早听牌或赢得更高现金。

## 预注册真实自然配对

选择此前 M4.14～M4.19 **未使用的洗牌序号**：开发组 60000–60002、独立保留组 61000–61002。每组3个独立洗牌×4座位轮换×2臂=**24场完整真实四川血战比赛**，合计6个独立洗牌、48场108实体牌真实对局。数量小，主要是验证分支计算开销、合法性、真实触发以及有无明显负收益；**不能据此直接上线、宣称统计胜率改善**。

完整每场按原状态机结算：`official_net = win_points + kong_points + exhaustive_points`，不得只看胡牌或只看局部切牌评分。某位置从未真实改切时必须保证原策略与研究臂完整动作轨迹、公开事件、所有正式账目和终局阶段完全一致。允许行动分叉后现金变化，但仅是完整路径的描述，不把收益归因于单个切牌。

若候选过于频繁或消耗不可接受、两组方向相反、没有足够独立干预或者净积分不足，不引入正式 AI，只保留通过测试的实验代码。即使两组均有正收益，至少还需要更大未调参独立组和线上性能保障才可考虑部署。

## 文件及核验

- `src/mahtrain_core/ai_bounded_public_lookahead_paired.py`：严格受限的两次摸切代理、原Challenge离线双臂对照、复杂度与权威分账汇总。
- `tests/test_m420_bounded_public_lookahead.py`：门槛、天听与短墙跳过、违法源排名拒绝、有效实体牌权重、假设第二切按官方积分计价、资源预算限制、真实108张对局回归、匿名性与独立洗牌聚合。
- `examples/audit_bounded_public_lookahead_paired.py`：按两组出具官方净分和开销的匿名JSON复现工具。
- `.github/workflows/m420-bounded-public-lookahead.yml`：新增单测+M4.19回归，以及开发组与独立保留组各24场完整真实配对；必须与整个仓库Python3.11/3.13和Web浏览器回归全部通过后才合并离线研究代码。
