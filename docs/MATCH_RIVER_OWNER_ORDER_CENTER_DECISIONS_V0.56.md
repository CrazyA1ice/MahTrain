# M3.44：牌河按各家视角排牌、大牌背与桌面中央碰杠提示（v0.56）

## 用户反馈及本轮修复

上轮 M3.42 只修正了左右家手牌、牌背及单张牌面的视觉朝向，**左右两侧牌河仍按常规横向行序**，并不符合玩家从各自位置观察的左右方向。本轮单独纠正牌河的真实时间顺序：

- **屏幕左侧（3号上家）牌河：** 第一张位于上方，之后按时间 **从上往下**，每列至多8张；第9张进入下一列，依此类推。
- **屏幕右侧（1号下家）牌河：** 第一张位于下方，之后按时间 **从下往上**，每列至多8张。列与列从右向左推进，符合右家的自家视角。
- 两侧都继续让牌面文字朝各家自己的座位；使用真实规则公开弃牌序列，不重排服务端记录，不重复已经被碰走的麻将。最后一张的外框高亮、摸切/手切标签和已被取走提示仍与真实对应牌匹配。
- 上下家牌河维持原来的横向时间顺序。**桌面优先**；窄屏仍使用既有紧凑网格。

## 默认统一放大

删除旧的“放大手牌”按钮及相关状态；三个 AI 的牌背尺寸默认直接放大（上家/下家牌背同一套固定大规格；对家同样放大）。四个方向的牌河也统一使用较大的图案。桌面同时为更大牌面预留空间，使牌河换列而不是内部出现滚动条。

## 牌桌中央碰杠响应

新增 `#match-decision`，放在真实麻将牌桌中心的交互浮层，容纳：

- 他家打牌后，我方有资格选择的胡、明杠、碰、过；
- 他家补杠后，我方可选抢杠胡、过；
- 自己回合可以主动选择的暗杠、补杠。

操作响应都使用同一风格的大按钮；胡牌优先、过牌弱化。无需到牌桌下面寻找碰杠按钮。按钮保留原 `match_claim`、`match_rob`、`match_kong` 请求语义和服务端资格检验；自己暗杠仍有原有确认对话框。没有可选操作时浮层立即隐藏，普通打牌和换三张的控制流程不变。AI 的动画提示仍独立存在，播放与语音门控保持不变。

## 验收和边界

本轮没有变更规则、胡牌判定、暗杠三盖一翻、计分或 AI 决策。公共牌河的每一张始终对应真实出牌事件，自动回放可按公开时序核对。测试覆盖左右各17张时分为8/8/1三列、原始次序、最新牌高亮、真人碰杠胡点击实际 API 请求、固定大牌面的样式标记以及移除尺寸按钮。真实浏览器的视觉可读性和布局仍需桌面验收。
