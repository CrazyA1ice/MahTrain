# M3.59：冻结点炮风险模型、跨策略迁移和配对真实净分实验

## 任务与之前结论

M3.57–M3.58 的候选牌点炮研究标注真实暗手，但预测只能用公开信息。M3.58 8 个训练洗牌种子、6 个独立测试种子中，训练1046行（14次正例），测试676行（5次正例）。Brier 从0.00738686变为0.00733107，聚类重抽描述区间[-0.00011013,+0.00000783]包含零；**不能证明稳定泛化**，更不能证明真实胜率上升。

本轮尝试解决两个更接近目标的问题：一是固定模型参数后能否迁移到**不参与训练的不同AI策略家族**；二是这种风险信息真的改变出牌后，能否提升完整四人血战的**正式净积分**。

## 数据隔离与真值

- 训练：独立洗牌种子使用默认四人自对局，`collect_ron_labels` 由可信模拟器在出牌前标注每个合法弃牌×每个活跃对手的立即点炮真值与倍率。对手真实暗手仅存在于离线标签函数。
- 一次性拟合：`fit_ron_model` 依训练数据计算带L2约束的十五维公开特征参数。参数只在本次离线Python进程中保留，报告仅导出16位SHA256摘要，**不导出参数/行级样本/真实其他三家暗手**。
- 跨策略：单独的全新洗牌种子运行两种策略家族——`challenge+advanced+basic+baseline` 与 `challenge_no_pressure+advanced+basic+baseline`；两者均只用于衡量此前已冻结模型的 Brier、log loss、真实点炮正例数和真实立即点炮倍率 MSE，绝不在测试种子上重新拟合/调阈值。
- 点炮基线：训练数据的合法花色平滑平均点炮率；目标定缺花色则依法直接置0。新模型也遵循相同规则硬约束。
- 由于本轮使用不同的策略家族和独立牌序，单局重复候选牌仍高度相关；聚类自助法只整组重抽**独立洗牌种子**，不把逐切牌的行数视为独立样本。

## 冻结研究策略 vs 原版挑战 AI

**在线挑战 AI 不改。** 仅 M3.59 可信离线脚本使用`FrozenRonResearchAgent`：先调用正常的挑战 AI 获取已经遵守合法切牌、最少向听、进张和番数规则的候选排序，再对这些合法的同向听切牌分别用公开信息逻辑回归估算候选立即点炮倾向。防守附加惩罚是有限函数：

```
expect_loss(tile) = sum_over_active_opponents(
    P_frozen(ron_for_that_tile | public_information) *
    mean_positive_win_multiplier_in_train
)
extra_penalty(tile) = min(0.12, 1.8 * expect_loss(tile))
experimental_score(tile) = existing_challenge_score(tile) * (1-extra_penalty)
```

- 惩罚最多12%；不能打破最小向听合法候选集，不能用真值标签预测未来、不能偷读实际暗手或牌墙；实验取的都是同一次训练冻结的权重。
- 所有其他动作（换三张、定缺、碰、杠、自摸胡牌、抢杠响应）仍沿用正式挑战 AI。单次抉择是否真正改变、是否点炮由实际演化出来的完整对局衡量，而非离线“不打出此张会怎样”的虚构单步反事实。
- 为了在随机扰动决策后比较**正确净积分账本**，离线配对比赛显式开启`kong_base=1`，记录 `official_settled_balances`（胡牌支付、明暗杠支付、可能的流局结算）；严格校验每局**四家和为0**、真实108张牌完整，流局时结算必须已入账。旧训练/公开模拟仍保持原参数，不改变任何已有前端行为。
- 每一轮种子做4个座位轮转，让研究中的挑战 AI 依次占据4个座位。每个完全相同的洗牌种子、轮转阵容分别执行基线与实验，比较**真实正式净积分**、被点炮来源次数、胡牌次数以及实验切牌变化次数。同种子但分歧后的牌局发展会改变，因此这是共享初始牌序的配对策略实验，不是强行假定之后每一巡都拥有“同样手牌”。
- 最终每一个洗牌种子把四座位轮转的净分差合为一个聚类单元，并作一个简单的有放回自助法区间。两种子的初次CI只是**链路冒烟测试**，绝不能作为显著性、因果效果或强度排名依据。

## 为什么不直接上线

M3.58 的测试仅5个正例，且区间跨零；对不同策略以及不重叠洗牌种子的泛化能力仍未知。M3.59 即使出现一个“正净分”，也必须进一步至少以几十上百**独立洗牌种子**和不同策略进行多次外推测试，验证完整净分、赢牌率、放铳、杠钱结算与决策耗时的变化，再决定是否允许研究策略成为玩家可选择的实验选项。

**不能将每张候选切牌的离线风险分数称为已校准真实点炮概率，不能将两次完整对局的平均净分差直接等同于稳定胜率优势。**

## 命令

```bash
python -m unittest discover -s tests -p 'test_ai_ron_frozen_experiment.py' -v
python examples/evaluate_frozen_ron_policy.py --seed-start 140 --train-seeds 6 --cross-seeds 2 --paired-seeds 2 --stride 3 --json-out /tmp/mahtrain-m359.json
```

CI 默认6个训练种子、2个独立跨策略测试种子、2个独立配对对局种子（每种子4个座位轮转×对照/实验各一局），真正的独立统计单元只有2个配对种子。本轮没有变更正式挑战AI的线上决策，也不发布在浏览器的概率分数。
