# M4.48：冻结首次可碰却过的两世界真实结算分支，并在24个新洗牌上复验

## 证据与问题

用户上传M4.47安全结果：8个独立自然洗牌，8场原Challenge完整四人基准；每个种子均在首次合法可碰却原AI选择过时找到1个检查点，2组未来墙、16组碰与过成对结果、32场完整终局分支，总计40场真实对局。16组碰牌都被规则实际接受，未被其他人响应优先级盖过。平均按原始shuffle簇计算，强制碰牌比原挑战级过牌净收益+20分（win+18.75、kong+1.25、exhaustive 0），但是**仅3个shuffle碰有利、3个shuffle过有利、2个相等**。2组未来墙不相互独立，8个shuffle不足以确认稳定优势或全局改碰规则的平均效果。

因此不在这8个shuffle上重拟合或挑选最有利的碰牌条件，而是冻结M4.47第一合法机会、正常Challenge选择pass、实际合法peng以及两未来墙真实完整对局的选样和终局流程。在后续**24个完全新的自然原shuffle**上原样复验。无新AI模型、无阈值选择、线上Challenge一行不改。原隐藏状态只用于完整规则引擎仿真，不作为AI额外输入。

## 固定方法与检验

每个新seed完成1场自然四人挑战级基准比赛。只研究该原局中首次发现的合法可碰却挑战级选择过牌的行动（如果没有该局面，保留无机会计数；不寻找第二次或按收益挑最有利机会）。找到了则从同一已实现游戏和四家AI当前完整随机状态复制，分别在世界0原未来墙和世界1固定排列的剩余牌墙中，完整打完强制pass与peng两个版本。

世界0的pass分支每个座位的胡牌/杠钱/流局/总净分必须与自然基准结算逐项完全一致，否则直接失败。两世界共享同一首个响应前状态；如果强制peng未真正被采纳，则计入其他合法优先响应而不是假定一定碰成功。每个原shuffle最多1基准+4真实终局分支，所以24seed最多120场真实终局。**统计独立单位始终是24个原shuffle**，不是最多48组世界，也不是96场分支。

新安全JSON给出每簇的平均碰减过净积分再次平均、胡杠流局分项、正负零独立簇数量、有资格碰的簇数量、两世界收益方向一致与不一致簇数量、原Challenge首次碰机会发生在哪个座次的合计分布、整体净分中位数，以及固定随机种子448、4096次独立原shuffle簇重抽样的描述性95%均值百分位区间。这并非未知隐藏世界的无偏方差估计或正式统计显著性判断；世界只有两个固定构造。

## 数据核验与续跑

运行前必须先从M4.34训练数据取得来源指纹、读取M4.47原试验私有计划和8个完整原seed结果SHA-256分片，重新计算M4.47安全摘要并与保存结果比对，要求对应M4.47源代码摘要仍一致。然后沿M4.46完整20seed证据、M4.45证据、M4.37/39/41/42/43/44原计划逐一核验来源和种子范围，禁止与这些旧评估及训练种子相交。新实验在私人计划中冻结24个新seed范围、M4.47源码SHA、两未来墙及固定重抽样参数。

每个seed所有分支完全结算后才将该原shuffle保存为原子私有SHA检查点。使用--resume只复用完整、结构和摘要均校验通过的簇，不复用未结算的部分游戏，且拒绝变更计划、seed、来源目录和策略代码。

## 证据限度及下一步

此轮要检验的是初次自然出现的可碰却过局面，在已实现的局势和两种有限未来安排下，改变响应可能造成的整局积分差方向是否稳定。就算新24seed均值正向，也不能直接称在线AI变强；更不能以后测试表现反过来挑参数，在同一批样本上声明泛化。若负面或强烈不稳定，应保留原Challenge碰牌机制，优先研究行动者可见的更可靠风险状态，并另设独立训练与确认集。

CI专项测试会以模拟结算结构测试新24seed数据合约和恢复机制，**不代表云端已经真的完成120场麻将**。真实分支引擎由M4.47实战四分支集成测试验收，正式结果以用户本机的新24原shuffle运行结果为准。
