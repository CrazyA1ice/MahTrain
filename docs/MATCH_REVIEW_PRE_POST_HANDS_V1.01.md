# M3.91 · 历史复盘出牌前／动作后真实手牌对照

## 问题

M3.88–M3.90 的服务端已保存每个动作的 `hands_before` 与 `hands_after`。历史复盘原先始终渲染动作后四家手牌；但每巡前三切牌和玩家实际选择的名次是按**出牌前**0号手牌、该时刻的公开牌信息计算。出牌后已经少一张牌的画面，会让使用者无法核对评分依据。

## 改动

1. 对保存了双时刻手牌的已完成牌局，增加「动作前手牌／动作后手牌」切换。逐巡切牌动作默认显示出牌前四家真实手牌；其他动作默认显示动作后。选中另一历史步骤或从逐巡列表跳转时恢复自动默认，不沿用上一步的状态。
2. 显示的暗手数量跟随当前选择的手牌快照，不再将动作后的公开 `hand_counts` 标在动作前手牌上。0号玩家实际切出的*牌型*在出牌前手牌中高亮；若同一种牌存在多个副本，会一起高亮，不伪装成能够辨认是哪一张实体牌。
3. 牌河、副露、已胡标记和牌山数依旧来自已保存的**动作后公开快照**，页面明确提示两个时刻不同，不将后验公开状态伪装成出牌前状态。
4. 缺少 `hands_before` 的旧终局记录，不伪造出牌前手牌：仅能显示动作后手牌和缺失说明；纯公开版旧档案继续只显示牌背。
5. 不修改对局中的私牌可见性、AI 评分/出牌行为、正式结算、数据库字段、历史存储结构或实时 API。

## 测试

`node --test tests/test_match_archive_dom.js` 覆盖：
- 使用不同的实际动作前后手牌，检查切牌复盘默认显示评分所使用的动作前真实手牌；
- 检查0号实际切牌牌型高亮、手牌数量与前后切换、公开快照时刻的文字提示；
- 从逐巡切牌列表跳转时恢复默认时刻；
- 老档案仅含 `hands_after` 时展示降级提示，不误称为前态；
- 保持原 M3.88–M3.90 的全历史周期、评分与复盘导航断言。

可连带运行 `node --test tests/test_match_playback.js tests/test_match_cut_quality.js tests/test_match_stats_dom.js`。所有前后快照只存在已完成终局的 `terminal_review`；当前对局客户端不会请求或获得对手真实手牌。
