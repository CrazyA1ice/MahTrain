# M3.47：首页返回对局、独立训练历史与战绩自动刷新（v0.59）

## 更新内容

1. 首页从五个入口扩展到六个：新增 **训练历史与错题本**，连续摸切训练保留开始训练及本轮解析，不再把大量历史记录混在同一模块。
2. 已有人机对战界面时，从对战返回首页会在对战卡片显示「已有对局界面，点击继续查看」。进入训练、历史、实验室等模块只是隐藏相应面板，**不会重新执行 match_new 或清空现有 JS 对局状态**；再点对战入口直接查看当前对局。注意：这只是同一页面内的状态保留，**浏览器刷新和服务端重启后的对局恢复还未实现**。
3. 从其他模块重新进入 **人机对战历史战绩** 时，主动读取最新本地 SQLite 历史汇总与分组统计，图表不用手动按刷新。训练历史也在重新进入时刷新。第一次加载仍交给各模块原有 init，避免重复首屏请求。
4. 修复快速切换带来的异步乱序：较早发出的战绩请求即使更晚返回，也不能把较新的战绩图表、档案列表或错误提示覆盖。
5. 井号路由只在真正切换模块时刷新历史；用户点击入口设置 Hash 后，浏览器自身的 hashchange 不会二次请求。导航不修改四人公开规则、手牌、胡牌结算、回放或 AI 决策。

## 图表验收

所有指标仍直接来自 `/api/match_archives` 的核验后 `scorecard`：
- 无历史档案显示清晰的空数据提示；
- 恰好一局时折线是一个有效数据点；
- 最多30局时累计积分曲线上的每个点对应服务器提供的一局，坐标有限且不混入未来或隐私数据；
- 已结束的新一局通过战绩模块重新进入便刷新折线及单局正负收益分布；
- 多次刷新返回顺序颠倒时，只认最后一次请求。

完整规则和 AI 回归需在 GitHub CI 中验证；此外仍建议在真实电脑浏览器亲自操作「开局→首页→战绩→对战」确认手牌和交互没有变化。

```bash
node tests/test_module_navigation.js
node tests/test_match_archive_dom.js
node tests/test_match_stats_dom.js
python -m unittest discover -s tests -v
```
