# MahTrain 单人训练 v0.6 — 错题重练

> 当前项目：单人连续14轮摸切、已完成回合复盘、错题重练。四人换三张/碰明杠补杠和三档AI仍未开发。四川血战规则文件仍是独立的v0.4草案（`enabled=false`），本说明的v0.6仅是**训练界面版本**。

## 一、新增功能

在本地网页完成最多14轮摸切或合法胡牌提前结束后，向下滚动到“逐轮切牌复盘与牌效总结”下方的 **“错题重练 · 再做一次”**。

- 自动列出该次训练中**没有选择局部最优切**的回合，标明第几轮、重练次数和最近一次重练正误。
- 点击某轮“重练这一题”后，恢复当时的暗手牌、定缺花色、摸到的牌，以及该回合已有的暗杠区。继续使用仓库原始完整麻将牌面图和1→9升序理牌。
- 重新点击手牌切牌（当原回合放弃了合法胡牌时，也提供“确认胡牌”）；在此次重新提交前，题目接口**不会返回正确答案**，并临时隐藏原报告和上轮解析，减少直接抄答案的干扰。注意：首次练习已展示过的历史答案，本来就可能被用户记住；这是一项自我训练功能而不是考试防作弊机制。
- 提交后并排展示**首次选择**和**本次重练选择**，对比相应的切后向听数、有效进张枚数、下一摸概率，并列出原回合全部局部最优方案。
- 可以“再练一次”“下一道错题”或“返回报告”。重练统计显示共多少道、已重练多少道、最近一次答对多少道。
- 通过原回合已经计算并确认的分析结果评分，保证同一历史题在规则、已知公开牌和局部最优切标准不变的情况下得到相同标准答案（**并列最佳动作全部认可**）。

## 二、重练不会破坏原有训练

- 错题重练必须等本次连续训练**结束**后才开启；进行中的回合不能进入。
- 原训练的13/14张手牌、108张实体牌墙、补杠/暗杠记录、历史切牌和原正确率**完全不变**。
- 不会新摸一张牌，不消耗补牌，不会从牌墙作弊读取未来顺序。
- 只可选择该历史回合真正持有的暗手牌，原有杠区里的四张牌不能再打出。
- 原回合如果已提示可以胡而玩家选择过牌，重练题可选“确认胡牌”；不把“胡牌”当成没有合法胡牌时的自由切牌。
- 结果对照中，普通切牌按原回合的模型估算切后牌效；直接胡牌时没有“切后牌效”，使用“胡牌”显示。重新提交不改变原始训练报告。
- 所有重练尝试及最近一次正误仅保留在当前本地 Python 进程的可信内存中，**未实现账户和跨进程持久化**。关闭服务后无法恢复重练进度。

## 三、技术实现

| 文件 | 职责 |
| --- | --- |
| `src/mahtrain_core/retry.py` | 只从已完成的错误回合生成无答案题目，基于冻结的原回合局部最优切结果重新判分并记录重练尝试 |
| `src/mahtrain_core/session.py` | 保存每轮操作前的手牌、已锁定暗杠区和当时已可见弃牌，并提供 `retry_list()`、`retry_question(round)`、`retry_submit(round, tile)` |
| `web_server.py` | 可信服务端的 `retry_list`、`retry_question`、`retry_submit` JSON 操作 |
| `web/retry.js` | 错题列表、原始牌面重练、提交后初次与重练对照、下一道题导航 |
| `web/index.html`、`web/app.css`、`web/app.js` | 在原训练报告下方接入错题重练区域及布局 |

关键服务器行为：

```python
# 完整训练结束后
mistakes = game.retry_list()
question = game.retry_question(2)        # 仅回合2为错题时有效；不含标准答案
result = game.retry_submit(2, "m9")     # 当且仅当原第2轮实际持有m9或其他合法动作
# 直接和原历史记录比较；不会消耗牌墙或改变game.report()
```

前端的随机种子、候选手牌或者自称的最优答案都**不被信任**，调用仅接受当前会话随机令牌、已有的错误回合编号和行动牌种。

## 四、验证与运行

在仓库根目录执行：

```bash
git pull origin main
python -m unittest discover -s tests -v
python web_server.py
```

浏览器打开 `http://127.0.0.1:8765`。先“发牌预览 → 看牌定缺 → 连续14轮”，每一轮点击切牌。完成后页面底部可见“错题重练”。

回归测试：

- `tests/test_mistake_retry.py`：训练未结束禁止重练、非法行动、伪造编号、隐藏正确答案、并列最优重新计分、原成绩/牌墙无变化、暗杠锁定与已提示的胡牌。
- `tests/test_web_app.py`：通过真正的本地HTTP服务进行“结束错误回合 → 选择重练 → 提交错误答案 → 提交正确答案 → 对比原训练报告未变”的测试。
- GitHub Actions：Python 3.11、3.13 单元测试与网页JavaScript语法检查。

## 五、接下来

当前错题重练只复习**本次训练内**的错误动作，完成后可反复选择同一错题。下一步可以增加：

1. **跨次练习的错题本**（SQLite，记录每个匿名本地档案/训练会话的错题历史、原答、重练次数）。
2. 错题难度与类型归类：退向听、同向听少进张、放弃胡牌、定缺相关。
3. 四种独立单题训练与网页统一入口，并将其错题也接入同一重练系统。
