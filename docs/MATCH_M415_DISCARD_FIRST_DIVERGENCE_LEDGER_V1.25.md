# M4.15：M4.14 风险改切首次分歧与权威积分差异的终局复盘（v1.25）

## 实际研究结论的来历

M4.14 [PR #114](https://github.com/CrazyA1ice/MahTrain/pull/114) 已在 Python 3.11/3.13 与专项回归全部绿灯后合入主分支。固定原策略与“同向听，番值加权进张 ≥80%，有效进张 ≥85%，公开危险指数至少降低0.08”的候选，使用52000–52003和53000–53003共8个独立洗牌、64场完整对战。真实改切只有开发组3次、保留组2次；官方挑战级积分差分别为**−700**、**0**。

本轮不更改风险门槛或重新挑选种子，也不提出“成功”的新策略。本轮做一次**用同样的种子重跑已有结果的事后解释性复盘**。这是对既有数据的诊断，不是新的保留组验证，更不能将五次改切当作独立因果估计样本。

## 方法与审计边界

`FirstDivergenceAuditAgent` 扩展原 M4.14 离线代理，仍由原 `MahjongAgent("challenge")` 计算唯一一次已授权的真实排名，再由固定候选决定是否改切。只有在实际改切后才保留**不含牌种与暗手**的匿名数值快照：本家出牌次序、严格最小向听、牌墙阶段（早／晚／紧张）、当时公开威胁指数差（千分位整数）、原预测番值加权进张保留比例、有效进张保留比例。

在完整对局结束后，比较同一初始洗牌和相同座位的两组真实动作 `trace`，找到首次行动不一致的位置，严格核对：首次不同必须是本人`discard`、切出的牌真的不同、双方都是最小向听且零向听后悔值、首次改切对应实际第几次本人切牌。没有实际改切时，整个 `trace`、公开事件、两组各项官方终局结算和终局阶段必须**完全一致**。

完成对局后，只用原仓库 `_official_outcome` 从权威 `partial_win_balances`、`official_kong_balances`、`official_exhaustive_balances` 验算
`official_net = win_points + kong_points + exhaustive_points`，并记录胡牌事件差、放铳事件差、实际杠次数差。每个真正改切的“座位配对”输出首次切牌发生在哪一巡及当时合法公开牌效差，然后单独列出终局净分/胡牌/杠钱/流局分差。**不得把账面最大变化的项目解释成首次切牌直接造成的损失**，因为之后两条对局的摸牌消耗、他人应对、切牌乃至胡杠过程都会分叉。

临时参与比对的牌种、全部公开原始事件和完整动作轨迹不进入返回值、JSON归档或公开日志；只在可信的离线进程内使用。研究代理仍跳过原挑战级专属“必须选第一名”的压力诊断，但所有真实 `analyze_discards` 最小向听合法性及全局权威账目检查继续生效。正式 AI、对战Web页面、牌规、胡牌与复盘历史均不改变。

## 完整回放对象

只复盘历史固定的两组，开发 **52000–52003**、独立保留 **53000–53003**；每种子轮换四个挑战级座位，每位置原策略／固定候选各跑完整真实比赛，共 **64局**。同时核验复盘得到的改切次数与旧试验完全一致（3、2次），两组挑战级权威总净分差仍为（−700、0）；如果不一致，CI立即失败，不允许将发生漂移的复盘误当成正式结论。

增加真实“首次分歧”核验，可判别：是否在尚未分叉时真由M4.14候选切牌引发变化、第一次改切公开危险差与有效进张/番值收益保留情况、净分差来自哪些权威结算账目、差异涉及多少种子／多少配对位置。该观察不能回答“换出哪张牌就一定更强”，更不能从五次样本拟合点炮概率。

## 研究限制

5次实际切牌是发生在**3个独立洗牌种子**上的低样本实验，而且复盘使用的正是此前M4.14发表过的同一组种子；没有新验证样本。首次分叉后的完整净分变化受到其它玩家后续行为与随机牌山进程影响，不能对单次切牌做无偏因果归因。本轮不继续调0.08风险差门槛，不将未证实的防守改切应用到线上挑战AI。以后如要改善最强AI，应重点围绕可重复的**终局积分**和实际可复盘的牌效／防守权衡制定新的前置假设，再在完全未参与调参的独立种子上验证。

**研究判断：** 基准与防守改切之间的损益符号混合、有效干预仅四个座位配对，没有独立新样本验证。单次公开危险指数下降不能替代真正的胡牌＋杠钱＋流局全局积分判断，**正式挑战级 AI 仍维持原状，拒绝将 M4.14 防守改切策略上线**。
