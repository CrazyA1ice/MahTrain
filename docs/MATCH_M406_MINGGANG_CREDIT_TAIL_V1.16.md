# M4.06：明杠可撤销杠钱、尾部补牌及保守行动排序

## 背景及问题

M4.05 已通过11项CI和128局正式对照，16个不同初始洗牌种子、四席轮换双臂；**100个可碰／明杠窗口仅8个同时存在两种积极操作**，其余92次不必进行额外统一排序。在保留组35000–35007，实验策略发生的2次真实改动全部把**原挑战级明杠变为过牌**，使正式净积分合计**−1005**（胡牌分账−600、杠钱分账−5、流局分账−400，种子簇平均−31.4062），且两个负面种子为35003和35005。开发组34000–34007没有真正动作分歧，净分差0。上线新排序的证据不成立，正式AI始终未改动。

初步机制是：M4.04的联合评分给“下一摸牌效”和向听数，但明杠的价值不止于当时的有效张；它还可能获得**真实杠钱，并立即从牌墙尾部补一张牌**。但这两个奖励都不能被简单视为确定净收益，尤其是杠后所弃牌立即被胡时，权威杠账会冲销此前的明杠钱。本轮优先修复**价值分解和在线决策边界**，不在尚无后验概率证据时随意把杠钱转换成“等效有效张”。

## 精确的四川血战权威规则

从现有 `KongLedger.declare` 和 `FourPlayerOpening._resolve_discard / _supplement` 提取以下可验证事实：
- **明杠（`ming_gang`）**：一名点杠的打牌者付款，金额 `2 × kong_ledger.base`。若房间没有设置合法 `kong_ledger.base`，杠钱为 **`None`（无法定价）**，不能凭空设为2分；**不能将房间赢牌系数误认为杠钱基数**。
- **明杠补牌**：合法时 `wall_count>0`，原玩家从实际墙牌的**尾部**补一张。在线AI和离线比较评分器**看不到尾部的具体牌**。真实`hu`和杠后及时胡牌保留官方行为，不改变实际补牌。
- **可撤销现金**：若刚补牌后的弃牌立即被对手胡，权威账本会对当前杠事件执行撤销账，避免明杠钱与相应杠后胡牌分数双记。因此 `2×base`只是**“合法且被记账时的名义支付”**，不是明杠相对过牌的无条件真实净收益。
- **物理未知牌**：评分器仅通过自身授权手牌、自己的已公开副露、牌河未被碰走的牌及他家公开副露，从27种×4张全局108张物理牌计算自己不知道的牌数；这里的“公开未知”仍包括他家暗手和真实牌墙，**不能当成下一张尾牌的真实概率分布**。 `effective_ukeire / publicly_unknown_count` 仅是未见牌均匀假设下的下一张补牌**启发式有效比例**。有效张代理对长远胡牌概率及官方现金没有共同的点数单位。
- **抢杠**：`bu_gang` 的抢杠胡与 `ming_gang` 杠后弃牌被胡不可混为一谈。M4.06仅研究明杠，沿用原有补杠抢杠响应、多响和杠账撤销规则，不设计隐藏对手暗牌神谕。

## 守门决策及排序适用窗口

M4.06复用M4.05的“双积极行动授权”快速路径：仅在官方`claim_options`同一窗口同时有`peng`和`ming_gang`且无`hu`时运行一次联合牌效排序。其他已合法胡／抢杠胡、仅碰或仅明杠操作、天听保护、自身暗杠／补杠都**原样沿用挑战级**。

在双选项窗口中保存基于公开信息的候选证据，不把分账现金和一阶牌效错误相加。新的保守守门规则：
1. **原挑战级已经选择`ming_gang`**：若新排序仅因相同向听数下牌效偏好过牌／碰牌，一律保留原明杠——未定价尾牌即时补牌及官方杠钱是缺失的关键价值项；只有有合法替代行动带来**严格更小的真实向听数**，才允许覆盖。
2. **原挑战级选择`pass`或`peng`**：不能只因为更高启发式牌效或者凭想象的现金收益强制明杠；必须明杠向听数严格更小，且官方杠钱基数实际已知、天听合法，才考虑试验。
3. **其他非明杠替换**：也仅在候选严格改善向听数的情况下允许，避免由轻微代理差异触发非必要的动作。
4. 任何试验动作必须真实位于权威`claim_options`。原策略在非双选项窗口完全不受影响；对手暗手、未来墙牌、真实终局胡牌所得仅用于离线验收而不是在线动作评分。

这套守门规则是**保守的可解释启发式，不是经过数学证明的最优期望收益算法**。只有真实自然对照可以检验改动是否值得进一步上线。

## 预注册的独立自然配对终局实验

- 开发组：**36000–36007**，保留组：**37000–37007**，各8独立初始洗牌种子；与上一轮的34000–35007全部不重叠。
- 每个种子四种挑战级/进阶/基础/牌形基线座位轮换，每位置原挑战级`baseline`与保守守门`credit_tail_guard`两种策略同源配对，总计 **16种子×4位置×2策略＝128局真正执行到正式终局的牌局**，64成对座位位置。
- 对照完整权威胡牌积分、杠钱、流局查叫/花猪分账和四席零和，核验`official_net = win_points + kong_points + exhaustive_points`。
- 按**初始洗牌种子四位置平均**对比净收益、正负种子数和真实改变行动次数，不能把四席、操作窗口当成额外独立样本。样本仅8个种子/组，不以其计算虚假置信区间。
- 记录额外评分总耗时及单次峰值，但`perf_counter_ns`仅用于CI运行环境内的观察，不能保证用户浏览器机器上固定延时。
- 如果守门规则保留了全部原行动，得出`0`净分差只能证明**没有真实干预，不能证明这套评分更强**；如果真正干预但独立保留净分未改善，保持正式AI原状。
- 成功与失败均如实写入研究文档，不按终局分数事后替换种子范围。
