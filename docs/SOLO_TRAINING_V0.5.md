# MahTrain 单人训练网页 v0.5 — 居中牌面与逐轮牌效复盘

> **当前用户界面版本 v0.5**，继承 [v0.4](SOLO_TRAINING_V0.4.md) 的项目原始完整牌面图、看牌后定缺/天缺、自动胡牌/暗杠提示。**四川血战规则**仍是独立的 v0.4 草案，不能把界面版本号误当规则版本。

## 1. 牌面图片居中

保留仓库 `assets/tiles/640x420.jpeg` 的原始九列三行映射（筒、万、条各1–9）；不是重新绘制或更换为虚构牌图。

- 牌面按钮保持桌面约74×97像素（移动端响应式缩小）。
- 每个牌按钮使用居中的 `display:flex; align-items:center; justify-content:center`。
- 裁切牌图位于独立 `tile-atlas-face` 中，**宽高均为牌按钮的94%**，四周保留等量的3%间隙，避免图案偏到某一侧。
- 操作性与定缺标记、杠区锁定、音效均不变。
- 原图实际尺寸560×420，图片内部低像素信息无法凭 CSS 放大恢复为高清。本次解决的是**对齐与图案占比**，并不声称高分辨率修复。

## 2. 页面底部的逐轮切牌报告

每次玩家提交动作（切牌或确认胡牌）以后，服务端只对**已完成**回合生成报告，自动更新页面底部；未提交本轮标准答案与未来牌墙仍不会被公开。

页面底部新增三部分：

1. **训练统计**：局部最优切正确率、退向听选择次数、同向听层损失的有效进张枚数合计、已完成切牌轮次。
2. **牌效变化总结与柱状图**：从首轮切牌后至最近一轮切牌后，列出向听数、有效进张、下一摸改善/和牌模型概率的首末值与差异；柱状图按回合绘制切后的有效进张，颜色区分最优与非最优。
3. **逐轮可展开的复盘**：每回合的摸牌、切牌或胡牌、是否正确、并列局部最优动作、实际切后向听数、有效进张、下一摸概率、与上一次切牌后的数值差异、有效牌具体种类及剩余枚数、判题原因。

支持**只看待改进回合**，并支持浏览器将目前已完成的逐轮复盘**导出为 UTF-8 CSV**，可在 Excel 中查看。导出只包含真实已完成的训练记录，不包含未摸的牌墙、未来抽牌顺序。

最终胡牌或满14轮时，底部报告会以“训练结束 · 完整复盘”呈现；如果胡牌提前结束，仅包括真实已完成的回合，不虚构后续切牌记录。

## 3. 数据定义和限制

- **向听数**：当轮实际切牌后，13有效张剩余向听；直接胡牌回合没有“切后向听”，用“胡牌”展示，不能当作0向听切牌。
- **有效进张枚数**：在该轮已知的自己的牌与公开弃牌下，使向听改善或和牌的**物理未知牌张数**；已完成暗杠的四张也属于已知牌。
- **下一摸概率**：以`有效未知张数 / 全部未知张数`表达的模型概率，不等于四人对局中真实的严格下一摸牌墙概率。
- **本轮最优切**：先保证切后向听数最小，再在同等向听层级中使有效进张最大；所有并列方案均算正确。
- **向听损失**：实际切后向听减当轮最小向听；为正表示相对最优方案退了向听。
- **同向听层进张损失**：仅在所选切牌达到当轮最低向听时，计算最优进张枚数与实际进张枚数的差，不跨向听层进行不恰当比较。
- **与上一轮变化**：是相邻两次**已完成切牌后**状态之间的差异。两轮间玩家还会得到新的摸牌、公开牌变化，因此这些差异**不能全归因于上轮切牌**。
- 放弃已提示的合法胡牌再切牌：记录为不最优，但仍计算该次**实际切牌后的牌效**，供回顾；该状态不冒称正常“当轮最佳何切”。
- **胡牌提前结束**：直接胡牌的回合没有可比较的切后进张和向听，报告独立记录为“胡牌”，不破坏走势数据。

## 4. 源码位置

- `src/mahtrain_core/review.py`：将已完成的训练历史汇总为逐轮复盘记录、向听/有效进张/概率变化及汇总统计。
- `src/mahtrain_core/session.py`：在现有 `report()` 返回数据中加入 `round_review`、`progress_summary`，并处理放弃胡牌后切牌的牌效。
- `web/review.js`：页面底部可展开轮次、柱状图、错题筛选、CSV导出。
- `web/app.css`：居中裁切样式与移动端复盘布局。
- `web_server.py`：已完成回合的实时报告，仅在提交答案后向网页开放。
- `tests/test_round_review.py`、`tests/test_web_app.py`：回合变化、胡牌边界、禁泄漏与网页资源回归测试。

本地执行：

```bash
git pull origin main
python web_server.py
```

浏览器地址：`http://127.0.0.1:8765`，如已有服务，请先重启并用 `Ctrl+F5` 刷新。
