# M3.58：真实点炮风险的分层与按洗牌种子聚类验证

## 目标

M3.57 首轮候选弃牌直接点炮测试：4个训练种子455个候选-对手样本、7个正例；3个测试种子514个样本、7个正例。样本外 Brier Score 由0.0133182降到0.01315407，但绝对改善只有0.00016413。在点炮极稀少、同一局可能产生许多相似的候选/目标组合时，仅凭大量**行数**和很低的 Brier，容易错误理解为“风险判断已经准确”。

这轮任务是建立**分层审计与独立洗牌种子聚类**，并扩大独立种子覆盖。在证明风险估计能够跨局面、跨种子保持稳定之前，不部署概率模型到正式挑战 AI。

## 变化

- 保留 M3.57 的真实标签：可信离线模拟器读取对手当时的13等效暗手与公开副露，依据 `winning_tiles`、`score_win` 标注每张候选切牌是否合法点炮及倍率；仅作为研究真值。
- 预测仍**只能**读取观察者自己的合法候选切牌、定缺、公开弃牌、公开副露、牌山数量。没有访问其他玩家暗手、真实牌墙或种子预测未来的权限。
- 按公开信息分为三组：牌墙剩余 **大于24 / 13–24 / 不超过12**；目标公开副露 **0 / 1 / ≥2组**；候选弃牌对该对手是否由定缺规则认定为“不可胡 / 可能合法胡”。分组直接由现有特征向量生成，不读取标签来划分组。
- 分组分别报告有效样本数、真实点炮正例数、Brier与 log loss 的基线、候选模型、差值，以及 `P(立即点炮) × 训练数据条件倍率` 对真实倍率的 MSE 差。空分组写 `null` 而不是0或假想风险。
- **尤其单列可胡花色组**：定缺安全组的预测本来就被规则限制为0，如果把这批易判定样本混入总体评分，可能掩盖真正关键的风险估计缺陷。
- 对每个测试独立洗牌种子分别计算 Brier 与倍率损失差；统计各有多少种子改善/变差/持平，报告种子等权的平均变化，并以固定随机种子做2,048次**整体洗牌种子有放回重抽**构建描述性的2.5%–97.5%区间。不能把同一局内多次候选切牌当成独立观测来重采样。对于仅有6个测试种子的CI试验，该区间**不构成可信的统计显著性证明**。
- CI 从M3.57的 4训练+3测试种子，改为**8个训练洗牌种子+6个完全独立测试洗牌种子**；步长仍为6。导出JSON仅含聚合指标、公开分层与按种子聚合变化，**不**导出行级的隐藏牌、听口、候选切牌、目标座位或真实逐条标签。
- 同时保留 Python 3.11/3.13、前端JS、四人对战、25局五策略消融、两种旧校准研究以及构造场况专项验证。M3.58 不修改 `ai.py` 的正式挑战决策，因此不引入额外出牌时延，也不能冒称实际棋力提高。

## 数据解释限制

当某分组没有正例时，零点炮并不意味着该类切牌不会点炮；当训练/测试每个独立洗牌种子数量仍偏小，强烈相关的同局观测、当前自对局AI固定策略、分组筛选偏差等，都限制结论外推。对人类玩家的实战风格尚无证据。

不能把“给定一个当前合法候选弃牌能被依法胡”的离线**潜在结果标签**等同于一局真实对战中玩家一定会点胡、或者某个候选切牌会获得更多完整净积分。后者需要完整对局的**相同种子与座位、唯一改变风险策略**的随机配对实验，独立样本足够时报告种子聚类置信区间、放铳及全账本净分（含杠钱和流局结算）和决策 p95 延迟。


JSON关键字段：`stratified_validation.overall`、`stratified_validation.strata.wall_stage`、`target_public_melds`、`candidate_rule`、`by_seed`、`cluster_bootstrap_brier`、`cluster_bootstrap_payout`。

### 下一阶段 M3.59 建议

在更大规模的自对局、不同策略族以及不同座位下获取数十到数百个真正的点炮正例；只有风险预测在**可胡花色**、后期与多副露这些重要子组中稳定优于先验，才能冻结权重，使用可选研究策略参加配对的**真实全局净积分**对照。即使观察到预测改善，也不能自动推出实战胜率提高。
