# M3.69 · 經典 Majiang UI 的胡牌提示、完整结算及中文语音

## 本轮解决什么

在原版 `@kobalab/majiang-ui` 经典 2D 牌桌上新增：

1. **胡牌实时广播**：每一笔服务器已入账胡牌都会在牌桌**上方独立信息栏**列出胡牌人（自己或哪名 AI）、方式（自摸／点炮胡／抢杠胡）、主番型、有效番数、实收分数。同局多名玩家胡牌分别显示；刷新续局时仍可通过服务器历史恢复广播。该栏不会遮住任何手牌、牌河、副露。
2. **结束后四家财务结算表**：完全从 Python 权威 `win_ledger`、`kong_ledger`、`exhaustive_settlement` 和 `settled_balances` 读取。显示每家真实胡牌番型、胡牌净收支、杠钱净收支、流局赔付及本局总计；下方列出每笔自摸/点炮/抢杠胡、每人付款、组合加成、杠的付款人/收款人、明暗补杠、撤销及冲正流水。对账核对零和及逐家分项和；**校验不一致时提示错误，绝不擅自调整分数**。牌山耗尽但花猪／大叫未入账时明确标记**暂不属于最终分数**。
3. **中文语音**：新 2D 之前并未绑定已有语音，本次复用原 `web/match_voice.js` 的 Web Speech API 模块；可报具体公开打牌牌名，碰、杠、胡只报这一个字，不泄露暗手和剩余牌墙。顶部有语音开关、慢／正常／快速、重听功能。每段语音最多尝试播放 **1.3 秒**，并不会阻塞 AI 行动或等待语音完成。因浏览器语音引擎和声音许可不同，实际发音质量、设备音量、后台节流不能保证一致；不支持时有明确提示。
4. **牌桌未换皮**：使用原 Majiang `Shoupai`、`He`、`mianzi` 和 28 张原版 GIF 牌面，不动任何上游开源桌布和牌面源码，仅增加牌桌外的提示、明细表和声音按钮。

## 运行

在 MahTrain 目录执行：

```bash
git pull origin main
python web_server.py
```

访问 `http://127.0.0.1:8765/classic/game.html` 或主页的「经典 2D 血战（Majiang UI）」入口。新版已将 JS/CSS 真实构建产物提交到 `frontend_2d/dist/`，无需用户执行 npm。

## 数据来源与验收

- `frontend_2d/src/settlement.mjs`：纯函数提取账本、验证余额、筛选可公开语音事件；不重算四川血战胡牌分数。
- `frontend_2d/src/report.mjs`：对战结束的四家结算表，逐笔胡牌和杠钱记录，流局待核验警示。
- `frontend_2d/src/main.js`：语音开启/重听、公开操作播报、结算渲染及胡牌广播。
- `frontend_2d/test/settlement.test.mjs`：真实服务器字段结构的固定分数样例、流局正式/未正式入账、杠撤销、重复通知与语音隐私测试。
- `frontend_2d/test/browser-smoke.mjs`：真实 Python 开局、换三张、定缺、牌面渲染。
- `frontend_2d/test/browser-settlement.mjs`：**模拟真实结算快照**的浏览器测试，使用 Chrome 真正渲染经典 2D UI，检测玩家和 AI 胡牌、杠钱明细、分数零和、实际语音“胡”、胡牌栏与财务表格不覆盖牌桌，并保存截图。该测试使用**结算 API fixture**（不是一局自动打至结束）；胡牌金额仍按服务器公开字段映射，不表示我们重新实现了结算算法。
- GitHub Actions 的 `.github/workflows/majiang-2d.yml` 已覆盖全部构建与测试并自动发布静态产物。

## 局限

1. 本轮尚未实现所有结算边界的**真实 Python 全局 E2E**，例如三家不同顺序胡完、多个抢杠胡、流局未结算等；金额来源可靠，但完整前端每种事件回放仍可进一步扩充。
2. 语音依赖浏览器支持 `speechSynthesis` 及中文语音资源；浏览器禁止声音时可点击顶部语音按钮触发用户手势。语音限时不等于服务器 AI 计算每步能在 1.5 秒内完成。
3. 现有 3D 页面和原生旧 2D 页面作为备用，不再作为这轮重设计基础。
