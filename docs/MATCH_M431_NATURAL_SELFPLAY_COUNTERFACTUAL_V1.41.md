# M4.31：四名挑战级 AI 的自然自对战与多动作真实净分标签（v1.41）

## 本轮的实质性变化

M4.30 已具备“4AI对战→安全公开牌谱→本家私有数据→轨迹积分弱训练→留出对照”，但实际首次4场训练与8场留出中模型**改变0次弃牌、平均净分差0**。简单把胜者的弃牌当成高质量标签存在严重的归因错误。M4.31不再把**整局回报当作每巡切牌的因果标签**，而是建立一个研究级流程：

1. **全员同强度自对战**：四个座位统一使用原样 `MahjongAgent("challenge")`，由官方 `FourPlayerOpening` 完整处理换三张、定缺、切牌、碰杠、抢杠、尾摸、多人胡、牌墙耗尽与一炮多响、查花猪及查大叫结算；所有玩法仍使用 `current_m423`，有价杠使用 `kong_base=20`。每局完整走到三家胡牌或真实牌墙耗尽，108张实体牌不增不减，胡牌／杠钱／流局／总净分账本四家均零和。
2. **自然产生的真实争议决策点**：在此自然对局中选第一个“轮到某个挑战级AI切牌、不能立即自摸、当前原策略不补杠，而且至少存在两种同一最小向听层级的合法弃牌”的决策节点。对比原挑战级选择与另一种**真正合法且同向听**的弃牌，不人为造牌或强制存在双候选；没有则如实记无样本。
3. **真正让各候选打到终局**：冻结同一自然时点，分别用原 AI 的选牌与另一合法弃牌打满剩余局面。未来牌墙分别采用原有墙序与另一个预先固定的实体牌合法洗牌顺序；一组中两个备选动作起点具有相同对手暗手、实体牌、对局历史和未来墙排列。每个分支后续都由四名正式挑战级 AI 执行，只干预这次切牌。最后**直接读取权威真实官方胡牌积分、杠钱、流局分、净积分**；不使用估计的预期分代替真实计分。
4. **受限动作级偏好学习**：先在独立训练洗牌种子区间采集“两个动作特征差→真实终局条件化积分差”，试着计算小幅度、绝对值不超过0.2的离线候选偏好；在**完全未参与训练的独立洗牌种子**上仅核对方向，不将少量样本直接覆盖在线挑战AI。

## 数据与隐藏信息约束

- 对局回放只使用已有 `public_replay_frame` 与递归私有字段保护。逐时刻公开事件、牌河、每家副露、剩余牌墙计数、官方结算等属于公开回放；**不会出现某家未公开暗手、真实未来牌墙、真人玩家的数据或复现种子**。训练/留出种子仅用于本地重现，不直接写入公开回放ID。
- 私有训练样本只记录这次决策玩家**自己在决策当时真正有权限看到的手牌／公开副露／公开牌河**、合法候选、候选牌效数据及终局对应积分差。整个完整隐藏牌局只存在实验进程内存中，不导出到任何训练 JSON。固定两种未来墙是**对研究者的离线条件化比较**，在线AI看不到、也不能从结局反推当时隐藏牌。
- 本轮“另一未知世界”仅在**当前墙内按实体108张保留副本、重排未摸未来墙顺序**；固定其他玩家实际暗手，不宣称样本已经代表所有合法隐藏手牌的真实后验分布，也不把两个未来墙当作两个独立随机开局。
- `data/selfplay/` 已被 Git 排除；`PRIVATE_*.jsonl.gz` 和完整模型的本地输出不得直接上传 GitHub。CI只上传不含私人内容的聚合计数摘要。公共牌谱可展示，但应确认实际用途与隐私边界。

## 复现命令

在 Python 3.11 的项目虚拟环境内从仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe examples\run_selfplay_counterfactual.py --seed-start 89500 --train-seeds 1 --holdout-seeds 1 --out-dir data/selfplay/m431
```

生成：

| 本地文件 | 数据 |
|---|---|
| `public_four_challenge_replays.jsonl.gz` | 自然四挑战AI对局完整公开动作时间线与终局官方分 |
| `PRIVATE_train_action_values.jsonl.gz` | 训练种子的本家可见决策状态、两种合法切牌×两种后续墙序×真实终局积分 |
| `PRIVATE_holdout_action_values.jsonl.gz` | **隔离的留出洗牌种子**同类真实分支结算，严格不参与学习 |
| `offline_preference_model.json` | 仅研究用的动作级收益信号受限权重；尚未部署 |
| `PRIVATE_holdout_diagnostics.json` | 留出行动预测/真实分账差的逐个比较 |
| `summary.json` | 不包含私有牌或复现种子的统计摘要 |

以上默认 **1个训练自然种子 + 1个留出自然种子** 是检验管线正确性的最小实验，不代表统计显著。每自然种子最多选一个真实候选决策点，至多额外4场分支完整局（2个未来墙×2种合法切牌）。如果这局从未出现两种同向听合法候选，必须如实记录0个学习样本，不允许补造。

## 研究局限和下一步

M4.31的标签比“赢家的每次切牌都好”更有针对性，但即使同起始点的两种动作终局净分相差200分，也不能由一两种未来墙推断玩家在现实所有隐藏牌条件下的平均得分差。本轮并未完成因果价值统计上的可校准后验采样。

面向未来强化学习，有两个待攻克的关键问题：

- **训练覆盖与吞吐率**：采集上万独立自然起手并为每个有效决策点从多种**合法可见信息条件下抽样**的世界做成对模拟；性能上应该缓存单步特征，避免无谓重复计算精确向听/牌效；保留原始对局回放和可回溯的行动标签。
- **模型选择与反偏差评估**：以真实官方净分构造行动Q值的有噪监督学习，参考行动的价值差要跨大量独立牌局统计；有数据支持才进一步扩展到“碰/杠/胡/过”的多动作比较。模型候选需冻结，然后与上一稳定版在全新未参与选模的洗牌种子、四座位轮换下完赛比较完整积分/胡牌/杠钱/流局，**仅当留出优势稳定且没有规则泄漏时才考虑人工审核上线**。

本轮**不改变线上 AI 策略、阈值、计分或用户UI**。所有CI必须完全通过方可合并。
