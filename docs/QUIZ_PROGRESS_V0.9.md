# MahTrain 单题训练 v0.9：SQLite 记分、错题本与难度推荐

> 本文对应 **M2.7**。继承 v0.8 的四种单题模式与三档结构难度，并保留 14 轮连续训练、原图牌面、单人暗杠和既有历史报告。本版本仍是**本机单用户**原型，不是多账户在线服务，也尚未实现正式四人血战 AI。

## 一、单题成绩正式入库

完成一题并提交有效答案后，服务器评分成功，才将该题记录存入原来的 `data/mahtrain_history.sqlite3`：

- 训练模式：一向听何切、听牌何切、清一色听口、清一色何切。
- 所选难度：基础、进阶、挑战。
- 题目编号、公开的当时手牌、声明定缺、初次作答、正确性、牌型构造分类，以及**提交后**的原始评分与解析。
- SQLite 中另保存该错题后续的重练次数和重练正误，与**首次作答统计严格分离**。

**不会保存**尚未提交的单题、服务器私有随机种子、随机会话令牌、未来牌墙或正在进行的连续训练完整洗牌状态。只有成功评分的答案可入库；重复提交相同题目令牌会被拒绝。相同题型的后续新题属于新的独立答题记录。

旧有 `local_history` 和 `local_retries` 表保持不变。数据库架构从**版本 1 增量升级为版本 2**，新增 `quiz_attempts` 和 `quiz_retries` 表，保留之前已经存储的14轮训练及旧错题记录。

## 二、根据每种模式的真实成绩推荐难度

网页单题训练中心下方新增 **「单题成绩与难度建议」**，四种训练模式相互独立：

- 三档显示该模式下的累计题数及各自首次作答正确率。
- 当前难度的推荐只使用**同一训练模式、同一难度**的最近10次已评分初次作答，不使用重练成绩，也不混入其他模式的统计。
- 同一模式、当前难度不足5题时，只提示“继续积累样本”，不建议升降档。
- 已完成至少5题后，最近成绩**正确率 ≥80%**且非挑战档：推荐晋升一个难度。
- 已完成至少5题后，最近成绩**正确率 ≤40%**且非基础档：推荐降低一个难度巩固。
- 中间正确率，或处于最高/最低档无法再升降时：维持当前难度。

上述阈值是**透明、可调整的启发式建议**，并不证明题目的实际认知难度经过实验校准，也不代表麻将技能排名。

界面只显示 **「采用推荐：××」** 按钮供用户自己决定；不会自动切换难度、中断当前做题或改变正在查看的题目。

## 三、单题错题本和跨重启重练

单题训练中心下面还有近期单题历史列表（按模式显示最近20条），每条可查看完整手牌、首次选择、正确答案及解析。

如果一题首次没有达到最优：

1. 点击历史条目的“查看 / 重练”，进入详情。
2. 点击“重新做这道错题”，恢复原题公开手牌与相同选项，**再次提交前不返回正确答案**。
3. 提交后显示本次作答与首次作答、原题最佳答案，并单独持久化重练正误。
4. 重启 Python 服务后仍可继续从这道历史错题练起。
5. 如不再需要，可以删除某道单题及其全部关联重练记录。

错题本复习是学习工具；首次提交后的答案本已对使用者可见，不能据此宣称严格的考试防作弊能力。历史重练基于提交时冻结的原题正确答案与评分理由，**不因将来算法升级而静默重算**。

## 四、使用方式

更新本地 Git 仓库、重新启动本机服务器：

```bash
git pull origin main
python web_server.py
```

打开 `http://127.0.0.1:8765`，按 `Ctrl+F5` 刷新页面。

在“单题训练中心”依次选择**训练模式 → 难度 → 生成训练题 → 点击答题 → 提交答案**，然后在下方查看不同等级的累计记录、近期正确率与难度建议。重新启动服务器后记录依旧保留。

### 检查测试

```bash
python -m unittest discover -s tests -v
```

- `tests/test_quiz_progress.py`：SQLite v1→v2 兼容升级；统计按模式/难度隔离；升级、降级和保持逻辑；错题重练不影响首次准确率；永久删除的关联数据清理。
- `tests/test_web_app.py`：真实 HTTP 出题→非法答案被拒绝且不写库→有效答案入库→历史重开后查看→错题重练→禁止重复提交；浏览器所需静态 JS 可正常获取。
- GitHub Actions：Python 3.11 与 3.13、Node.js 前端脚本语法检查、既有单人连续训练与固定题型冒烟测试。

## 五、局限与后续

- **当前不存在账户身份系统**：浏览器打开相同 localhost 服务时看到的是这台电脑上的共享历史，不能将服务直接开放公网。
- **当前没有云端同步**：数据库在本地 `data/mahtrain_history.sqlite3`（可用 `MAHTRAIN_HISTORY_DB` 更换路径），受 `.gitignore` 排除；不应推到 GitHub。
- **连续14轮中途断点续练**仍未实现；只归档已经结束的连续训练。
- 单题自适应目前只提供基于近期正确率的**建议**，不自动选择题型比例；不同牌型的出题平衡和客观难度尚需更多样本检验。
- 正式四人血战的换三张/同时定缺、碰明杠补杠、番数和三档 AI 仍待后续实现。
