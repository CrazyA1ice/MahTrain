# M4.02：四座位自然补杠机会—合法抢杠资格—实际结算闭环

## 前情与必要性

M4.01最终10项CI全部通过，自然8+8独立种子×四席总64局，开发组合法补杠窗口7次（同牌重复4次，3个不同候选），实际宣告2次、成功1次、被抢杠1次；开发组自然抢杠正例来自种子26001。独立保留组3次窗口均为不同候选，全部补杠成功且没有合法抢杠正例。**样本规模仍不足以校准真实风险概率**。物理构造的抢杠正负例不参与自然发生率估计。

此前自然抽样**只观察挑战级AI对应的一个座位**，同场的其他三个真实AI可杠时并未成为样本。本轮观察器不再更改、替换任何AI，只在原有真实完整对局开始每次行动前读取当事座位的合法补杠候选，基于公开牌桌和独立可信离线规则真值审计，扩大覆盖到**四座位**。

## 全座位观察与反事实边界

固定新种子开发28000—28007、保留29000—29007，每组8个独立洗牌种子，每种子四个策略位置轮换：每组32个完成的自然对局，四座位全部观察共128个座位位置；两组共64局/256座位位置，但**仍然只有16个独立初始洗牌种子**。不得把64局、256座位、窗口或同牌重复候选称为256个独立数据点。

对每个合法选择前的补杠候选，仅受信任局内对象记住 `(owner_seat,public_peng_tile)` 用以去重：

1. **首次合法候选**：公开风向/定缺、副露、弃牌、剩余墙牌都在不读取对手暗手的 `public_bugang_features` 中生成；**与特征完全隔离**的受信任离线 `_sealed_potential_robbers` 读取当刻其他玩家暗手，生成规则真值。它不影响任何AI行动。
2. **同牌重复候选**：只记录重复次数；另检测潜在抢杠资格是否已经与首次不同，但不能把新的时刻当成独立局。
3. **真正宣告补杠**：权威事件 `bu_gang_declared` 可能发生在同牌重复提示数巡后，因此须使用**最近一次决策前**的合法抢杠标签，而不能偷用首次标签。用同一宣告的 `rob_kong` 公共解决事件核对**多人胡牌**个数；若全部过牌则 `bu_gang` 成功。一次被抢杠只能计一次失败宣告，无论几个赢家。
4. **官方完整结算**：每局验证108张物理牌守恒，四席 `settled_balance=hu_ledger+kong_ledger+exhaustive_ledger`，且总净分零和。
5. **按AI级别的描述性观察**：分组只显示 `challenge/advanced/basic/baseline` 已遇候选数、提出次数、实际抢杠次数以及最初观察到的潜在抢杠标签。它不证明某个策略更强，因为四家的策略和牌局路径不是随机独立分配的因果试验。
6. **不导出牌种或暗手**：研究JSON只包含已公开特征的**类别与计数**、去标识的座位号/策略类型、离线标签总人数，以及官方真实结算；私有同牌关联键只在可信内存里存在。实时API、浏览器、玩家存档、AI权重完全不改变。

### 重要的统计边界

即使在这轮自然样本观察到潜在抢杠对手、实际被抢杠和多响，也只能说明在当前4人策略构成下有这些事件；不能把所有候选聚集起来做无条件风险概率，也不能用开发种子调整阈值后声称保留组仍是严格独立验证。

已公开碰牌与本家真实合法补杠选项允许研究**补杠前**可观察的状态；对手真实暗手仅能在离线标签生成器内使用。可抢杠胡并不表示一定会选择胡，也不能将未来尾牌或终局盈亏当成当时能看到的预测信号。

```bash
python -m unittest discover -s tests -p 'test_m402_all_seat_bugang.py' -v
python examples/audit_all_seat_bugang.py --seeds 8 --output results/m402_all.json

# CI中开发/保留分作两个并行独立作业，以缩短验收时间
python examples/audit_all_seat_bugang.py --cohort development --seeds 8 --output results/m402_development.json
python examples/audit_all_seat_bugang.py --cohort holdout --seeds 8 --output results/m402_holdout.json
```

工作流 `.github/workflows/m402-all-seat-bugang.yml` 会审计完整终局牌守恒、每个实际补杠宣告对应的合法资格与真实抢杠事件、各类计数的守恒及隐牌字段隔离，分别保存2个GitHub Actions JSON artifact。

**部署决策**：本轮仅建成更全面的自然样本观察和可信闭环。只有在新独立样本中存在足够真实正例，且公开风险信号表现稳定，下一轮才考虑研究公开特征的风险权重或线上AI决策。不能直接读后验标签决定线上行动。

## M4.02 实测结果（2026年10月22日）

[GitHub Actions 双自然组完整验收](https://github.com/CrazyA1ice/MahTrain/actions/runs/39801797753) 中 `all-seat-unit`、`all-seat-cohort (development,28000)`、`all-seat-cohort (holdout,29000)` 三项专项作业均成功。两个自然组的原始审计 JSON 分别归档为 `m402-all-seat-development` 和 `m402-all-seat-holdout`，包含各局所有座位的官方终局积分、候选风险类别以及潜在合法/实际发生结果，**无暗手、具体补杠牌种或未来牌墙**。

### A. 真实完整牌局和重复候选

| 真实指标 | 开发组28000–28007 | 独立保留组29000–29007 | 总计 |
|---|---:|---:|---:|
| 初始独立洗牌种子 | 8 | 8 | **16** |
| 完整规则自然对局 | 32 | 32 | 64 |
| 被观察的座位位置（相关样本） | 128 | 128 | 256 |
| 实际合法补杠候选窗口 | 25 | 15 | 40 |
| 同座位同牌去重后首次不同候选 | **6** | **9** | **15** |
| 同牌跨巡再次成为合法候选 | 19 | 6 | 25 |
| AI 真正宣告补杠 | 4 | 7 | 11 |
| 宣告前受信任标签存在合法抢杠胡者 | 0 | 0 | 0 |
| 实际被抢杠胡次数 | 0 | 0 | 0 |
| 自然概率校准状态 | 无正例、不可估计 | 无正例、不可估计 | **未完成有效校准** |

开发组的重复窗口主要集中在**种子28006**：两张不同的可补杠候选共反复成为合法候选21次，均未由该局挑战级AI真正宣告。因此不能简单地以21次“没补杠”来计算21次失误。其余开发组合法补杠主要来自28001、28002、28003、28004，每项首次候选1次且全部真实宣告/生效。

保留组自然候选的种子分布为：29000有5次候选窗口但仅1个不同候选（重复4次）；29001一次候选未执行；29002有3次窗口、2个不同候选、2次实际宣告；29005一次候选并宣告；29006三个不同候选且均宣告；29007两个窗口但仅1个不同候选（重复1次）、未宣告。种子29003、29004没有候选。

### B. 按四种自然AI策略区分（不是独立随机实验）

| AI 级别 | 开发组首次候选 | 开发组实际宣告 | 保留组首次候选 | 保留组实际宣告 |
|---|---:|---:|---:|---:|
| 挑战级 challenge | 2 | 0 | 0 | 0 |
| 进阶级 advanced | 2 | 2 | 5 | 5 |
| 入门级 basic | 2 | 2 | 4 | 2 |
| 牌形基线 baseline | 0 | 0 | 0 | 0 |

挑战级在开发组的21次合法窗口中实际上只有2个首次不同候选，且都来自同一个种子；保留组没有出现该级可补杠候选，**不可能用这批数据判定挑战级是过度保守还是恰当防守**。四类AI的手牌路径、碰牌行为和补杠可见机会并不随机等价，禁止根据上表宣称胜率或长期收益排名。

### C. 公开风险标签与真实抢杠结果

- 开发组6个首次不同候选全部属于 `unresolved`，且隐藏规则真值均无合法抢杠对手。
- 保留组9个不同候选中，`dingque_excluded`有2个、`same_suit_focus`有1个、`exposed_pressure`有1个、`unresolved`有5个，全部隐藏真值为0。
- 两组11次实际补杠声明全部成功，没有被抢杠；但这不等于“实际补杠安全率100%”可推广，因为独立种子仅16个，首次不同候选仅15个，而且两个自然组没有正例。
- M4.01的更早、独立种子组确实已在**种子26001**观察到一次正式抢杠胡（开发组7窗口/3候选中存在1个正例，且2次实际宣告中1次被抢）。这证明规则/标签链条可以处理自然正例，但不能把两轮小规模样本事后合并成已校准预测模型，更不能拿人为构造场景填正例。

### 研究判断

**模型可验证性提升，但尚不允许部署基于此的高危概率或新杠牌权重。** 本轮最重要的完成项是把真实多级AI行动、合法候选去重、宣告前的最新合法Hu标签与真实裁决结果和正式终局账本连接成同一闭环，并独立重复两组完整自然对局。没有使用任何未来墙牌、对手暗手或实验终局结果来改变正在对战的AI。

下一轮可以采用预先固定的**更多独立自然洗牌种子**，保持四座位只读观察和去重口径，观察真实正例是否能重复出现。只有具有足够来源独立的合法抢杠正例、负例，并与旧构造场景区分后，才有条件研究稳健的公开风险阈值和正式净收益对照。
