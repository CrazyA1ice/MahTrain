# MahTrain M2.8：错因分析与薄弱项强化训练（v0.10）

> 本文是**单题训练模块 v0.10** 的说明，延续 v0.9 SQLite 首次成绩、错题本、推荐难度，并不修改四川血战正式规则版本 v0.4，也不改变14轮连续训练的判分逻辑。

## 1. 错因来自真实评分，而不是模板标签

仅对**四种单题模式已经提交、经原始判题引擎评分、且答错的首次作答**分析：

| 错因 | 判定条件 | 可用模式 |
| --- | --- | --- |
| 退向听 | 实际切后向听数大于本题所有候选的最小向听数 | 一向听、听牌何切、清一色何切 |
| 同向听少进张 | 向听数达到最优层级，但有效进张枚数少于该层级最佳切牌 | 一向听、听牌何切、清一色何切 |
| 错过合法胡牌 | 实际已经合法胡牌，却选择切牌而未胡 | 清一色何切 |
| 未成胡误判胡牌 | 牌型或定缺不满足合法胡牌，却点击确认胡牌 | 清一色何切 |
| 漏选合法听口 | 提交的听口集合遗漏真实可胡牌种 | 清一色选听口 |
| 误选无效听口 | 选入不属于完整合法听口集合的牌种 | 清一色选听口 |

同一道清一色听口题可能**同时漏选和误选**，两项分别计数。极少数没有落入上述具体条件的非最优动作归类为其他错因，不会强行解释为退向听/进张损失。已答对题不计入任何错因。

诊断代码：`src/mahtrain_core/error_focus.py` 的 `diagnose_quiz`；分析基于 `grade_answer` 返回的**真实向听、有效进张和全部合法听口**，不是依据生成模板的名称猜测。

## 2. 统计口径与入口

单题中心“单题成绩与难度建议”下方新增**错因分析与专项强化**：

- 选择的**训练模式**对应近最多30道**首次答错**的单题，合并该模式三个难度统计，不混用另外三种模式。
- 列出该模式适用的每种错因出现次数，并标示当前最多的错因。
- 历史 SQLite 版本 v0.9 中没有 `error_types` 字段的旧评分，分析时从原有 `result_json` 动态重建；**不需要删除旧数据库，也不必重新作答**。
- 在任一错因行点击 **“专项练习”**：当前模式当前难度下，后端尝试从最多24个私有随机种子中生成符合条件的题；找不到则明确报错，不把其他题冒充专项题。
- 也可点击 **“开启薄弱项强化 · 按错因频次出题”**：当此模式有历史错因时，每题约 **75%** 的机会尝试专项，约 **25%** 保留普通题；选择哪类专项按历史错因出现次数加权。若专项筛选未找到可验证题目，退回普通题并在牌面标明**“普通穿插题”**，不虚构强化成功。
- 此强化比例是**题目生成的预设概率**，而非保证任意连续10题刚好7或8道专项；只有能够被完整胡牌/牌效引擎核验的候选，才明确标为专项。
- 用户可以在当前模式自主开启或退出强化；**切换训练模式时会退出强化**。原有基础/进阶/挑战难度选择继续有效，不强制升降档。

## 3. 数据、私有性与安全

- `quiz_answer` 返回 `error_types`、`error_labels`；评分成功后一起写入**已有的** `quiz_attempts.result_json`，无需 SQLite 新增列或再做破坏性迁移。
- `quiz_progress` 返回 `weaknesses.counts`、标签、历史错题样本数、主要错因。统计只使用**首次作答**，不把错题重练重复计入。
- `quiz_new` 可接收 `focus: "auto"` 或该模式支持的具体错因，例如 `"ukeire_loss"`；服务器保存私有种子，提交前只下发题目牌面、可选动作及**公开的训练目标标签**，不会提前下发标准答案、向听/有效进张排行榜。
- 生成目标通过 `question_has_focus` 核验：如退向听练习必须存在某种可选切牌会加大向听，进张损失练习必须存在同向听但少进张的切法，胡牌识别题必须与真实胡牌判定相符。这仅说明**题目具备该错误陷阱**，不预言用户必然做错。
- 同一原题在提交前仍只能有效评分一次；非法选牌/篡改题目不计入 SQLite；强化题与普通题一样支持原有历史错题重练。
- 本机服务仅监听 `127.0.0.1`，并无账户体系、云同步或在线多人隔离；勿暴露公网。

## 4. 使用

在 MahTrain 项目根目录：

```bash
git pull origin main
python web_server.py
```

浏览器打开 `http://127.0.0.1:8765`，按 `Ctrl+F5` 以更新 JS/CSS：

1. 选择单题训练模式与基础/进阶/挑战等级，完成几道题。
2. 在页面下方查看“错因分析与专项强化”的错误种类与次数。
3. 点击某一错因的“专项练习”或下方的“开启薄弱项强化”。
4. 看牌、做题、提交，再比较原始分析、具体错因及正确答案；点击“重新出一题”会继续沿用当前强化策略，直到点击“退出强化”。

## 5. 测试与下一步

运行：

```bash
python -m unittest discover -s tests -v
```

涉及 `tests/test_error_focus.py`、`tests/test_web_app.py`；CI 同时执行原有 Python 3.11/3.13、Web JS 和全套训练/SQLite/暗杠冒烟测试。

**边界**：当前聚焦的是四种单题，不改变连续14轮每轮报告；错因权重按次数统计而非心理测量模型，专项筛选仍以现有题型生成器为上限。后续可以加入跨局14轮错因汇总、不同错误类型的错题专项复习、题型分布平衡和正式四人牌局模拟。
