# M3.83 · 挑战级 AI 多候选杠的严格向听预筛选

## 原因

项目此前已合并 M3.81 非听牌有效张缓存及 M3.82「只能过」快捷路径。M3.83 专门针对真正有暗杠或补杠候选的**己方选择阶段**。原 M3.79 挑战级决策依次枚举：合法切牌中最小向听、所有最优切牌的完整有效进张和番值、每个杠候选的完整有效进张和番值，最后才按向听数/有效张/番值判断能否接受。

这样即使某个杠**精确向听数必定劣于正常切牌**，仍要做完整多种进张枚举；而既定 `_outlook_better_than_baseline` 对此必然返回否，计算属于浪费。本轮不调整任何副露积极程度、75% 保留阈值、天听原听口要求或同分优先规则。

## 严格等价的处理

1. 仍完整枚举合法缺门限制后的可切牌，求出**最小向听数** `least`；所有向听计算都调用已有精确 `shanten_13` 及 `_cut_shanten`，不是随意启发式猜测。
2. 对每个 `an_gang` 或 `bu_gang` 合法候选先实际构建扣除相应实体牌的**13 有效张**与合法副露集合，调用精确 `shanten_13`。如 `stage>least`，按既有策略必定拒绝，提前跳过其 `effective_draws` / `score_win`。
3. 如所有杠候选都被拒绝，直接返回 `None`，**不用再评分所有正常切牌参考态**。如余下候选均严格 `stage<least`，既有规则不需要保留 75% 参考张数也会接受；不计算参考态，但仍完整评价各实际候选的有效张、番值、天听保存条件，按照旧版同一键排序，不影响最后决策。
4. 如存在任一 `stage==least` 的候选，仍完整评分所有最优参考切牌，保留 `ukeire>=75%` 且 `value>=75%` 的既定门槛以及**三背一明的暗杠、可能遭抢杠的补杠**原规则，不捏造尾墙补牌或对手暗牌。
5. **不缓存玩家对手暗手、未来墙、公开风险推断**。本优化改变的是计算顺序与无用调用次数，不改变牌效函数内部规则，旧正式比赛可以逐字段对照。

## 独立回归

- `tests/test_ai_kong_prune.py` 内保留原 M3.82 `_challenge_kong` 的完整函数体，除改名外不修改。测试真实服务器构造的两个可选暗杠对照、破坏七对听牌结构的合法杠、已验证天听、其他隐藏字段污染、同分真实选择和模拟更优结构。
- 在真实 108 张牌守恒的 `FourPlayerOpening` 上生成授权 `private_view`；两组正式 `simulate_match` 全局对照：旧策略和新策略的行动历史、公开复盘、赢家、最后胡牌/杠钱/流局结算必须完全一致。
- 复跑既有 `test_ai_calls.py`、`test_ai_pass_fastpath.py`。针对旧测试中人工返回的 `shanten=1` / 价值排名，需要同时 mock 精确向听而不让虚构数值与实际向听冲突，这不是修改真实算分。
- `examples/benchmark_kong_prune.py` 交替对**同一授权局面**调用旧、新策略，24 次记录 CPU 中位耗时；场景含两个真实候选暗杠、以及真实七对结构可能被杠破坏的方案。任何一轮选牌不同即失败，原始 JSON 归档在专项 GitHub Actions。

## 科研边界

M3.80 在 8 个独立种子、64 局发现新旧碰杠策略的正式净分差 -21.875，95% 种子簇区间跨过 0，**不支持宣称挑战 AI 已变强**。本轮只优化不可能被接受的候选计算，不改善算法本身的获胜概率。一个 CPU 同场景微基准不能推出麻将完整对局耗时降幅，尤其是“只能过”窗口已在上一轮加速过；这一步只涉及实际可杠阶段。


## 专项实测 · 2026-10-20

[GitHub Actions 39444015755](https://github.com/CrazyA1ice/MahTrain/actions/runs/39444015755) 全部成功：**7 项** M3.83 冻结旧版策略与真实结算测试，**6 项**原挑战 AI 碰杠测试，**8 项** M3.82 旧测试，以及合法场况旧/新同局交替耗时基准。正式对局在旧函数与本轮候选预筛选之间的动作轨迹、公开复盘、赢家与三项正式分账逐字段相同。

| 真实合法杠选择场景 | M3.82 旧版中位耗时 | M3.83 预筛中位耗时 | 观察 |
|---|---:|---:|---|
| 两种暗杠候选仍需要评价 | 0.949615 ms | 0.963581 ms | 约 +1.5% 耗时，未观察到加速 |
| 杠牌必破坏七对听牌结构（向听劣于切牌） | 0.543752 ms | 0.057194 ms | 此类必拒绝选项约 9.51 倍局部加速 |

两类场景均在同一授权 `private_view`、108 张实体牌和 M3.81 公用计数缓存条件下交替计时 24 次，中位数不代表所有随机种子或部署设备。特别是两种暗杠都需要评分时，新增精确向听筛选本身会增加少量开销，不能声称每一个可杠局面都提速；真实对局综合加速需要另测场况出现频次和缓存冷热比例。
