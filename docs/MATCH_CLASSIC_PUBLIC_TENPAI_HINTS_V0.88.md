# M3.77 · 经典 2D 牌效参考、听牌及公开可见进张

## 为什么采用按需分析

根据用户此前确定的界面原则，经典 Majiang UI 使用固定的 800×680 四方牌桌，普通弃牌/碰杠不允许在上方反复插入提示条，更不能触发牌桌重新缩放。因此本轮把「查看当前牌效参考」置于**牌桌下方**：只有轮到自己实际出牌、自己未胡牌且已定缺时才可点击；不点不会运行新的牌效计算，也不会拖慢 AI 普通出牌。点击后展示表格，随后出牌、碰杠、重新开局、AI 回合等状态变化会自动撤销旧建议。

## 数据和算法的真实含义

后端 `src/mahtrain_core/classic_hint.py` 直接使用已经过回归的四川血战 `efficiency.py`：`analyze_discards` / `effective_draws`，规则仍由 Python 负责，前端只负责中文解释和原版 GIF 缩略牌面。

- **向听：** 每个候选切牌后，13 有效张在现有四川规则下距听牌的结构阶段。**0 向听=听牌**。如果 14 有效张已经组成允许的胡牌，提醒玩家优先考虑服务器自己的「自摸胡」按钮，而不虚构需要再次弃牌。
- **定缺强制：** 手里还存在自己定缺花色时，候选切牌只包含该花色，不能通过牌效排序暗示先打非定缺牌。
- **公开已知牌：** 仅本人获授权 `private_view(0)` 的手牌/副露，加上公开牌河和各家的公开副露；公开弃牌被他人碰/杠时，避免把「已拿去副露的那张弃牌」再扣一次。绝不读取对手暗手、未来牌墙、隐蔽的 AI 进张或 RNG。已公开副露的具体牌按 Python 的公共数据表示处理。
- **有效牌种和未知副本：** 报表列出切牌后可将向听进一步降低的有效种类，听牌时就是结构胡牌听口；「≤N张」是在**所有未知位置（墙内 + 对手暗手等）仍可能存在的物理牌副本总数上限**，绝不是已证明牌墙中还有 N 张，更不是「下一次摸进 N 张的概率」。
- **参考排序：** 最少向听优先，其次未排除有效张数最多。浅金色标出此有限指标下的参考牌，并在自己手牌原版 GIF 上用轻微虚线描边。不计算对手胡牌风险、隐藏墙的真实位置、整个后续对局的番型得分期望；**不将它标榜为 AI 的全局最优或必赢切法**。

## 交互与安全

- 仅新增只读 `POST /api/action`、`action=match_hint`。必须持有该局合法 `match_token`，并且当前是授权 seat 0 轮到出牌。该动作**不会修改轮次、弃牌、墙、已胡标记、账本，也不会启动 AI 继续执行**。
- 服务端只返回当前牌效表及原本对应的 token；不返回整个对局手牌/暗墙信息。前端请求如果因用户真实出牌而变成旧状态，异步结果会被丢弃。
- 「查看/收起」按钮和表格都在固定桌面之后，不影响牌桌尺度、原版四向56格牌河或任何玩家位置；不创建顶部动态动作条。正常语音、AI 节奏、金色常驻「已胡」、终局四家收支和刷新恢复全部保留。
