# M4.05：碰／明杠双选项快速路径与独立配对终局验证

## 前情

M4.04 已实现研究专用的 `pass/peng/ming_gang` 统一一阶牌效候选表，保持合法胡、抢杠胡必胡、天听原听口和线上挑战级原有自身暗杠／补杠全部候选排序不变。在预先冻结的开发32000–32003、保留33000–33003共8个独立种子、64局完整成对终局对照中，开发组**0次实际操作分歧／净分变化0**，保留组**3次操作分歧／平均净分+25**，且正收益集中于**种子33002**。仅4独立种子/组，不足以证明新策略稳定更强。

M4.04 实现对每个可碰或明杠窗口都先运行原挑战级评分，再额外运行统一候选表，即使该窗口只有一种积极行动。M4.05 聚焦真正会改变 `ming_gang` 与 `peng` 排序的情形：**两个积极行动均在同一官方授权窗口合法出现**，其余窗口直接返回原策略决策，避免无收益的额外评分。

## M4.05 精确行动与性能契约

- 真实官方 `claim_options` 同时包含 `peng`、`ming_gang`、没有 `hu`，且 `phase=="claim_window"` 才调用 `optional_claim_slate` **恰好一次**。综合评价包含 `pass`、`peng` 与 `ming_gang`；评估碰牌时必须列举碰后合法切牌，不重复计算被碰走的公开弃牌。
- 仅碰或仅明杠的窗口及只能过牌的窗口，**不调用额外候选评分**，完全保留已经经过验收的原挑战级策略。
- 已有 `hu` 或抢杠 `hu` 时不进入新评分，并强制检查原挑战级确实选择 `hu`；已有认证天听的碰牌禁止和明杠原听口保护仍由同一个合法候选表执行。
- 自身 `an_gang/bu_gang` 继续调用原挑战级对所有本家合法杠候选的评分器，不改变杠后补牌、抢杠多响、胡牌优先及正式结算。
- 受信任实验内记录每个真正双选项窗口的新旧动作**是否有差异**、研究臂是否真的改变了动作、额外评分器调用次数、原挑战级响应耗时与额外候选评分耗时（`perf_counter_ns`）；只输出汇总数和毫秒数，**不导出具体暗牌或任何未来牌墙**。
- 计时是研究运行机器上的*描述性测量*，不对其他硬件给出固定延迟承诺；不能只看总秒数，因为改变碰杠后两条策略路径会改变后续操作次数。确保 `extra_slate_evaluations==dual_active_windows`。

## 预注册独立自然配对

两组从未用于M4.04或M3.95–M4.03的固定初始洗牌种子：

- 开发组：34000–34007，8独立初始洗牌种子
- 独立保留组：35000–35007，8独立初始洗牌种子
- 每种子四种AI位置轮换，比较原挑战级 `baseline` 与研究专用 `dual_fastpath`，其他三席AI类型和参数完全一致。两组合计 **16独立种子×4轮换×2策略=128局正式四川血战对局**，64组成对座位。
- 每局核验牌种108张物理守恒、官方胡牌＋杠钱＋流局结算净分与四席零和；每个独立种子的四位置先求平均，再跨8独立种子求总体均值。
- 附带的研究臂在同一初始洗牌的另一完整对局中改变一次碰/明杠会导致后续墙牌抽取和对手路径随之改变，**不能假定后续牌墙和对手操作相同**。这只是正式终局的配对比较，不是持有未来暗牌知识的在线因果神谕。
- 如果自然双选项窗口很少，或多数种子没有真正操作变化，必须诚实给出零干预数，不按收益重新选择种子；**任何单轮4/8独立种子都不足以声称获得稳定最优AI**。

## 真实物理牌与安全回归

测试包括以完整108张物理牌分发的**真正可碰和可明杠同一窗口**，验证无需额外隐牌即可给出合法动作；单积极操作窗口不调用额外排序；双积极候选恰好算一次；合法胡／抢杠胡必胡；天听保持；两个合法自身杠候选全部交回已有评分器；私造的对手暗手、未来墙牌字段注入不能影响决策；非法候选／无效样本种子／积分账本异常不得静默吞掉。

## M4.05 实测结果与上线判断（2026年10月23日）

本轮**不是拟定测试**。[PR #103](https://github.com/CrazyA1ice/MahTrain/pull/103) 已通过11项CI后合并至`main`。[GitHub Actions 39911693950](https://github.com/CrazyA1ice/MahTrain/actions/runs/39911693950) 中专门的真实双选项回归、开发组及保留组128局正式终局测试、Python 3.11/3.13、真实浏览器、公开压力和风险校准回归 **11项全部成功，0失败**。原始匿名对照结果分组归档于`m405-development-paired`与`m405-holdout-paired`。

### 完整自然对照：快速路径确实减少额外候选评分，但收益不成立

| 指标 | 开发34000–34007 | 独立保留35000–35007 | 合计 |
|---|---:|---:|---:|
| 独立初始洗牌种子 | 8 | 8 | **16** |
| 四座位成对位置 | 32 | 32 | 64 |
| 官方128局中的完整规则对战 | 64 | 64 | **128** |
| baseline策略自然出现的自愿碰／明杠操作窗口 | 47 | 53 | 100 |
| 其中碰、明杠同时合法的窗口 | **3** | **5** | **8** |
| 因仅有一种积极行动而跳过联合排序 | **44** | **48** | **92** |
| 真正额外运行联合评分器次数 | 3 | 5 | 8 |
| 研究策略实际改变的碰／明杠操作 | **0** | **2** | **2** |
| 新策略减原策略的每个独立种子四席平均净积分均值 | **0** | **−31.4062** | 不合并成外推估计 |
| 四座位正式净积分差累积 | 0 | **−1005** | −1005 |
| 收益为正的独立种子数 | 0 | 0 | 0 |
| 收益为负的独立种子数 | 0 | **2** | 2 |

开发组所有8个种子均没有真正改变动作，严格来说**只能验证快速路径跳过冗余评分和策略一致性，不能评价新的碰／明杠排序强度**。原策略47个窗口中44个（约93.6%）直接沿用原判断，不会计算额外的候选表。

独立保留组原策略53个可选操作窗口中48个（约90.6%）直接沿用原判断，真正存在碰／明杠双积极选项的只有5个，研究策略在其中2个窗口与原策略分歧，且**两次都将原策略的明杠改为过牌**，而非改为碰牌。真实官方积分两次均为负：

- 初始种子**35003**：四席平均正式净积分差 **−125.50**，1次真实改动。
- 初始种子**35005**：四席平均正式净积分差 **−125.75**，1次真实改动。
- 其余35000、35001、35002、35004、35006、35007均0改动、0净分差。
- 保留组累计官方净积分差 **−1005**，胡牌分账 **−600**、杠钱分账 **−5**、流局分账 **−400**，三项完整相加严格相符。额外出现1次点炮事件、研究策略相对原策略少完成2次杠。不能将结果简化为只少收5分杠钱，因为放弃明杠改变了后续牌墙、对手决策与胡牌、流局结算路径。

本轮合计100个原策略遇到的可选操作窗口中，**92个完全不需要运行额外联合评分**，只在8个双选项窗口运行了8次评分。这是按**算法调用次数**得到的性能事实。实际跑在CI机器上的计时数据显示单次额外评分时间随运行负载有很大波动，例如保留组两种试验臂可见的`max_single_extra_slate_ms`差别很大，故绝不能声称线上固定提速百分比，更不能把CI墙上计时当成用户浏览器的响应保证。

### 机制分析

上一轮M4.04保留组33000–33003有3次操作变化、种子均值+25分，且开发组全无改动；但本轮新的**完全不同**独立种子35000–35007的真正双选项快速路径出现2次干预，全部造成负收益。两轮结果方向并不一致，研究特征与样本大小也不同，不能据此声称“明杠永远优于过牌”，但已经充分表明**尚不能将现有一阶牌效评分直接替换线上挑战级的明杠选择**。

最应追查的局部机制是：统一候选表的相对有效张与下一摸番权代理，并未为明杠即时获得的**真实官方杠钱**和**杠后补牌**充分定价，也未可靠评估后续对手行动、抢杠或流局结算。在纯代理分数稍逊时，算法可能过于轻易选择过牌。这里的未来完整账本只能用于**离线检验**，绝不能作为AI在线时可见的未来信号。

### 决定与下一轮

**生产策略保持不变。** 研究快速路径及安全测试保留在仓库，正式挑战级仍使用原来逐一检查碰牌、明杠，且自行暗杠／补杠候选全评估的代码。原因很明确：真实独立保留组实际行动改动的官方净积分为负；这不是值得上线的版本。

M4.06 可先做不泄密的**明杠边际收益分解**：固定额外的合法官方杠钱、公开剩余墙牌推导的补牌有效张代理、杠后向听／待牌集和可能的合法抢杠风险上界，构建**完整候选证据表**，但所有权重须由新的未见种子配对终局和多响/尾牌规则回归检验；如果仍没有独立正向收益，不接入线上AI。
