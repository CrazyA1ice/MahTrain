# M3.56：真实听牌状态标注、公开信息概率基线与样本外校准

## 为什么改变研究重心

M3.54–M3.55 的条件化隐藏牌世界采样已满足真实108张牌库存约束，且不偷窥对手暗牌。不过固定的五个独立洗牌种子、25局四人对局中挑战 AI 的胡牌事件与正式积分没有可观测变化；合成听牌假设的命中数也**不是**真实的条件听牌概率。继续增加抽样世界数缺少可靠的研究依据。

本轮首先回答一个更基础的问题：**只看公开弃牌、公开副露和牌山信息，到底能多准确地识别对手当时已经听牌？**

## 严格的数据边界

两个完全不同的函数负责“观测”和“真值”：

- `public_tenpai_features(view, target_seat)`：输入为当前**观察者的已授权视图**，只读取座位、各家定缺、是否已胡、公开碰杠、公开弃牌、牌山剩余数量；生成固定七维向量（含常数项）。不读取对手手牌、摸牌、抽样隐藏世界或真实牌墙。测试通过注入额外 `opponent_hands`、`_hands` 和 `future_wall` 键核对预测特征不变。
- `_truth_label(game, target_seat)`：只在**可信离线自对局执行进程**使用，检查实际对手暗手和真实副露。仅对合法13张等效手牌调用四川规则 `shanten_13(...)=0` 产生 0/1 真值。14张待切或已胡玩家一律不标注。
- 通过 `simulate_match(..., offline_observer=...)` 内部回调，**在 AI 切牌前**记录公有特征与隐藏真值，未修改 live AI 决策。内部回调不会进入 `public_replay`、`trace`、Web 端或数据库。
- 导出的 JSON 只包含洗牌种子分组编号、训练/测试总样本与听牌样本数量、Brier、log loss、ECE 和 5 个校准区间的计数/均值。绝不导出单局对手暗手或单条真值样本。

## 初版可解释概率基线

公开特征包括：牌山进度、公开副露组数、对手牌河长度、牌河中非定缺花色所占比例、最近3次是否还在打定缺牌、公开副露中最大花色集中度。加入常数项后使用**只依赖 Python 标准库**的正则化逻辑回归。

- **训练集基线**：以训练种子的总体真值频率作为预测常数（不是测试集正例频率）。
- **公开信息逻辑回归**：只用训练集拟合各特征系数（L2约束），对同一洗牌种子的样本设置等权，避免长局面占比过大。
- **样本外评估**：训练洗牌种子与测试洗牌种子完全不重叠；测试只用于 Brier Score、log loss、Expected Calibration Error 与校准分箱。
- 分箱结果空桶用 `null`，不伪造该概率段的命中率。报告必须同时说明测试总体样本数、正例数和正例率，否则“0.1概率”缺少解释基础。

**当前研究阶段不在线部署拟合参数**，不修改 AI 真实出牌逻辑或默认响应速度。

## 实验限制

1. 同一牌局中的多次观测、同一座位与多个对手的样本高度相关；尽管按**洗牌种子**分离训练/测试，当前 CI 烟雾试验只用2个训练种子、1个测试种子，其结果无统计外推效力。
2. 训练数据来自本项目现有 AI 对手的自对局，而非真实玩家，因此学习到的弃牌行为可能不适用于人类对手。特别是 AI 不同难度策略分布可能产生偏差。
3. 本轮对方处于13等效张时统计听牌状态，不能等同于“马上会胡你这张牌”的个别弃牌放铳概率。某人听牌但不一定听此张；要额外预测每个听口及对应得分并经过真实事件验证。
4. 目前没有概率校准所需的足够样本，也没有跨策略/跨座位/跨时间的独立测试，更没有信息集 MCTS 和未来多步完整净积分评估。即使小样本 Brier 小于常数基线，也**不能称其为已经验证的最强 AI**。

## 下一轮应做

先增加独立的自对局种子样本，并在多个不重叠的时间/种子簇上作成组置信区间和逐座位/剩余牌山区间的校准检查；必要时增加 `P(听牌且听某张)` 的公开信息特征。仅在 Brier / log loss **稳定优于基线**、对不同难度 AI 有泛化能力、且决策耗时可接受后，再把冻结的概率映射接入更复杂的候选切牌长期净收益搜索。
