# MahTrain M3.37：四人对局语音调速与公开动作重听（v0.49）

本轮继续优先改进用户体验。保留 M3.36 已完成的移动端四边牌桌、二次确认出牌、真实加减分与方案A结算；本轮**不修改麻将规则、AI策略、种子或服务端接口**。

## 使用方式

启动 `python web_server.py`，打开四人血战区域。原“语音播报出牌、碰、杠、胡”开关旁新增：

- **播报语速**：慢速（0.85）、标准（1.12，默认）、快速（1.35）。这是 Web Speech API 的 `SpeechSynthesisUtterance.rate`，实际语音速度及音色取决于用户浏览器与中文语音引擎。
- **重听最近公开动作**：仅重播最近一次**已经播出**的公开动作播报内容。如果本次状态更新中含多个公开动作，则播报的是最近一次已播出的整组公开动作（至多8个），不宣称是单张牌。按钮不会发送后端请求，也不会重新执行任何麻将动作。
- **静音/无支持浏览器**：关闭语音开关将停止队列并禁用调速与重听；浏览器不支持 Web Speech API 时控件自动禁用，不影响对局。
- **新局重置**：无论随机开始还是“再来一局”，成功开启新局时立刻取消上一局语音并清除可重听内容，避免跨局播报。
- 用户本页选择的语速在本次页面中持续有效，刷新后回到默认标准，不写入 Cookie 或服务器。

## 声音与信息安全

动作来自现有 `MahTrainPlayback` 的公开事件或可信公开快照，由 `match_voice.js` 中的 `phrase()` 转为中文短语。非公开摸牌、AI暗手、暗杠牌面和未来牌墙从未进入播报文本。暗杠只说“暗杠”，不念未公开的具体牌。重听缓存仅保留**已经合成的纯中文公开短语**，不保存 API 对象、牌墙、玩家暗牌或下一轮事件。

播报的新动作会取消仍在排队的旧播报以避免积压；重听同样中断正在播放的播报。播放速度的改变仅作用于后续语音或重听，绝不改变回放视觉速度、对局走向和 AI 难度。
