# M4.35：本机自对战动作收益分歧与离线研究（v1.45）

## 为什么要改

用户的 Windows 电脑已成功完成 M4.34 小样本：4个独立自然洗牌种子，4场自然四挑战级AI对局+16场动作分支，合计20场真正的终局结算。训练集双墙严格同号标签为0条，留出集有2条同号标签（**留出数据不得拿来训练**）。以前的硬规则直接丢弃两个条件墙下方向相反的合法动作点，数据利用率过低。

M4.35 **不重跑已经结束的真实牌局**。新模块 src/mahtrain_core/ai_selfplay_uncertainty.py 从 M4.34 生成的 PRIVATE_seed_shards 原样读取、审计保存的真实官方游戏状态；按原始洗牌种子保留全部合法对照动作（包括收益相反、均值为零者），计算两个条件化未来墙顺序下的完整真实净分差、算术均值和绝对差。

采用明确标记为研究启发式的收缩：若两墙下动作净分差分别为d0、d1，均值m=(d0+d1)/2，差异g=abs(d0-d1)，则系数 r=abs(m)/(abs(m)+g/2+100)，训练目标为clip(m/1000,-1,1)×r。最终只训练三个基于**行动者本人合法可见信息**的差异牌效特征权重，权重绝对值限制在0.2以内。同一原始洗牌多个节点先平均，再跨独立原始洗牌平均；训练过程中绝不能读取留出收益。

两个墙排列共享同一原始种子与固定对手暗手，彼此高度相关。这里的 r 只是降低分歧较大样本影响的诊断**启发式**，不是校准方差、统计置信区间、真实动作Q值或总体期望收益。均值0仍然保留合法动作记录，只是其线性更新贡献为0。此轮**没有新旧AI实战**，亦不提升或替换在线挑战级AI。

## 本地现有数据直接分析（不再运行对局）

在 MahTrain 项目根目录执行：

~~~powershell
git switch main
git pull --ff-only origin main
python examples\run_local_uncertainty_analysis.py --out-dir data/selfplay/m434-smoke
~~~

只需现有 M4.34 冻结的 PRIVATE_plan.json 和所有成功完成的 PRIVATE_seed_shards/index-*.json。程序先核对计划哈希、原始种子属于训练还是留出、所有公开牌局108张实体守恒与官方结算分账、训练动作完整性、两个合法未来墙终局净分是否相符。任何缺失、混合、篡改都中止，不创建假的训练样本。

与原始训练分片并存的新文件：

| 文件 | 含义 |
|---|---|
| PRIVATE_uncertainty_offline_model.json | 只使用训练原始洗牌簇的全部合法动作拟合的受限离线三维诊断权重 |
| PRIVATE_uncertainty_holdout_diagnostics.jsonl.gz | 留出种子每个合法动作在两墙下的原始真实积分差、预测与弃权明细；仅本机保存 |
| safe_uncertainty_summary.json | 公开无私有种子和暗手的训练/留出独立簇数、自然合法决策点、两墙同号/相反/平局数、真实两墙净分差分歧程度、有限留出方向评估 |

复用已有数据不用额外的CUDA/GPU、PyTorch、外部API或付费服务。现有M4.34所有文件不被覆盖。

## 隐私和统计限制

留出原始洗牌区间固定不变；先只读训练数据拟合权重，再只读独立留出数据检验方向，绝不在训练时读取留出标签。真实留出均值或模型方向为0时记为弃权；少于5个实际可评分留出决策点时准确率输出null而不是0%或100%。

统计单位仍然是原始自然洗牌种子。自然对局里的多个决策点和两个相关墙排列不构成独立随机实验。纵然能预测这两个条件世界的净分差，也不能推断用户对战中AI真实胜率或其行为更优。

GitHub CI只上传 safe_uncertainty_summary.json；完整实际种子、本人手牌、内存中的对手暗手和未来牌墙不进入公开工件。下一阶段必须在更多一致信息隐藏世界和冻结新旧AI的完整真实对局中验证；线上AI维持不变。
