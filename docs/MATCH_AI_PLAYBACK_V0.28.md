# MahTrain M3.16：AI 公开动作播放与速度控制（v0.28）

## 功能与实现边界

服务器继续在一次请求内完整执行真实 AI 行动与结算。页面仅对这次响应的新增**公开事件**逐项播放：正常摸牌、杠后补摸只显示牌背；已公开的弃牌、碰、明杠、补杠或胡牌事件可以显示公开牌面；暗杠无论服务端内部事件中是否含牌种，动画都不显示。座位外框同步突出行动者，胡牌有不同视觉提示。

播放速度可选快速（180ms）、标准（450ms）、慢速（900ms）和关闭。播放中可暂停、继续、跳过；跳过时直接更新到服务器最终真实牌桌。播放期间禁止重复提交其他操作，只有播放按钮仍可控制。新增事件超过80条可展示动作时，仅回放最后80条并提示略过数量，完整公开事件记录仍在原日志中。

**历史状态限制**：这不是逐帧服务器快照或 AI 真正逐步思考模式。客户端在动画时保留上次完整牌桌，中心叠加公开动作；所有动作结束后才同步最终权威牌桌。不要把中间浮层理解为墙牌数量或 AI 暗手的完整历史快照。没有新增能够查询其他玩家手牌、刚摸的牌或墙牌顺序的 API。

## 涉及文件

- web/match_playback.js：公开事件白名单、禁显示的暗杠和摸牌、定时控制器，支持取消、暂停、继续、切速、跳过。
- web/match.js：只选取本次响应新产生的公开事件，独立中央动作浮层，突出行动座位，完成后刷新权威牌桌。
- web/index.html：速度选择、播放进度、暂停/继续、跳过及桌面中央动态牌卡。
- web/app.css：行动弹入与座位高亮，适配 reduced-motion。
- web_server.py：新 JavaScript 静态资源，不改规则接口。
- tests/test_match_playback.js：模拟时钟与隐私边界，检测取消和跳过回调只触发一次。
- tests/test_match_board_dom.js：加载真实人机对战 JS，模拟提交切牌、暂停、继续、变速及跳过后正确同步牌桌。
- tests/test_web_app.py：新静态资源、加载顺序和页面组件测试。CI 同时保留 Python3.11/3.13、25场五种子对局及定向公开副露测试。

## 验收步骤

在仓库根目录运行 python web_server.py，浏览器打开 http://127.0.0.1:8765 并进入人机对战。完成换三张和定缺后点击一张牌，观察中央公开行动弹层。选择慢速、暂停、继续、跳过，核对前端最终牌桌的牌河与牌山数量；切换关闭播放，提交下一次弃牌应直接更新完整局面。AI 摸牌、杠后补摸、暗杠不能显示任何对手暗牌身份。

本轮还未实现按单帧重建完全真实的历史牌桌、服务端真正暂停 AI 行动、正式流局结算或多用户联网。
