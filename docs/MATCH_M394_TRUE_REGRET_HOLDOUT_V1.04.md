# M3.94：只替换真实参考差距的切牌，独立种子组验证

## 目的与 M3.93 的差别

M3.93 把“挑战级实际切牌与牌效参考排行榜第一张不同”视为分歧；但参考函数支持多个 `reference_best=True` 的**并列最优**牌。仅是牌面名称不同，不等于当前牌效受损。M3.94 保留挑战级原本选择，**只有其实际牌的 `reference_best=False` 时才替换为首名参考牌**，从而避免实验人为改变等价最优解。

该改动**仅用于离线对照研究**：当前 Web 端挑战级、实际 AI、游戏规则、数据库和历史复盘都不变。离线研究继续使用本座位授权可见信息计算，不窥墙牌及其余三家暗手。

## 可解释的差距分类

| 类别 | 判据 | 是否干预 |
|---|---|---|
| `agreed_first` | 当前挑战级牌正是参考第一名 | 否 |
| `equal_best_other_tile` | 实际不同但 `reference_best=True` | 否 |
| `unscored` | 无合法参考候选 | 否 |
| `shanten_gap` | 实际切牌向听数高于最优 | 是 |
| `tenpai_fan_weighted_gap` | 同处听牌，实际可见未知张数乘基础番值权重更低 | 是 |
| `tenpai_ukeire_gap` | 听牌权重相等，但有效张上界较低 | 是 |
| `ukeire_gap` | 尚未听牌且有效张上界较低 | 是 |
| `other_reference_gap` | 其他参考排序差距，保留实测类别 | 是 |

挑战级现有形状先验、公开风险折扣、确定性私有世界模拟与牌效参照的排序规则并不相同。公开风险修正是否反转同向听候选另有统计，但**不把相关性说成放铳因果效应**，也不把风险指数当作概率。

## 预先划分、不重叠的开发与保留种子

默认配置：

- 开发组：8420、8421、8422，三个独立初始牌堆种子。
- 保留组：9400、9401、9402，三个独立初始牌堆种子。
- 每个独立种子做四种座位轮换，且各自对战“原挑战策略”和“仅纠正真实参考差距”的研究策略。两组共**24组成对完整对局，合计48局**。
- 每局对完整规则下官方净积分、胡牌和点炮次数作对照，含正式杠钱及流局方案A结算；物理108张守恒、正式结算零和校验失败即报错。
- 保留组不用于调参和择优，先在代码和 CI 文件中固定再执行。开发组也不训练任何模型，只汇报观察。
- 汇总统计单元为**独立种子**，不是座位轮换，也不是每巡。列出各种子的四席净积分差、调整次数与说明性的确定性种子聚类 bootstrap 95% 区间。当前种子数量极少，该区间不具备可靠的推广性，更不是证明优越性的显著性检验。

## 运行

在仓库根目录：

```bash
python -m unittest discover -s tests -p 'test_m394_true_regret_holdout.py' -v
python examples/compare_challenge_regret_holdout.py --development 8420 --holdout 9400 --seeds 3 --rotations 4 --output results/m394_regret_holdout.json
```

对应自动工作流 `M3.94 true-regret paired holdout` 只在 PR 对应代码变更时运行，不改线上策略。

## 评估注意事项

1. **不会从“改牌次数很少”推断“挑战级已达到理论最优”**。这是一个公开牌效参考对照，而非完美信息博弈理论。
2. 两种对局一旦出牌不同，其后局面就自然不同；干预轨迹后续再次出现的差距不能直接归因于最初那一张牌。
3. 哪怕观察到更高净积分，也不能凭有限种子认定实力提升。反复挑选有利种子或查看保留组之后再修改并反复试验，都会使所谓泛化检验失效。
4. 如果两组没有足够真正不同的策略决策，结论就是“本次实验无法区分胜负”，而不是“已经证明两者等效”。后续可扩大独立种子，或另做**仅用于机制诊断**的分歧场景库，不把定向筛选的场景混作无偏胜率样本。
