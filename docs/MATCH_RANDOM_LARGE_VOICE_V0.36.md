# MahTrain M3.24：随机开局、高清公开牌桌和中文语音（v0.36）

本轮对 **四人血战人机对战** 做三项用户侧调整。原有单人训练的手动种子与用于 AI 评测的固定种子工具维持独立，不改变实验可复现性。

## 1. 普通对局不再手动输入种子

点击「随机开始一局」，前端不再传 `seed` 字段，Python 服务器使用 `secrets.randbelow(2**32)` 生成种子，并对本次服务器进程中已用过的对局种子去重。重复候选会再次生成；手动种子也加入已使用集合，后续自动开局不会撞上该值。两次普通开局不重复；**重启服务器后不承诺跨进程全局唯一**，但随机范围足够大，生产账号/长期持久唯一编号目前尚未实现。

对战界面增加「再来一局 · 随机开局」按钮。点击将另建对局及会话令牌、清除当前浏览器的未保存临时复盘和旧动画；如果上一局尚未结束，先确认是否放弃进度。历史已完成对局 SQLite 档案保留原行为。

「实验室 · 固定种子复现」是默认收起的配置区。只有勾选「本次开始时使用固定种子」并点击「随机开始一局」时才携带固定种子；「再来一局」**始终随机**，即使实验室复现已开启也不例外。为了兼容原有 Python/API 自动测试，旧的显式 `seed` HTTP 请求仍被接受。服务端没有向普通对局返回实际随机种子或未来牌墙。

## 2. 牌河、碰杠牌面放大

四家牌河的公开牌由原来的约 **28×39 CSS 像素**改为 **44×60 CSS 像素**；各家碰/明杠/补杠牌由约 **27×37** 改为 **40×54**。暗杠仍以放大的牌背表示，不暴露牌种。

牌桌最低宽度同步扩大，保留横向滚动；四周牌河有纵向滚动区域。窄屏以完整清晰牌面优先，不再把麻将牌压缩到难以辨认的尺寸。使用仓库原有的麻将牌面图片，无需上传新素材。

## 3. 中文公开动作语音播报

增加由浏览器 `speechSynthesis` 提供的中文读牌；目前支持：
- 四家已公开的弃牌：「1号打五筒」
- 公开碰牌：「3号碰二万」
- 明杠、补杠及不泄露牌种的暗杠：「2号暗杠」
- 自摸、点炮胡、抢杠胡和一炮多响

语音只消费已有 `MahTrainPlayback` 白名单净化后的**公开**事件。真人操作、AI 公共动作按真实逐动作回放朗读；关闭回放动画时改为在请求成功后朗读**本次新增**公开事件。不会朗读 AI 摸到的私有牌、暗杠未公开的牌面或未来牌墙。

对局顶部有独立「语音播报」开关；不依赖以前的 Web Audio 音效按钮。浏览器不支持时自动禁用并显示说明。较快回放会取消较早的语音请求，优先跟上当前画面，避免累积几分钟的过期朗读；不同浏览器的中文声音质量和自动播放许可不同。

## 验收

启动 `python web_server.py`，访问 `http://127.0.0.1:8765`：
1. 直接随机开始，不需填写种子；再来一局仍使用新随机种子。
2. 展开实验室、勾选固定模式，输入 42 后使用开始按钮复现；再来一局应忽略 42。
3. 查看牌河和其他三家碰杠牌，牌面显著比原来大；其他玩家暗手仍只显示牌背。
4. 用支持 Web Speech 的浏览器开启语音，出牌/碰/杠/胡会读出实际已公开信息；关闭语音后不继续播。
5. 运行 `python -m unittest discover -s tests -v`、`node tests/test_match_board_dom.js`、`node tests/test_match_voice.js`，并查看 GitHub Actions 的 Python 3.11/3.13 集成测试。

**尚未解决**：整套正式血战流局赔付入账、完整 AI 学习算法、多用户对局以及跨服务器持久种子唯一性。
