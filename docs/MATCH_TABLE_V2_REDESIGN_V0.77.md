# M3.66 – 四人牌桌 UI V2（独立前端皮肤）
## 动机
M3.65 过度依赖数百条层叠 CSS，中央装饰牌墙被画成 400px 以上的巨大方框；四家手牌离牌河过远，自家手牌落在绿色卡片条内。尽管数字化的「无遮挡」回归通过，实际观感远离用户提供的天凤参考图。本轮不再向 app.css 尾部追加同类补丁，而是清理 M3.65 的临时规则，启用独立 `web/match_table_v2.css`。
## 开源参考与许可
- `yuandom/mahjong` （https://github.com/yuandom/mahjong）：参考四人座次、麻将桌层次、点选出牌与浮动响应的交互关系，不拷贝 Go/Pixi/React 的规则代码。
- `EpicOrange/riichi_advanced`（https://github.com/EpicOrange/riichi_advanced）：参考四川血战、多套规则共用牌桌的结构，仅研究视觉信息组织，**不移植 AGPL-3.0 源代码、美术素材或音效**。
- MahTrain 自有的 `web/assets/tiles` 图集与原先的 Python 血战规则/AI/公开事件接口保持不变；没有下载商业天凤的素材。
## 主要变化
1. 深蓝桌布、简洁座位铭牌、四边紧贴桌沿的暗手背、桌面下边连续的本家手牌和独立副露。
2. 14×4 四家固定弃牌矩阵以小型中央计数台为核心而不是围着一个巨大的框。牌墙图案仅是计数台周围的装饰，不伪装为精确的逐张牌墙状态。
3. `#match-wall` 平时是小巧的「血战到底 / 牌山余张」计数牌；换三张、定缺、碰杠胡、出牌确认时才扩展为中央操作区。只显示教程文字时操作卡不盖住计数台，所有弹窗仍不得碰到四家河牌/副露/手牌。
4. 牌背和河牌保留座次旋转方向及隐藏暗牌保护；自己摸牌在牌尾稍作分隔但没有覆盖性的浮动标签。
5. 桌面 701/1024/1440px 及手机 320/375/390/700px 继续执行 Chromium 56格完整河牌、四家定缺/副露、中央安全区和缩放可见性测试；新增中央计数台不得退化为巨大方框和本家手牌背景透明两项。
## 调整边界
AI牌力、血战规则、换三张/定缺、牌效计算、服务器私有牌数据和声音时长均未更改。小屏手机原有本家手牌横向查看保留；极端合成的「四家各四组副露且各家56河牌」仅用于几何极值，不是有效实战牌局。浏览器 Actions 通过不自动代表设计审美完全达到参考截图，建议对照用户实际桌面截图继续精修。
