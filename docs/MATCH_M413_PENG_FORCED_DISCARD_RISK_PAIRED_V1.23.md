# M4.13：碰牌后强制切牌风险与过牌选择的配对试验（v1.23）

## 转向背景

M4.12 的 [PR #112](https://github.com/CrazyA1ice/MahTrain/pull/112) 完成了 128 场权威自然配对实验，开发组0次明杠改碰、保留组2次；一次收益为正一次为负，预先冻结的候选未达到继续扩大研究门槛。因此不再围绕低频「同时可碰、可明杠」反复搜索阈值。

M4.13 改研究普通碰牌时的行动：碰牌一旦被允许并选中，玩家需要**马上切出一张牌**，不能只根据碰牌后的向听数或上牌总数判断有没有代价。公开牌河、定缺、其他玩家副露、剩余牌墙阶段等可能提示立即切牌的相对危险程度，但这些都只能是本人授权可见信息，不是对手暗手的真实点炮概率。

## 与历史实验 M3.95 的区别

M3.95 已实现 `no_tie_peng`，拒绝所有不改善严格向听数的原挑战级碰牌。这轮不是复制旧策略，而是提出**风险条件化**的研究候选：

- 仅在原挑战级真实选择 `peng`，牌局授权 `pass`、`peng`，且没有合法 `hu` 或抢杠胡、非天听保护时，考虑是否改为过牌；
- 先用本人真实授权暗牌、当前已公开的原弃牌种类，计算碰牌前向听及碰牌后的所有**合法即时切牌**的严格向听数，并遵守定缺强制优先出牌；
- **碰牌后严格向听改善**时，保留原有碰牌；当前已经听牌且碰后仍听牌也保留，避免把通过碰获得的进张或胡牌机会凭空删去；
- **仅当碰前后严格向听相等且大于0**，检查所有最佳向听切牌的公开危险总和 `read_discard_threat(tile, view)["risk_index"]`；若最佳候选中至少一张低于固定 **0.30**，保留碰牌；若所有最佳切牌均达到或超过 0.30，离线试验候选改为 `pass`；
- 基准臂永远只用原 `MahjongAgent("challenge")`，其余交换三张、定缺、手牌切牌、本人暗杠补杠与一切胡牌决策保持不变。

危险指数可超过1，不是 `P(Ron)`。所比较的是**碰后可选择的假设切牌**，不保证这张牌将在后续完整局面中真的被打出。本轮不使用墙尾、未来切牌、真实对手暗手，不宣称精确期望收益。

## 冻结实验与正式积分

开发组预定洗牌 **50000–50003**、独立保留组 **51000–51003**。每种子四个不同挑战级座位，每座位基准和候选各打一场完整108牌四川血战对局，共 **8个独立洗牌种子、32个配对位置、64场权威完整比赛**。

观测指标包括：基准AI实际选碰窗口、真实碰改过次数、各独立洗牌种子上的四座位平均正式净分差、胡牌积分差、杠钱积分差、流局积分差和其它行为频次。对任何**候选实际未干预**的位置，两臂必须保持相同的公开比赛事件、动作轨迹与全套官方积分；否则失败。官方净分必须逐场满足 `official_net=win_points+kong_points+exhaustive_points`。

所有汇总按**独立洗牌种子**计数，不将四个座位循环当成独立样本。完整游戏积分差反映整条对局路径上的实际结果变化，不能直接等同于本次碰牌动作的精确局部因果价值。

## 解释边界与上线条件

这是一项早期、探索性的**离线候选**。不根据小样本收益改门槛；若候选实际改选很少、开发与保留组方向不一致，或官方净分未证实提升，则如实保留负面实验结论。无足够大规模多独立种子稳定收益、严格合法性和实时性能证明之前**不修改正式最强AI**、不影响用户对战、训练复盘或胡碰杠提示。

现有规则代码、108张物理麻将、正式挑战级策略、页面交互与真实流局查大叫均不改动。只有最新提交的 GitHub Actions 专项和全量规则全部成功才允许合并研究文件。
