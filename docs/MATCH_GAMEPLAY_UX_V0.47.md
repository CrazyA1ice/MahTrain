# MahTrain M3.35：手机端四人牌桌与真实积分反馈（v0.47）

本轮继续响应参考网游截图的要求，**优先真实人机对战体验，不研究/不调参 AI**。基于原有本地麻将 PNG、CSS 桌面以及服务端可信牌局状态，不借用参考网游的商用角色、桌布、图片资源，也不增加新网络依赖。

## 1. 手机竖屏四家完整牌桌

此前规则 M3.24 为了放大牌河，将整个桌面的最小宽度设为 `1250px`。在手机上用户需要滑动整张牌桌才能看到上下家与牌墙。本轮在屏幕宽度不超过 **700px** 时，桌面改变为**视口内的三列四座位结构**：对家在上、上家在左、下家在右、本人在下，牌河在中央四方紧邻牌墙。

- 牌河卡片与侧边牌背缩为小屏专用尺寸；竖向牌河只滚动牌河本身，不让整个桌面水平移动。牌墙仍只显示公开剩余牌数，不伪造牌墙上的真实牌序。
- **自己的手牌仍保持清晰大图**。14 张手牌通常无法在一部竖屏手机中同时以50px以上宽度显示，因此允许仅在手牌区域单独左右滑动；最右侧新摸牌与同值的旧手牌继续保持分离。用户可用 M3.34 的“放大手牌”切换。
- 大屏仍保留原 1250px 高信息密度牌河与副露布局，不将桌面上全部牌面强行缩小。

## 2. 碰杠胡大字动作提示

沿用既有真实公开动作回放：碰牌显示醒目的“碰”，各类杠显示“杠”，自摸显示“自摸”，普通点炮胡显示“胡”，一炮多响显示“一炮多响”。文字在现有牌桌中心的动作说明卡中出现，**不新增一次服务器操作，不伪造中间牌墙、暗手或牌序**。

原有的逐步回放、播放速度、暂停、单步、跳过、关闭回放与语音播报不受影响。若浏览器设置“减少动态效果”，大字与积分提示会关闭视觉动画但保留文字内容。

## 3. 真实 `+800 / -800` 风格的积分动效

- 服务器在发生合法胡牌付款后，除了此前的 **赢家累计实收**、番数、来源，还公开这笔**已正式记账的**每付款者金额 `amount_per_payer` 与付款座位 `payers`。均从 `WinLedger.pay_win` 实际结果生成，属于已公开零和流水，不含私人牌或猜测付款。
- 浏览器通过受限字段白名单解析，验证座位编号 0—3、付款座位无重复、付款额×付款者数量等于赢家实收。有效时会在每个相关座位附近显示正/负号，例如一人点炮被两位玩家分别胡出800分，同一帧分别在两个赢家座位显示 `+800`，付款人显示 `-1600`；这是**实际同时记账**的积分，不是一律显示 `800` 的占位符。
- **自摸**时按真实三家付款比例显示赢家 +实收、三位未胡玩家分别 -单人实付。金额来自服务器，不根据番数在客户端重新计算。
- 对旧服务器的回放，如果只包含赢家实收，仍可显示这一笔已确认入账的赢家积分，不会为了凑动画假定“其他三家各扣多少”；完整结算表仍为最终标准。
- 关闭回放（速度0）时，也可直接通过本次返回的**新增已入账胡牌**显示正负变化。打开新局会清除上一局动画；普通计分表、方案A流局正式积分与独立模拟杠钱保持各自原有口径。**本轮只让胡牌付款浮字化**，没有把尚未核验的流局或实验杠钱伪装成胡牌。

## 4. 桌面视觉细节

最近弃牌增加柔和高亮，不遮挡牌面。得分浮字锚定本人的下方、下家的右侧、对家的上方、上家的左侧，醒目但无法点击，避免妨碍选牌。手机下缩小浮字，桌面仍能操作。
