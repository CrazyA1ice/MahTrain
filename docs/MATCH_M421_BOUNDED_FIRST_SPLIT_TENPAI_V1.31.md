# M4.21：有限步前瞻首次真实改切及后续上听、权威结算复盘（v1.31）

## 已合并 M4.20 的实证背景

上一轮 [PR #120](https://github.com/CrazyA1ice/MahTrain/pull/120) 已完成测试并并入 `main`，部署最强AI并**未**改动。冻结的离线有限步摸切候选在开发组60000–60002、保留组61000–61002（共6个独立初始洗牌、48场配对对局）分别发生 **1 次真正改切**；每组的官方胡牌、杠钱、流局净分差均为 **0**。候选使用2个首切、各最多6类公开未知摸牌、每位置2个前瞻窗口。此前已验证的“模型假设第2步较优”不能直接证明上听提前或减少放铳。

**本轮 M4.21 不开发、调参或验证新的切牌策略。** 重新运行原样已合并的 M4.20 基准与候选，只研究这两次真实改切的首个动作分歧、后续真实打成听牌的观察次序、整局权威积分是否发生变化，以及模型分支收益高的原因。历史洗牌已用于 M4.20，因此本轮是**事后复盘，不是新的留出集验证**。

## 复盘定义、信息边界

- 在原 `BoundedLookaheadResearchAgent.discard()` 做完授权合法切牌选择后，由单独的离线子类 `FirstSplitBoundedAuditAgent` 观察确实改切的决策。用原当次最小严格向听排名验证：两种首切都为严格一向听、有效进张至少保留70%、公开风险增量最多0.12，并且分别按照未改动的 `projected_branch_score` 重新计算有限分支评分，验证候选至少为原选的1.12倍（浮点边界按M4.20已有的1e−8修正）。
- 对两条真实规则对局，使用原 M4.15 的 `first_real_discard_divergence` 在保留于可信模拟器内存中的**完整动作轨迹**核实：第一条不同动作必须是同一座位本家、同一事件位置实际切出不同麻将牌，两臂切后严格最小向听均=1，且之前轨迹完全相同。日志**不得**导出两种具体切牌、暗手、其他玩家隐牌、未来牌墙或原始完整动作轨迹。
- 在两个完全分叉的真实对局中，从第一个改变的动作之后逐个查看**本家后来真正执行的弃牌**：最早出现 `shanten_after==0` 的一张视为「首次**观察到**后续打出听牌状态」，记录从首次分歧到此事件间的完整动作事件数量、此人之后第几次弃牌。**如果本家在另一次弃牌显示0向听之前就胡牌、流局或没有更多可观察的弃牌，则将这个指标标记为右删失（censored），不能简单判作一直未听。** 若两臂都确实观察到后续0向听，才比较分别所用的本人额外弃牌次数。这个计量不是完整“从抽牌到立直”的胜率，也不是跨两条分叉牌墙因果相同的对照。
- 真实终局状态再复用 M4.16 的 `audited_terminal`，核对其本家官方查大叫、花猪付款及真实流局听牌／未听／已胡类别（终局若三人已胡不能凭空产生查大叫）。全部正式 `official_net` 必须等于 `win_points + kong_points + exhaustive_points`，且流局额等于 `flower_pig + da_jiao`。仅返回本家终局类别、听口**数量**、有效最高番数，以及本家实际积分；不泄漏别家暗手或听口。
- 用于探索决策价值的预测比值、摸牌分支覆盖率都是**原M4.20的截断代理**，不是校准后的下一巡上听概率或官方行动期望净分；分析属于完整游戏分叉的事后描述，不能直接把后续“变快、变慢、分数相同”因果归结到一张切牌。

## 冻结复现组和验收

开发组原始洗牌60000–60002和保留组61000–61002，各3独立洗牌×4轮换座位×2策略=24场真实完整对局；共**48场规则权威比赛**。两个历史独立块必须各复现 **1次真正不同切牌、1个发生改切的座位配对、全组胡牌／杠钱／流局／总净分差均0**。没有改切的11座位配对，两臂动作轨迹、公开事件、终局结算须完全一致。

每个真实改切必须由正确的首次真实动作分歧支持；对比分歧时前后事件位置、真正弃牌次序、本家听牌观察指标、是否删失、预测代理比值和终局真实账本。两臂后续动作可能不同，即使账本相同也不能推断候选改善等价或无作用；6个独立种子中只有2个受到真实干预，不足以支持统计优势。
