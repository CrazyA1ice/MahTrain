# M4.00：公开场况补杠风险与离线抢杠胡合法性标签

## 研究问题

前几轮已看到真实补杠机会极少，同一个补杠候选可能在连续若干巡反复出现。M3.99自然样本的64局中，真实成功补杠3次，实际抢杠胡0次。**这不能证明所有未执行的补杠都没有抢杠风险**，因为旧统计只能标记规则已执行的补杠。M4.00增加一项区别于真实行动的新标签：在玩家**有机会选择补杠、尚未作出选择**时，其他未胡牌玩家中，究竟有多少人的真实暗手**具备规则上的抢杠胡资格**。

此后分离两套严格独立的输入：

- **公开预测特征**：只能访问 `FourPlayerOpening.public_state()` 的当时公开信息，再附加玩家已公开的碰牌牌种。严格限制为公开定缺、活跃对手、已副露数量/花色集中度、弃牌记录和剩余墙牌数量。牌种是**已公开碰牌**，不能推断其他暗手。
- **受信任的离线参考标签**：只在 `_sealed_potential_robbers` 中访问其他玩家当时的暗手，按正式 `is_legal_win` 判断对这张补杠牌是否能合法抢杠胡。仅输出合计人数和是否存在候选；不会把暗手、牌墙、听口或牌种发给模型、在线接口和回放系统。

**标签“潜在合法抢杠胡”不等于真实有人抢杠胡！** 真实玩家可能没打算抢、杠不一定执行、未来分歧也不可从历史标签直接预测。此研究不涉及推断未来牌墙、强制改变对手行动或假设对手一定胡。

## 预先冻结的公开风险类别

按以下优先级标注（都是粗糙的定性类别，不是估计成功率或部署模型）：

1. `dingque_excluded`：所有仍活跃对手定缺恰好是该张已公开碰牌的花色。在目前定缺胡牌规则下，对这张牌不存在合法抢杠胡者；但不代表补杠本身总体收益最优。
2. `same_suit_focus`：至少一名在定缺规则下可能胡这张牌的对手，公开有**至少两副同花色副露，且该花色与补杠牌相同**。
3. `exposed_pressure`：规则上可能胡这张牌的对手拥有合计至少两副已公开副露，但未命中上述同色集中度。
4. `unresolved`：其余场况。**不能**把本类理解成安全，也不能把没有公开副露推断为没有听牌。

完整公开特征还包括活跃对手数、定缺不排除的对手数、对手同花色副露数、其他玩家此前打出同牌/同花色牌次数、自家已公开副露数和前/中/后墙牌阶段。

**先在代码中冻结类别，再研究独立样本**。即使后来发现某个类别与收益关联，禁止按已经看到的少量案例事后修改门槛再声称进行了独立保留组验证。

## 真实自然对局的取样与独立性

与 M3.97–M3.99 不重叠的全新种子：

- 开发：24000–24007
- 独立保留：25000–25007
- 每组8个原始洗牌种子，各做四席轮换，总计64个全局规则真实对局。
- **不筛选一定出现补杠机会的种子**，即使两组没有任何可补杠或抢杠可行者，也必须如实报告“无法校准”。
- 取样时刻是自己的合法可补杠决策**之前**，不改变当时挑战级 `MahjongAgent.kong` 结果，且已确认可自摸胡时本次窗口不纳入。
- 同一局同一座位同一补杠牌再次成为候选时仅记录重复次数，**不重复计算其首次抢杠标签**；内部按具体牌种做去重，输出绝无该身份信息或可逆哈希。
- 完成每局后按规则公开事件验证实际宣告补杠＝成功补杠＋被抢杠，并核验权威胡牌/杠钱/流局分账。

主分析为**按原始独立洗牌种子四座位聚合后的覆盖率与标签可用性**，不是把所有候选当作独立对局。分类只有观察到实际正负标签并且来自足够多个独立种子时才有讨论预测意义；默认 `estimated_rob_probability:null`。本轮不使用任何未来胡牌结果训练策略权重。

## 使用说明

```bash
python -m unittest discover -s tests -p 'test_m400_public_bugang_rob.py' -v
python examples/evaluate_public_bugang_rob_pilot.py --seeds 8 --output results/m400_public_bugang_rob.json
```

GitHub Actions `.github/workflows/m400-public-bugang-rob.yml` 运行真实对局并检查公开特征不读取私有字段、标签不改变牌局、同牌机会去重、胡牌合法性和权威零和账本。完整审计结果作为单独 artifact 保存30天。

## 推广限制

本轮不会修改在线挑战级策略。未来即使在某些种子里存在“潜在抢杠胡”的真值，也只能用于研究一个**公开场况模型**是否在从未见过的独立种子中有预测能力。没有这样的证据不能认为“无副露的对手安全”，更不能用实际隐藏牌墙或对方手牌算在线最优补杠。
