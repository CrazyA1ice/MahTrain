# M3.99 · 补杠重复机会去重、真实抢杠胡风险审计和独立终局验证

## 目标与改动边界

M3.98 已对64局**未筛选自然对局**统计碰杠机会，发现保留组11次可补杠窗口中有9次集中在种子17004。可补杠窗口数≠独立补杠决策数，更不等于“错过九次收益”。此外，规则引擎的 `bu_gang_declared` 仅表示**提出**补杠；对手可以抢杠胡，只有 `bu_gang` 事件才表示真实完成补杠并计入杠钱。

本轮不改变 `MahjongAgent`、在线 `web_server.py`、任何牌桌前端和权威规则。新增纯离线 `src/mahtrain_core/ai_bugang_repeat_risk.py` 统计下列不同层次：

- **自然操作窗口数**：挑战级当前轮到自己且可以合法暗杠／补杠，每次真的有牌可杠算一个窗口。
- **合法候选数**：一次窗口可同时存在多个暗杠／补杠候选，候选数可以大于窗口数。
- **同牌首次出现数**：仅在可信分析进程内部以 `(kind,tile)` 为键，对本玩家在一局中的同一暗杠／补杠候选做去重，不向结果输出任何牌名、加密牌名或指纹。
- **重复出现数**：同一合法候选在后续轮次再次被提出（当次只算一次）；另统计“期间曾不在合法候选中、之后再次出现”的返回机会数，避免误称每次候选都来自不同物理牌组。
- **原挑战级实际决策数**：可杠时真正选暗杠、补杠还是直接出牌，不能以合法次数反推执行次数。
- **补杠宣告／成功／被抢杠**：必须用真实规则引擎终局公共事件及赢家校验 `declared = successful + robbed`。一炮多响可以产生多个抢杠胡赢家，但仍只有**一次**被抢杠的补杠宣告。
- **抢别人补杠胡的机会**：若自己是合法抢杠响应方且规则引擎确认可抢杠胡，计数真实行动，绝不拿对手暗牌模拟抢杠概率。

局内身份只在可信观察类的集合中保存，不导出包含具体麻将牌名、暗手、真实未知牌墙及种子可逆牌序的隐秘快照；JSON仅存公开动作类别、计数、按座位官方终局净分。若导出中发现暗手或未知牌墙字段，CI应失败。

## 两组独立实验（预先固定，不因是否出现补杠而重抽种子）

| 实验 | 开发组 | 保留组 | 目标 |
|---|---|---|---|
| 自然补杠去重和抢杠审计 | 连续种子20000–20007 | 连续种子21000–21007 | 各8独立种子×四席；合计64局完整自然对战 |
| 首次自身暗杠/补杠反事实 | 连续种子22000–22007 | 连续种子23000–23007 | 各8独立种子×四席；64个首次自身可杠目标位置 |

第二项实验不挑“确实有补杠”的局；仍以**首次可杠的自然机会**为目标，执行 M3.97 已验证的三种冻结策略：原挑战级、强制不杠、强制选择第一个合法积极杠，然后让原来的四家 AI 打到真实终局。

- 禁止覆盖合法自摸／抢杠胡，包括多响；起始同洗牌、同座位、同授权操作前视图，不匹配就报错。
- 总分＝胡牌分＋杠钱分＋流局分，所有真实局都要验证108张牌守恒、三本零和分账与官方结算一致。
- 主要指标是**先对一个独立洗牌种子的四席均值汇总，再跨独立种子求均值**。不得把回合、候选、座位轮换和抢杠响应当成独立种子。
- 分组有8独立种子并不保证获得8个实际杠牌干预；若太稀少，仍将置信区间标为 `null`、把缺机会组如实标注缺覆盖。不使用事后最优种子筛选，不尝试把未来墙牌填入在线 AI。

## 运行

```bash
python -m unittest discover -s tests -p 'test_m399_bugang_repeat_risk.py' -v

# 8+8独立种子，四席轮换，终局真实补杠声明/落地/被抢杠
python examples/compare_challenge_bugang_repeat_risk.py --mode natural --seeds 8 --output results/m399_natural.json

# 全新8+8独立种子，强制不杠/强制积极杠，只干预首次可选杠一次
python examples/compare_challenge_bugang_repeat_risk.py --mode paired --seeds 8 --output results/m399_paired.json
```

CI工作流 `.github/workflows/m399-bugang-repeat-risk.yml` 将两组实验分两份并行执行，验证零和、重复候选数守恒、合法动作、隐牌访问边界及分组不重叠，并将去敏 JSON 保存为可查验的GitHub Actions artifact。

## 后续 M4.00

若出现被抢杠成功的补杠案例，再结合**公开信息**下的对手听牌迹象、尾牌阶段和剩余有效张，设计不读取对方暗手的风险代理。必须在新独立对局种子验证对正式净积分是否稳定有效，才能尝试对线上挑战级补杠逻辑做受限升级。不能用已知对方暗手、反事实实际结算来代替在线时的概率。
