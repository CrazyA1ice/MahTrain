# M3.99 · 补杠重复机会去重、真实抢杠胡风险审计和独立终局验证

## 目标与改动边界

M3.98 已对64局**未筛选自然对局**统计碰杠机会，发现保留组11次可补杠窗口中有9次集中在种子17004。可补杠窗口数≠独立补杠决策数，更不等于“错过九次收益”。此外，规则引擎的 `bu_gang_declared` 仅表示**提出**补杠；对手可以抢杠胡，只有 `bu_gang` 事件才表示真实完成补杠并计入杠钱。

本轮不改变 `MahjongAgent`、在线 `web_server.py`、任何牌桌前端和权威规则。新增纯离线 `src/mahtrain_core/ai_bugang_repeat_risk.py` 统计下列不同层次：

- **自然操作窗口数**：挑战级当前轮到自己且可以合法暗杠／补杠，每次真的有牌可杠算一个窗口。
- **合法候选数**：一次窗口可同时存在多个暗杠／补杠候选，候选数可以大于窗口数。
- **同牌首次出现数**：仅在可信分析进程内部以 `(kind,tile)` 为键，对本玩家在一局中的同一暗杠／补杠候选做去重，不向结果输出任何牌名、加密牌名或指纹。
- **重复出现数**：同一合法候选在后续轮次再次被提出（当次只算一次）；另统计“期间曾不在合法候选中、之后再次出现”的返回机会数，避免误称每次候选都来自不同物理牌组。
- **原挑战级实际决策数**：可杠时真正选暗杠、补杠还是直接出牌，不能以合法次数反推执行次数。
- **补杠宣告／成功／被抢杠**：必须用真实规则引擎终局公共事件及赢家校验 `declared = successful + robbed`。一炮多响可以产生多个抢杠胡赢家，但仍只有**一次**被抢杠的补杠宣告。
- **抢别人补杠胡的机会**：若自己是合法抢杠响应方且规则引擎确认可抢杠胡，计数真实行动，绝不拿对手暗牌模拟抢杠概率。

局内身份只在可信观察类的集合中保存，不导出包含具体麻将牌名、暗手、真实未知牌墙及种子可逆牌序的隐秘快照；JSON仅存公开动作类别、计数、按座位官方终局净分。若导出中发现暗手或未知牌墙字段，CI应失败。

## 两组独立实验（预先固定，不因是否出现补杠而重抽种子）

| 实验 | 开发组 | 保留组 | 目标 |
|---|---|---|---|
| 自然补杠去重和抢杠审计 | 连续种子20000–20007 | 连续种子21000–21007 | 各8独立种子×四席；合计64局完整自然对战 |
| 首次自身暗杠/补杠反事实 | 连续种子22000–22007 | 连续种子23000–23007 | 各8独立种子×四席；64个首次自身可杠目标位置 |

第二项实验不挑“确实有补杠”的局；仍以**首次可杠的自然机会**为目标，执行 M3.97 已验证的三种冻结策略：原挑战级、强制不杠、强制选择第一个合法积极杠，然后让原来的四家 AI 打到真实终局。

- 禁止覆盖合法自摸／抢杠胡，包括多响；起始同洗牌、同座位、同授权操作前视图，不匹配就报错。
- 总分＝胡牌分＋杠钱分＋流局分，所有真实局都要验证108张牌守恒、三本零和分账与官方结算一致。
- 主要指标是**先对一个独立洗牌种子的四席均值汇总，再跨独立种子求均值**。不得把回合、候选、座位轮换和抢杠响应当成独立种子。
- 分组有8独立种子并不保证获得8个实际杠牌干预；若太稀少，仍将置信区间标为 `null`、把缺机会组如实标注缺覆盖。不使用事后最优种子筛选，不尝试把未来墙牌填入在线 AI。

```bash

# 8+8独立种子，四席轮换，终局真实补杠声明/落地/被抢杠

```

## 真实执行结果（2026-10-22）

[GitHub Actions M3.99 专项成功运行](https://github.com/CrazyA1ice/MahTrain/actions/runs/39787776506) 已完成两个8+8独立种子组以及单元测试，真实执行结果分别保存在 Actions artifact：`m399-natural-bugang-audit` 与 `m399-first-kong-eight-seed-holdout`（若30天后过期，版本化文档仍保留重要指标）。下列数据来自**已完成工作流实际日志**，不是实验计划数字。

开发组6次可补杠候选来自**种子20006的一名挑战级座位在不同巡的同一个候选**，只有1种牌组首次出现、之后重复5次。这直接证实了过去将多个“可补杠窗口”当成多个独立可杠决策、再对“过牌”计错的风险。另有种子20002同一暗杠候选跨巡累计4次，其中3次是重复提供。

保留组4次补杠候选来自3个不同牌组；其中2次出现在种子21004、1次在21005的实际成功操作，另1次是重复候选。两组共计**3次真正完成补杠、0次真实被抢杠胡**，不能据此推出抢杠概率为零；构造的多响场景单元测试已验证一次补杠宣告被多人抢杠仍仅算一次失败补杠。

### 首次自身可杠反事实：8＋8独立种子、64个预先固定目标位置

以下净积分变化均为 **研究策略减原挑战级**；每组独立洗牌种子各四个座位先平均，再跨8独立种子取均值，**没有筛选含杠机会的种子**。

| 观察指标 | 开发组22000—22007 | 独立保留组23000—23007 |
|---|---:|---:|
| 首次自身可杠的目标位置数 | 6 / 32 | **1 / 32** |
| 强制过：真实改变操作次数 | 4 | 1 |
| 强制过：平均正式净积分差 | **-31.8125** | **-9.4688** |
| 强制积极杠：真实改变操作次数 | 2 | **0** |
| 强制积极杠：平均正式净积分差 | +37.7812 | 0（未发生真实干预） |

开发组“强制过”的4个改动在全部座位中累计正式净分 **-1018**：胡牌账本差-1100、杠钱差-18、流局差+100。保留组唯一真实改动也使净分 **-303**：胡牌账本差-300、杠钱差-3。

开发组“强制积极杠”的两个实际干预，合计净分 **+1209**（胡牌账本-400、杠钱+9、流局+1600），但**全部正向结果只来自种子22002的四席平均+302.25**；其余7个种子为0，其中很多根本没有可杠机会。保留组唯一机会中挑战级本来就杠，因此“强制积极杠”没有改变任何动作，0净分差意味着**本实验未检验到该策略**，绝不能宣称对照已证明它与原策略相同。

### 研究解释与决定

1. 两组自然对照均成功揭示“重复提示”和“独立候选”数量差异，且符合真实合法选项和完整官方结算。实际抢杠风险在本批64局没有发生；无法估计其概率，不能利用0事件放松防守。
2. 关闭原本选择的杠在两组中都出现负的真实净积分变化，但只有**5个被实际改变的目标位置**，且两组含机会种子占比很低，不足以得出“应该永远杠”的普遍规则。
3. 将原本不杠强制改为杠的开发组正收益由**单一初始种子**驱动，保留组根本没有改变过该动作，无法进行独立结果复现。不能上线“更积极补杠”的规则。
4. 按预先固定的分组执行的正式全局账本、真实多人抢杠合法胡牌保护、完全不读取未来未知牌墙作为线上输入和不按事后收益抽样的校验通过。
5. 正式挑战级策略及网页行为均**保持原状**。后续应研究可观察的**对手公开副露、防守强度、杠牌尾牌阶段**下的补杠风险代理，并使用另外全新独立种子进行检验；不能把 M3.99 所看到的完整未来结算当作在线 AI 的预测值。
