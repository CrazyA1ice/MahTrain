# M3.73 · E 方案经典 2D：不再弹出弃牌提示，桌面大小完全固定，AI 胡牌持久标记

## 用户报告与改法

之前每个 AI / 玩家公开弃牌、碰杠都会在牌桌上方新增/隐藏 `classic-live-action` 条幅，`resize()` 又根据条幅高度重算 `#board` 的整体缩放，导致**同一局中桌面不断上下跳动、缩放和重新排版**。胡牌高亮则仅存续 1～1.65 秒，随着下一张牌出现会消失，视觉上不知道谁已经胡了。

现在：

1. 彻底移除上方动态操作条 `classic-live-action` 的 HTML、动作插入和旧 CSS。**普通弃牌、碰、明杠、暗杠、补杠不再新增顶部弹出信息条**，仍有麻将牌河、公开副露和用户已开启的原版中文语音。
2. 经典 2D 整张牌桌的缩放比例只由**视口和固定高度工具条**决定，不再根据任何胡牌记录或公开事件临时更改。顶部操作状态栏预留固定行高，避免字符串长度变化造成额外布局抖动。
3. 原版 Majiang 四家固定位置姓名牌中加入清晰的**金色「已胡」常驻徽标**。当前玩家/AI 的 `won[seat]` 或服务器正式 `win_ledger.wins` 记录存在即可出现，后续对局继续、碰杠、网络恢复、刷新均重新计算并显示；一炮多响各家分别独立标出；未胡玩家不误标。
4. 每家原有**桌面中央计分区域**在已胡时显示已确认的「自摸/点炮/抢杠」「中文主番型」「有效番数」，详细信息也可悬浮在姓名牌标记中查看，绝不从暗手推测具体番型。
5. 原先的完整胡牌历史明细移动至**整张牌桌下方、最终结算表上方**。胡牌后即使追加更多赢家也只延长**牌桌之后**的内容，不会移动牌桌本身。
6. 不修改 kobalab/Majiang 原版实体牌、牌背、牌河和四川血战 Python AI、游戏计分、完整收支表和现有语音播报。终局自动定位完整结算仍保留。

## 实际测试

- `frontend_2d/test/seat-status.test.mjs`：服务端单赢家、多人胡、中文番型、恢复、无详情时仅出现已胡提示、不泄露私人牌值。
- `frontend_2d/test/browser-fixed-table.mjs`：真实 Chromium 连续弃牌、AI 自摸后继续弃牌、1.95秒等待、刷新只读恢复；每一步与初始牌桌坐标、宽高、缩放完全一致；无 `classic-live-action` 动态条；AI 金色已胡标记持续。
- `frontend_2d/test/browser-settlement.mjs`：原模拟一炮多响的浏览器测试改为验证两个赢家同时有常驻标记、输家无标记、顶部不出现动态条、胡牌历史位于牌桌下方、双方真正中文番型；语音和最终结算表继续有效。
- `frontend_2d/test/browser-real-round.mjs`：真实 Python 对局恢复时核对 `won` 席位与四张姓名牌的实际常驻标记相同，且没有旧动作提示条。
- CI 为新前端编译 `frontend_2d/dist/`，用户只需 `git pull origin main` 并重启 `python web_server.py`。刷新时建议 Ctrl+F5。

## 设计约束

保留原生 Majiang 800×680 四人桌面，姓名牌尺寸固定为160×30、中心计分字段有固定宽度、过长名称省略号显示，完整具体番型在鼠标悬停/屏幕阅读器文本可查。状态反馈无需新建任何影响文档流的上方 UI。
