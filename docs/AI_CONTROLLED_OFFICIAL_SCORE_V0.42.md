# MahTrain M3.30：三档 AI 固定规则、配对洗牌与正式积分对照（v0.42）

上一轮 M3.29 的历史分组属于观察性统计，不能排除房间规则、种子、座位和对手阵容造成的混杂。这一轮在**现有 M3.6/3.8 三档 AI 自动对局**中增加独立的**方案A正式净积分**审计，不再重复模拟或引入新的观察口径。

## 实验协议

- 每个独立种子对应真实同一套108张牌的起始洗牌；对入门/进阶/挑战三档启发式 AI 执行三轮座位循环。同一 AI 档位每个种子在0至3号席位上**各出现一次**，因此每档每种子共有4次“座位出场”。
- 固定同一份游戏代码和房间规则：`room_coefficient=100`、`fan_cap=3`、`kong_base=None`。AI 选牌会影响后续轨迹；**同种子不代表不同策略面对完全相同的后续行动轨迹**。
- 记录胡牌净额 `partial_win_balances` 和服务端正式已入账净额 `official_settled_balances`（胡牌 + 真实牌山耗尽后规则方案A的查花猪/查大叫）。模拟杠钱没有正式入账。
- 每局四席正式净额必须零和，三轮合计按策略分类也必须零和；本实验**完全不依赖网站上的用户历史档案**。
- 如果某局 `wall_exhausted` 而不能核验流局结算，**整个种子的三轮一起排除**出正式积分比较，不把未结算的差额写成零，也不把三轮当成三个独立样本。报告列出排除的种子 ID 和数量。
- 每档报告：有效种子、有效座位出场、正式积分净额总量、每次出场均分。配对差为“挑战－入门”“挑战－进阶”，按同一批完整种子比较。
- 至少5个有效独立种子时，使用固定随机数生成器执行种子簇 bootstrap 的**探索性区间**；它仅反映已选初始洗牌种子上的有限波动，绝非真实玩家胜率置信区间或策略优越性的证明。
- 所有公开统计只包含整数积分、档位名称、对照种子与坐席数量，不包含任何对手暗手、未公开牌墙、私有牌效或真实用户会话令牌。保留 M3.8 的原始胡牌事件、切牌质量指标、公开逐步回放及 M3.9/M3.10 独立对照。

## 页面操作

本地运行 `python web_server.py`，访问 `http://127.0.0.1:8765` 的 **M3.8 AI决策公开解释与种子对照统计** 栏目。该栏目同时承担 M3.30 的实验室入口：

1. 设置起始实验种子以及独立种子数（1/2/5），点击“开始多回合AI评测”。
2. 完成后“**M3.30 受控正式积分对照（方案A）**”区域显示房间规则、有效/排除种子、三档正式积分和配对差值。少于5个有效种子时只显示点估计；对未结算的对局绝不虚构积分。
3. 点击“导出正式积分种子对照 CSV”，获取每个**已核验**的独立种子三档实际总积分和出场均分。
4. 仍可切换原来的公开回放，检查行动及相关规则，不暴露隐藏牌。

**注意**：正式积分只是此项目规定的试验室结算积分，非现金，也不是含真人行为的实证统计。本版本实现了可信的受控度量，不声称三档模型性能实际提高。
