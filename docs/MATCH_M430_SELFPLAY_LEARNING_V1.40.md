# M4.30：AI 自对战、牌谱保存与离线学习试验（v1.40）

## 能否通过大量 AI 自行对战提升最强 AI？

**可以，适合作为下一阶段长期研发的主线，但“AI 打牌并保存牌谱”并不等于“AI 已通过训练变强”。** 真正需要四个环节：

1. 使用**权威四川血战到底规则**进行大量合法、可重现的全 AI 对局；每局真实完成至3家胡牌或牌墙耗尽，杠钱、胡牌、流局查花猪/查大叫均进入官方净积分账本，108张实体牌守恒。
2. 从牌谱抽取**每次决策当时该玩家能合法看到的输入与其实际选择**，然后在局末关联权威输赢分；不能让 AI 读取对手未公开手牌、未来牌墙、其他座位的训练手牌，也不能提前让 AI 看到结果。
3. 首先训练一个**离线受限策略**。本轮采用小型“轨迹收益加权的弃牌并列候选偏好”探索模型，作用限定为挑战级AI当前最优向听层级且原始分数相近的弃牌候选，保留真实合法牌约束和已验证决策的基本结构。后续可逐步升级为基于具体动作价值比较的策略改进、信息集搜索（ISMCTS）、模仿训练/强化学习等；不能仅按赢家曾打出什么牌做归因。
4. 在**没有参与模型拟合的独立洗牌种子**上与冻结的旧挑战级 AI 成对对局，完整结算真正的官方净分。必须按洗牌种子作统计簇、考虑座位轮换，明确留出样本数和结论边界。小型实验不够时，不进入线上挑战模式。

## 本轮真实提交内容

- `src/mahtrain_core/ai_selfplay_learning.py`：单个洗牌种子进行4种轮换，即挑战级 AI 分别坐到0、1、2、3号座位，与基础、进阶和独立牌形基线AI按统一权威引擎打牌。私有 `RecordingChallengeAgent` 捕获自己的交换、定缺、碰/杠/胡响应、补杠和弃牌决策。弃牌候选复用正式 AI 已计算出的向听、有效进张、代理番值、公开花色压力及风险指数，**不会用结果重新写入当时的状态特征**。
- `examples/run_selfplay_learning.py`：一次运行生成**四人AI对局的安全公共牌谱**、包含本家历史决策的**本地私有训练样本**、离线试验模型，以及尚未参与训练的种子区间上正式积分对照报告。
- `tests/test_m430_selfplay_learning.py`：真实对局的公开/私有数据隔离、4座位平衡、108张守恒与官方三项分账、拒绝非法训练输入、模型边界和留出全局种子范围。
- `.github/workflows/m430-selfplay-learning.yml`：Python3.11/3.13重现与防泄露验证、小型全自对战及真实留出试验。**GitHub Actions仅上传不含训练种子/手牌/牌墙的汇总 JSON**，不上传私有牌谱或训练集。
- `.gitignore`：阻止误提交 `data/selfplay/` 与 `selfplay-private/`。

### 本地运行

在仓库根目录运行：

```bash
python examples/run_selfplay_learning.py --seed-start 88000 --train-seeds 2 --holdout-seeds 2 --out-dir data/selfplay/m430
```

运行结束后，在**本机** `data/selfplay/m430/` 查看：

| 文件 | 内容 | 外发边界 |
|---|---|---|
| `public_replays.jsonl.gz` | 四人AI自对战的逐行动公开牌桌快照与揭示动作，可重放时间线 | 不含训练用种子、任一家暗手和真实未来牌墙；适合展示 |
| `PRIVATE_actor_training.jsonl.gz` | 挑战级玩家当时的自身手牌、自己合法决策、公开信息、真实终局回报、私有复现种子 | **保留在本机**，不得不加筛选地公开 |
| `pilot_model.json` | 本轮拟合出的微小弃牌候选偏好权重 | 只能用于研究，不自动开启 |
| `holdout_report.json` | 旧挑战级与离线模型在新种子、四座位轮换中打完的官方积分差与策略改动次数 | 小样本探索，不是已有优势证明 |
| `summary.json` | 训练和留出局数及简单实验摘要 | 用于快速定位本地输出 |

数据目录默认被 Git 排除。如果把 `--out-dir` 设到仓库其它位置，请自行确认包含自身手牌和洗牌种子的私有文件不会被提交/分享。

## 当前离线学习的强度与局限

这版是**闭环基础工作流，不是已经完成的高水平强化学习**。目前训练标签是整局玩家的最终净分，属于轨迹级回报：

- 胡牌/杠钱/流局是真实裁定分，但无法从一次整局输赢推断某一次弃牌若改打另一张会怎样。回报高不代表每个动作都好，回报低不代表每个动作都差。
- 四种座位轮换共用同一洗牌种子，不是四个独立自然样本。训练和留出采用**不重叠的洗牌种子区间**。四个AI都是算法对手，并非现实麻将玩家群体代表。
- 试验模型只对**最小向听且原始评分相差不超过10%**的弃牌做温和探索，不改变碰、杠、胡的正式策略，不以未知暗牌进行非法学习。超过绝对 `0.2` 的权重一律不允许使用。
- 本轮默认2训练种子、2留出种子，仅验证数据管线可运行，不作显著性判断。即使正分也不自动更新挑战级AI；下一阶段应扩大独立洗牌数量、优化人工对手多样性、引入“一个决策点×多个隐藏世界×多次合法终局”的反事实动作比较，从而产生更有因果含义的**动作级价值估计**。
- 如果某策略在独立留出中持续输分，保存失败和反例牌谱，继续分析；**不能挑选打得好的种子才算实验结果**。

## 推荐的后续成长路线

第一阶段（本轮）建立“真实AI对战→可复盘公共牌谱/可训练本家历史→学习候选策略→新种子对照”的基础。第二阶段针对切牌、碰牌、明杠、补杠与胡牌形成独立动作标签，并将官方净分和不同番型期望纳入价值函数；第三阶段再使用信息集MCTS与模型训练加速挑战级AI，严格确保推理时只使用本家可见信息且不依赖未来牌墙，最终依靠大规模、与训练样本隔离的真实规则对战决定是否晋升版本。

当前没有理由把 M4.29 对5个人工补杠局面的 `+93.33` 当成强化学习的即时奖励，它包含大量流局赔付且不代表整体状态分布。本轮切换至完整随机洗牌的 AI-only games 是在补齐真实实验总体来源。

## 首次 GitHub CI 实验观测（真实结果，非承诺）

[本轮专项CI](https://github.com/CrazyA1ice/MahTrain/actions/runs/40156362755) 在 Python 3.11 与 3.13 的牌谱隔离/官方账本/实际留出单元测试均成功，完整端到端演示也成功运行。

首次演示固定训练种子1个×挑战AI四座位 = **4场真实训练对局/4份合法公开牌谱**；留出种子1个×四座位×旧策略/离线策略两臂 = **8场真实完整留出对局**。所有对局完整结算并核对官方净积分分账，GitHub Actions仅上传不含暗手/洗牌种子的统计摘要。

**真正观测：留出对局中离线策略改变弃牌0次，平均官方净积分差0。** 这说明管线和模型验收闭环已跑通，但这批小样本训练**没有产生可观察的策略更新**，并未证实AI增强；不能把0分差解释为两种策略未来实力相等。模型仍是离线试验候选，不会自动晋升正式挑战级。

后续需要扩大独立洗牌样本、提高等向听候选出现覆盖，并升级为从**同一个决策点**出发在若干合法未知牌世界下测试**不同动作**的真实完赛官方净积分差，以获得比整局回报更直接的动作训练信号。尤其应扩充同实力AI之间的完整四人自对战，而不仅是不同难度之间的训练竞争。
