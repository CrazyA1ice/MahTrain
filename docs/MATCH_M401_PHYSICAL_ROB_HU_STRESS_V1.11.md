# M4.01：108张牌完整构造的抢杠胡正负例与独立自然保留组

## 研究动机

M4.00 在64局自然样本里仅发现2个真正不同的合法补杠候选，全部不存在抢杠胡的合法对手；不能从2个负例校准抢杠概率。M4.01分别检验：

1. **确定性的正确性**：在真实108张物理麻将牌的约束下构造明确的抢杠胡正例和反例，正式进入 `declare_kong` → `rob_options` → `respond_rob_kong`，检查抢杠有无、多响、取消补杠、杠钱与合法动作。
2. **独立的自然可用性**：另外使用从未用于M3.95–M4.00的**连续新洗牌种子**26000–26007和27000–27007，逐局对战四座位，复用上一轮严格隔离的 `public_bugang_features` / `_sealed_potential_robbers` 方法，汇总首次候选与合法抢杠标记是否有足够正例。绝不重抽种子直到获得正例。

两者完全分开。第一项中人工设计的“正例占比” **不是随机自然事件发生概率**，不做训练数据集或置信区间；第二项如果仍缺正例，直接报告无法校准。

## 八种物理规则压力场景

每个场景从一套真实麻将牌开始，**全局108张、27类各4张**；预留自己的公开碰牌三张和暗手第4张，再为对手分配已知的合法听口组合，剩余牌分配给其他玩家及真正的墙牌。每一回合后都调用官方 `debug_tile_counts` 和零和分账，确保没有凭空造出第5张牌。

| 名称 | 验收目标 |
|---|---|
| `one_robber` | 1名对手合法抢杠胡，真实响应后补杠被取消 |
| `two_robbers` | 2名对手同一补杠多响，只有1次失败补杠宣告，但产生2个赢家 |
| `decline_legal_hu` | 存在真正合法的抢杠胡资格，但对手主动过牌；补杠最终成功，证明“潜在资格”和“实际抢杠”不同 |
| `all_dingque_excluded` | 所有活跃对手均定缺补杠牌花色；公开信息可**确定性排除**合法抢杠，但不能推断总体杠牌最优 |
| `focused_positive` | 对手两副已公开同色碰牌，确实能抢杠胡 |
| `focused_false_alarm` | 同样有两副同色公开碰牌，但自身真实手牌不能合法胡；公开同色副露不是已听或必能抢杠的证明 |
| `mixed_meld_positive` | 对手两副不同花色公开碰牌，依然可以合法抢杠胡，公开风险类别并不完整 |
| `critical_wall_positive` | 在剩余末段墙牌条件下仍有合法抢杠；此场景通过把墙牌物理移动至**合成公开牌河**构造，只检验物理守恒及状态机，绝非从真实自然对局产生的记录 |

每次用公开视图构建粗风险类别，先用可信离线 `_sealed_potential_robbers` 检验自身以外对手的合法Hu资格，再执行真实 `declare_kong` 并逐一查询**权威** `rob_options`；**预决策标签必须与进入响应窗口后的合法Hu对手人数完全一致**。之后根据预注册操作（胡/过）逐座位响应，检查一炮多响、宣告/成功/被抢计数、原碰牌是否升级、物理牌守恒及每本账零和。

## 新独立自然实验

- 开发组26000–26007，保留组27000–27007，两组各8个独立洗牌种子，每种子四座位独立轮换（总共**64局真实自然对局**）。
- 固定种子段不与旧研究共用；无候选的局纳入分母，绝不能事后只挑出现过补杠的种子。
- 每个真实候选仅以首次出现计算受信任标签。同牌后续回合重复候选仅加重复计数。
- 继续严格区分公开风向、规则上真正能合法抢杠的**潜在**对手数、选择不杠/实际发起杠、抢杠成功人数。
- 实际净积分继续由官方胡牌＋杠钱＋流局三类结算核对；不能把“补杠多发生于尾牌”作为部署后的策略优化证据。
- 即使构造场景有若干正例而自然保留组没有，本轮的 **线上挑战级 AI 仍保持原样**；不向实时模型加入任何隐藏标签或过拟合构造场景的风险百分比。
