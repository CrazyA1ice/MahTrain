# MahTrain M3.21：可交互的整局公开牌桌复盘（v0.33）

## 这一轮实现的功能

1. **跨回合公开状态归档**。现有后端在每次真实规则调用完成时返回 `match.public_steps`，但只保留在本次响应中。浏览器在每次成功操作后把这些步骤的**脱敏公开状态**添加到本局历史：`wall_count`、四家 `hand_counts`、公开 `melds`、牌河 `discards`、已胡 `won` 及当前公开阶段和轮到谁。就算前端动画速度选为“关闭播放”，仍然归档；新开一局立即清空前局。归档最多保存512步，超过时优先丢弃最早步骤。
2. **按座位筛选胡牌流水**。终局复盘新增“查看玩家”筛选；选择某座位会展示其担任赢家**或付款者**的实际入账胡牌记录，保留原始/有效番数、付款者、赢家实收与附加番。没有相关入账时显示明确空状态，不伪造账单。
3. **按座位和动作类型定位**。时间线可切换全部公开动作、关键动作、胡牌、杠牌、碰牌或出牌。若勾选具体玩家，列表仅保留该玩家公开行动或该玩家实际参与的胡牌步骤。最多显示最后200条匹配的步骤；较早但未超出512步归档上限的内容仍在页面内，但暂不提供直接逐条跳转入口。
4. **点击查看历史牌桌**。单击时间线动作或“上一步/下一步”，在终局报告内**独立只读窗口**重绘该真实规则调用结束后的牌山剩余张数、四家暗手背牌张数、各家公开副露、每家的公开牌河和已胡标记。对手暗杠始终只用背牌表示，**包括本人历史暗手也不重建牌面**，没有历史真实墙牌顺序，不提供任何从快照操作或出牌的入口。不会更改正在使用的真实牌桌或向服务器发起请求。
5. **旧服务器兼容**。如果旧响应没有 `public_steps`，只能保存这次 HTTP 响应的**最终真实公开局面**，不能伪造逐动作历史。步骤没有可展示的事件时，也可保存其已经完成的真实公开局面，但使用中性标签而不暴露未公开的换牌信息。

## 边界与隐私

- `web/match_playback.js` 统一通过 `normalizeBoard` / `normalizeSteps` 的严格白名单转为前端可保存的对象，丢弃其他玩家暗牌、暗杠牌种、未来牌墙、私有换牌内容。终局和回放显示均只使用这些安全对象。
- 这是一份**单浏览器当前页面会话**的临时历史，刷新网页、更换浏览器、重新开局均不保留。不会上传到新的后端数据库，也不对整个时间序列提供永久 URL。
- 每条历史快照对应**一次真实规则函数完成后的公开状态**；一次函数内的杠与补摸、多人同炮胡都共用真实的后置公开状态，没有虚构其中更细的牌局。
- 复盘中的胡牌积分只使用已入账 `win_ledger`；独立杠钱仍是可选实验积分，流局查花猪与查大叫未正式入账，不能视作全部完成结算。

## 测试与验收

- `tests/test_match_playback.js`：验证中性事件的真实快照也能保存、按玩家和动作过滤、隐藏牌不泄漏、非法筛选值与不完整公开数据拒绝处理。
- `tests/test_match_board_dom.js`：真实网页脚本在关闭动画时，跨**两次不同成功响应**保存真实步骤；终局可筛选胡牌入账、切换关键动作、查以前牌山与牌河；浏览历史不更改真正牌桌或发起网络请求；新开一局会清除上局历史与筛选。
- `tests/test_web_app.py`：静态页面唯一 ID、浏览器接口及样式入口检查；既有全部麻将规则、25场四人AI、多种环境测试继续保留。

手工验收：`git pull origin main`、`python web_server.py`，访问 `http://127.0.0.1:8765`，正常完成一局人机对战。可以提前选择“关闭播放”；终局复盘中改变玩家与动作类型，点击行动查看历史牌山与四家牌河，核对历史预览和当前正式桌面互不影响。刷新页面或重新开局后，前局临时快照会清空。
