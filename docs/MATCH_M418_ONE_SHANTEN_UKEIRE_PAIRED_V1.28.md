# M4.18：一向听有效进张与上听机会的离线真实积分配对实验（v1.28）

## 研究方向

M4.17 的 [PR #117](https://github.com/CrazyA1ice/MahTrain/pull/117) 已完成全部回归与 64 场全新自然配对并合入主分支，但开发、保留两组均为零真实改切和零正式分差。根源是临近流局（墙剩≤32）、切牌后已听牌、合法等向听多选、最高有效番数提升及多重收益保护同时出现的机会太少。继续在同一批历史种子上调阈值会造成选择偏差。

这轮转向相对高频的**严格一向听**：如果一个合法切牌在原最强AI排序中位于第一，但另一张不退向听的合法牌有更多公开未知的有效进张实体张数，而潜在番数与公开风险都没有明显恶化，离线候选可以研究改切是否更有利于上听及整局结算。**这是可验证假设，而不是“有更多上牌就一定会更早听牌”的结论。**

## 固定的候选条件

候选仅利用 `MahjongAgent("challenge").discard(view)` 先前已经计算的一份 `_last_discard_scores` 排名；这份列表按照真实当前合法手牌和强制定缺偏好，已经过滤到**最低严格向听**的切牌。研究代理不再调用额外牌效枚举，不读取未来牌墙和任何对手暗手，并保持已经核实的天听牌局不变。

- 只有原排名的严格最小向听 **=1**，且排名至少有两个不同的真实合法切牌，才进入候选比较；**不退向听**。
- 备选至少比原切牌多 **2 张**有效进张实体牌数，且达到原有效张数的 **110%**。这些是从自身手牌和公开副露/弃牌推断的**尚未公开实体张数**，不代表这些张一定还在墙里，也不构成未来上听概率。
- 备选必须保留至少 **90%** 原切牌的 `expected_fan_weighted_copies`（原挑战级已经计算的轻量牌型潜力代理，非确定胡牌积分）。
- 备选公开危险指数 `table_threat_index` 不得超过原切牌 **0.12**；该指数是可累加启发值，**不是点炮概率**。
- 仅当公开墙剩至少 **9 张**时允许离线候选改切，墙将尽时保留原有决策。候选按有效实体张数最高、番数加权代理最大、公开风险较低、确定性牌序排序。
- 无候选、原选择已经听牌或尚有两向听、合法天听或任何异常信息时保留原出牌或拒绝非法输入。对 `exchange`、定缺、碰杠胡、胡牌计分、流局查大叫、其他玩家 AI 和所有正式网页操作均不改变。

**不能将「有效进张实体牌数」直接解释为上听概率或高番胡牌概率**；未知手牌和未来牌墙是不可见的，后续决策与其它玩家出牌也会影响上听与终局。

## 全新、预先固定的配对实验

开发组 **56000–56003**、独立保留组 **57000–57003**；和 M4.14～M4.17 使用的初始洗牌种子完全分开。每组四个独立初始洗牌、每种子挑战级轮换四个座位、每个座位由原挑战级与冻结候选分别完整打一场 108 张牌四川血战比赛，即两组共 **8个独立洗牌、32个座位配对、64场完整正式对局**。

基准与候选要分别报告：基准总切牌次数、严格一向听切牌次数、严格一向听且存在多个最小向听备选的次数、真正改切次数和覆盖的**独立种子**、公开不同决策产生的完整胡牌/杠钱/流局与净积分差额。每场官方结算严格满足 `official_net = win_points + kong_points + exhaustive_points`；若未发生改切，对应两臂必须完全相同的官方积分、公开事件、动作轨迹与终局状态。

四座位使用同一初始洗牌，**不能按四个独立实验样本统计**。一个座位对局可能发生不止一次改切，因此总改切次数同样不能当独立样本。配对后若有后续胡杠、流局或牌墙消耗分叉，只可解释为**整条路径的正式得分差**，不是单次行动局部因果效应。

若开发与独立保留方向不一致、真实干预数很少或净分没有明确改善，本轮只保留研究工具，不能上线候选或微调阈值美化实验结果。即使两组均正收益，仍需更多未见过的独立洗牌、更严谨的风险校准和性能验收，才能考虑修改正式最强AI。

## 冻结两组的实际自然配对结果

最新 PR 的第一次完整专项与真实自然配对 CI 已完成：两组各4个新初始洗牌、四座位旋转、每座位两条完整官方真实对局，共 **8个独立洗牌、64场完整比赛**。13项新增测试和11项M4.17回归均通过。冻结所有门槛后，没有一场实际切出不同麻将牌：**零干预，不存在收益提升证据**。

| 指标 | 开发组56000–56003 | 保留组57000–57003 |
| --- | ---: | ---: |
| 完整官方比赛 | 32 | 32 |
| 挑战级原出牌次数 | 182 | 169 |
| 严格一向听最小切牌次数 | 40 | 42 |
| 其中具有多个合法同向听候选 | 40 | 42 |
| 有备选但未找到满足全部进张收益与风险约束的决策 | 40 | 41 |
| 实际改切 | **0** | **0** |
| 有改切的独立种子 | **0** | **0** |
| 胡牌积分/杠钱/流局结算差 | 0 / 0 / 0 | 0 / 0 / 0 |
| **官方总净分差** | **0** | **0** |

该实验的两组拥有大量真实可比较的一向听候选，但按已有挑战级的评分和预先冻结的安全收益保护，均未发现会改变选择的有效备选。保留组一向听40余次与未满足收益保护41次不矛盾：后者是控制流程的互斥原因分组；另外还有一些切牌在墙剩低于9张时被跳过。对所有实际零改切的配对，两个完整比赛的官方账目与动作路径完全一致，CI已核验。

**研究结论：** 只有相同动作下的零差分，不能声称新候选提高了上听速度、查大叫分数或对局胜率。下一轮优先做一向听候选之间的**公开牌效—防守 Pareto 前沿覆盖诊断**，研究原挑战级是否已处于有效张数、番值代理与风险的合理非支配选择，而不是在本批种子上重新调0.90/1.10/0.12阈值。不部署任何修改到最强AI。
