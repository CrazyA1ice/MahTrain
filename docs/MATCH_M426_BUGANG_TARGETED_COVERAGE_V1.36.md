# M4.26：合法延迟补杠局面的定向构造与挑战级 AI 决策覆盖审计（v1.36）

## 为什么不再盲目增加自然比赛局数

M4.25 PR #125 已合并到 `main`，16个独立洗牌种子、128场真实比赛均完成，延迟补杠两个策略之间的**实际行动分歧为0次**，因此这批样本无法回答“延迟补杠是不是过于保守”。本轮改为专门生成符合实体牌守恒和时序的新规则**定向决策检查点**。此类构造数据只用于增加决策边界覆盖，**不能当作随机真实牌局分布、胜率或期望净分样本**。

## 构造办法及真实性边界

固定24个检查点：`m/s`两门、数字`1/2/3/5/7/9`、两种手牌形态（随机混合／靠近已碰牌的聚集型），每个牌种4个实体副本，牌组总量108。为便于系统性判断，将玩家0预先置于已经公开碰出目标三张的合法抽牌检查点（隐藏10张、已碰3张，正常前摸第四张）；其他三家各隐藏13张，墙里仍有56张。构造检查点不假装已经从自然洗牌完成完整换三张、碰牌来源和历史选择，因此不得声称其在随机对局中的发生概率。

- 本家及其他三家初始都没有已经定缺的筒牌，随后均使用引擎真实 `draw`、`discard`、`respond_discard` 经过一个完整轮次。玩家0保留刚摸到的第四张，下一巡真正摸到**另一张**后，得到引擎给出的合法延迟补杠选项。
- **不能用修改视图的方式假造延迟补杠资格**，不能从牌墙中虚构额外复制牌，不直接操作下一巡的最近摸牌标志。公开状态不能泄露暗手或真实摸牌身份。
- 在同一组合的两个真实局面各自用权威引擎 `declare_kong`→三家依次 `respond_rob_kong('pass')`→尾摸：**当巡补杠应收入+60（底数20、三家付款），延迟补杠应收入0**；已碰副露均升级为补杠、牌墙尾部少一张、108实体守恒、杠账零和。
- 无论当巡还是延迟，**根番依 `score_win()` 的四张同牌根+1处理**，不是另设“动作补杠+1番”。
- 面对每一个延迟合法检查点，分别用挑战级当前保守门槛和仅去掉该门槛的离线策略**对同一玩家授权 `private_view`**进行比较，并记录是否不同（不复制或改变权威游戏引擎的真实计价模式）。
- 当前巡有钱补杠的行动也独立统计，作为区别条件的解释资料。**注意当巡与下一巡除了杠钱资格外，最近摸牌和其他家公开弃牌也会改变，因此当巡与延迟的动作差不是只由杠钱引起的因果效应**。报告字段 `paid_vs_delayed_action_changed` 只表示两种场景下动作是否变化。整套方法不窥视或把别家暗牌／未来牌墙传给AI决策函数。

## 结果的有效范围

输出只包含公开可见的已碰目标牌种、形态标签、动作类别（放弃/补杠/暗杠）、两个策略是否分歧、杠钱账本的可验证结果，以及示例编号。固定种子让**构造样本**可以复现，不代表自然分布独立观测，不能因为24种构造状态中某策略选杠更多就声称胜率提高。

按四个固定分片 `set_a..set_d` 分别评估6个检查点。审计器不接受遗漏、交换编号、随意增加局面、弄错杠钱或伪造行动标签。最后自动生成覆盖汇总：付费补杠选择数、无钱延迟补杠选择数、是否存在守门策略分歧。**零分歧也是有效结果**，下一步如需构造更接近自然牌谱的复杂局面，需要事先另立协议，不能从本组24个样本后验筛选优势。
