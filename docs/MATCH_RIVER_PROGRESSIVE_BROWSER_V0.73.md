# M3.62：四家固定牌河的动态出牌稳定性验收

M3.60 固定14×4牌河格位，M3.61 在真实Chromium中检查多窗口宽度满格位布局。M3.62新增对从开局空牌河逐张放牌的真实浏览器验收。

在320、390、701、1024px窗口，以0张弃牌的四家牌河、整体牌桌及本家手牌矩形为基准，逐次模拟每家0、1、13、14、15、28、56张弃牌，校验所有矩形位置和宽高不因弃牌数量改变。第6张弃牌模拟被碰或杠取走，格位不前移、不重复出现实体牌；已用位置坐标唯一，牌河始终无纵向滚动。

14→15对应从首行换到第二行，额外验证这个边界条件。模拟四家分别填满56格是视觉容量压力测试，并非声称真实108张麻将牌能同时产生224张弃牌。

基于项目真实页面CSS与Chromium，分别在0、14、56张场景生成截图，保存于 test-artifacts/match-layout/，由原有 real-browser-match-layout CI 上传工件。已有7个屏宽满格位校验继续保留。

此轮只增加动态视觉回归，不修改对局规则、AI算法、正常玩法或牌桌固定尺寸。自动化几何测试不等于所有设备上的人工视觉验收。
