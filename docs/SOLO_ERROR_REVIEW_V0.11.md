# MahTrain M2.9：14轮错因总结与专项练习（网页 v0.11）

> 这一版本在现有 **14轮连续摸切训练**基础上增加错因报告，延续 v0.10 的单题强化训练功能。四川血战规则 v0.4 仍为未启用的草案；单人模式**不等于四人血战完整对战引擎**。

## 1. 训练报告的新内容

当用户完成任意一轮摸切或确认胡牌后，底部“逐轮切牌复盘与牌效总结”会针对**已经提交的回合**同步提供：

- 逐轮“该轮错因”字段，包括错过合法胡牌、退向听、同向听少进张；个别历史结果无法归入前述类型的会标为“其他非最优动作”。
- “整局错因分析与针对性训练”汇总四类错因的回合次数与具体回合编号，指出出现最多的错因，并提供下一步训练建议。
- 在每种支持的错因下点击“练习这一弱项”，会跳转至上方**单题训练中心**并切换到对应模式，开启该错因的专项练习。14轮连续训练和单题专项训练的牌墙与评分相互独立。
- 下载“逐轮 CSV”时新增**错因分类列**。
- 完成整局后的最终报告保留全部真实回合的分类；如果提前自摸胡牌，则只统计真正完成的轮次，不虚构后续摸切。

### 判定优先级

1. **先判断是否正确**。局部最优选择（包括并列最优和正常确认胡牌）不标记错因。
2. 已被系统提示可合法胡牌，却选择过牌、继续切牌：**错过合法胡牌**。这是最重要的优先级，不再将该回合同时记为“退向听”或“损失有效进张”。
3. 非胡牌的普通决策：切后向听数高于该轮最小向听数：**退向听**。
4. 切后向听达到本轮最优层级，但有效进张少于同层最佳：**同向听少进张**。
5. 仍无法归类的已评分非最优选择：**其他非最优动作**。

与四种单题训练有区别：连续14轮系统**不会开放非法胡牌按钮**，也没有13张清一色听口多选操作，因此14轮错因报告**不会凭空出现**“未成胡误判胡牌、漏选听口、误选听口”。

**统计单位是非最优的已完成回合，每回合最多一种主错因**。原有向听和有效进张变化图中，相邻两轮还存在摸牌及可见牌变化，跨轮指标变化不能直接当成用户本轮切错牌的证据；错因判定依据**同一轮自己当时的所有候选动作比较**。

## 2. 针对性练习映射

| 整局错因 | 关联单题模式 | 新题验证 |
| --- | --- | --- |
| 错过合法胡牌 | 清一色何切 / 胡牌判断 | 系统混合可胡与不可胡的牌型，提交前不泄露本题真实答案 |
| 退向听 | 一向听何切 | 新题确实存在退向听切牌，但不告诉用户是哪张 |
| 同向听少进张 | 听牌何切 | 新题确实存在同向听却减少进张的切牌，但不告诉用户是哪张 |
| 其他非最优动作 | 暂无针对性出题映射 | 只能先使用原回合错题重练，不虚构一个专项类型 |

链接到单题模式**不是复现原14轮完整公开牌、已经开的杠和牌墙**。如需在相同局面重新练一遍，可使用原有“错题重练”；关联单题是根据错误类型提供新的、经算法核验的结构题。

## 3. SQLite 兼容与实时反馈安全

- 新完成的14轮训练，其原始 `report()` 自动携带 `error_summary`，逐轮 `round_review[]` 包含 `error_types`、`error_labels`；无需新增 SQLite 列或修改原训练总分。
- 以前 v0.5～v0.10 版本已经入库的14轮报告，当用户打开**历史记录详情**时，由原本已冻结的 `history` 数据重新生成错因说明。只改变当前查询结果的展示，**不覆盖 SQLite 旧成绩**。
- 仍只向网页公开已经提交并评分的回合，不返回未摸的牌墙、未来摸牌顺序或当前未提交回合的最优动作。训练进行中退出服务，尚未完成的整局仍不持久化。
- SQLite 中原有单题成绩、单题错因频次及难度推荐不变；**连续14轮的错因计数不会混入单题推荐难度的正确率计算**。

## 4. 如何体验

```bash
git pull origin main
python web_server.py
```

本地打开 `http://127.0.0.1:8765` 并按 `Ctrl+F5` 强制刷新。发牌预览后自行定缺，进入14轮练习，每轮提交切牌后到页面下方查看新增错因分析；整局结束后报告仍然保留，历史训练区域也能查看旧报告及原因。点击“练习这一弱项”可以跳转到顶部的专项单题。

运行回归测试：

```bash
python -m unittest discover -s tests -v
```

重点文件：

- `src/mahtrain_core/review.py`：历史已评分回合的错因归类、整局统计及建议映射。
- `src/mahtrain_core/session.py`：每轮实时返回 `error_summary`。
- `src/mahtrain_core/history.py`：旧历史详情在**内存读取时**补充错因，保留原始 SQLite 的冻结正确率。
- `web/review.js`：整局错因卡、逐轮标签、CSV 错因列、跳转单题专项。
- `web/history.js`：旧历史回合的错因展示与训练入口。
- `tests/test_solo_error_review.py`：错过胡牌优先级、退向听/进张损失、历史回填不改库与未提交轮次安全。
- `tests/test_web_app.py`：HTTP 页面报告的整合检查。

## 5. 后续边界

这轮没有开发四家真实换三张、碰牌/明杠/补杠和番数完整结算；也没有把14轮错误归因直接用作单题自动难度升降的样本。若继续推进，可以优先完善局面重练的教学提示、统计跨多局14轮常见错因，或进入正式四人规则状态机。
