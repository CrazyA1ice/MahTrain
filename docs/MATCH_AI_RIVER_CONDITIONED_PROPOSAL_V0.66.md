# M3.55 公开行为约束的隐藏手牌提案分布（v0.66）

## 问题与设计边界

M3.54 的24次世界抽样主要按定缺门降低未知牌权重，随机生成的13张对手暗手很少能够听牌，在此前五独立洗牌种子、25局对照中没有改变挑战 AI 的胡牌次数或净积分，且增加了运行时间。本轮改进的**不是**“读取真正的对手手牌”或“估计准确的后验听牌概率”，而是**让有限世界的采样包含有信息量的、物理可行的听牌假设**。

## 公开信息如何影响抽样

只使用已经给本座位授权的 `private_view(seat)` 中的本家手牌、`hand_counts`、`missing_suits`、`melds`、`discards`、`won` 与 `wall_count`。

1. **定缺的软约束**：后期对仍持定缺牌种的权重进一步降低，但不把“对手一定清空定缺牌”当作硬事实。
2. **弃牌（牌河）证据**：同种牌以前被对手打过仅略微降低持牌倾向，不能当作四川麻将中绝对安全的振听；公开连续弃某花色可减弱继续持有该花色的权重，较长牌河中完全没打过的花色可适度提高保留权重。
3. **公开副露证据**：若同一名活跃对手已有两副及以上已公开同色副露，倾向在对应花色构建合理的剩余暗手；不使用对手的私人手牌、牌墙顺序或随机种子。
4. **局部结构**：普通世界构建时，已经选择的对子、邻张和隔张带来温和的牌形连贯性权重，而不是对所有剩余实体牌等概率独立抓取。
5. **专门的听牌假设**：针对至少两副公开副露的对手，每4个世界（公开副露3副及以上时每3个）尝试构造一个“剩余隐藏暗手由若干完整刻/顺和一张单牌组成”的假设。这构成依法允许的单骑听牌结构，全部实体牌从同一未知池不放回拿取，最后可由规则引擎检查；无法成立就自动回到普通样本。此假设**故意过采样听牌结构**，命中比例绝不代表客观听牌概率或准确放铳概率。

## 消融与性能限制

- 只有至少一位尚未胡牌的对手已经公开两副及以上副露时，挑战 AI 才会打开新采样器；平时继续执行 M3.53 的公开场况估分，不额外等待。
- 默认24个合成世界，至多64个，最多比较当前最小向听候选中的三张切牌。对手合成手牌在同一个世界内共享一副未知实体牌库存。
- 任何公开暗杠的牌种因隐私遮挡不可辨识时，无法确定实体库存，直接关闭模拟并依旧使用既有公开风险模型。
- 直接点炮情景使用四川麻将本项目 `is_legal_win` 与 `score_win`，多个对手若在同一情景里均能胡同一弃牌，按一炮多响累计模拟倍率。
- 额外防守分数惩罚仍不超过12%。无样本胡牌不表示弃牌绝对安全。
- 额外输出 `ready_hypotheses` 作为研究日志，可核查采样有否真正引入听牌结构；不展示生成的任何合成暗手。

## 严格科学局限

使用弃牌和副露影响“提案分布”是启发式规则，不等于历史数据校准的条件分布。按固定间隔混入构造听牌的特殊样本还会使 `hits/worlds` **带有偏差，不能作为概率**。本轮没有训练机器学习模型、没有离线测量真实对手的隐藏听牌状态，也没有完成包括未来摸牌、碰杠与正式杠钱/查大叫在内的多步 ISMCTS。

**验收判据**：Python3.11/3.13、规则及前端回归全通过；在同种子和同位置的多组比赛中比对净积分、真实放铳/百次切牌、切牌向听后悔率以及决策时间。若在小样本没有胜率或净积分改进，只保留经验证的不泄露合成世界框架，不以“更聪明”作定论。
