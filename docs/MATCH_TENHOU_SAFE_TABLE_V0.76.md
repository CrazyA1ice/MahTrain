# M3.65：天凤风格固定牌桌与中央无碰撞交互区

## 用户验收目标

参照所附天凤麻将视觉参考，MahTrain 的四人血战桌使用深蓝绒面桌布、浅色窄面牌、深色牌背、环绕中央记分牌的四面示意牌墙。借鉴版式与色彩，保留项目自身的麻将图案/规则/牌型，不直接复制天凤受保护的美术资产。

1. 浏览器 **100% 缩放**、桌面标准窗口（701/1024/1440px）时，四人固定牌河（每家 56 格）、副露、缺门徽标、自己 14 张手牌均纳入同一完整牌桌，四家河牌不允许出现横向/纵向内部滚动。
2. 四家河牌继续遵循 M3.60 的 14×4 及 90/180/270 度座位旋转，已被碰/杠取走的弃牌保留位置但不复制实体牌。
3. 换三张、定缺、碰/杠/胡/过、自摸确认和出牌二次确认都在 **中央专属操作区** 内，不以覆盖层占据自己的手牌、任一家的牌河或副露。无操作时中央恢复牌墙剩余数量显示；公开动作播报动画也限于此区域。
4. 听牌候选提示位于牌桌下方的独立信息带；积分详情移出牌桌下沿，避免已结算时把牌桌本身拉高/遮住手牌。
5. 四家定缺长期附在对应座位身份区，不飘在牌河或实体牌上。左右两家牌背仍保持自己方向的连续一排、公开碰杠牌遵循安全展示（暗杠不可泄漏未公开牌面）。

## 修改文件

- `web/index.html`：将原 `#match-controls`、`#match-decision`、`#match-motion` 收纳到 `#match-wall .match-center-prompt` 中；将 `#match-ready-hint` 和 `#match-table-settlement` 移至棋盘外。保留原有 DOM ID 与事件绑定。
- `web/app.css`：在最末端覆盖历史层叠样式：深蓝牌桌与牌背、四边中央牌墙示意、固定且更紧凑的河牌格距；四家身份/牌背/副露分区；中央按钮垂直压缩并限制在安全区域；手机版保留本家手牌单独横向滑动。
- `tests/test_match_layout_browser.js`：使用真实 Chromium、真实网站 CSS，新增标准缩放视口中完整牌桌的可见性、四人定缺及四组副露可见性、中央换牌操作与实体河牌/手牌/副露不相交的验收。叠加的“四家均有4组副露+各家56格河牌”是纯几何压力场景，不是合法同步游戏状态，不读取真实对手暗牌。
- 对局规则、AI 策略、牌山剩余张数、公开时间线以及服务器状态不作修改。

## 已知边界

本轮的“牌山”是 **CSS 示意图案**，并非真实实时牌墙逐张位置；屏幕狭窄的移动端仍保留本家手牌独立横向滑动，不能让一张可点击手牌缩得过小。整个网页上下正常滚动用于切换控制/复盘模块，但 **牌桌内部不允许河牌滚动**。桌面牌桌须能完整放入相应高度的浏览器视口，并可通过正常页面滚动将它移到视口内。
