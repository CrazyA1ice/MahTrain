# M4.17：临近流局保留合法听口的最大有效番数切牌配对实验（v1.27）

## 问题来源

M4.16 [PR #116](https://github.com/CrazyA1ice/MahTrain/pull/116) 在所有CI通过后已经合并。其权威终局复盘确认，M4.14开发组总净分相对下降700，其中胡牌积分+300、杠钱0、花猪0、**查大叫−1000**；关键配对52001轮换2，原挑战级在流局时听2张、最大有效2番，从3个未听玩家处各收400分，共收入1200，而已有的风险改切候选未听牌、该收入归零。这是**分叉后的整局结算差异，不是首次改切的确定因果损益**。

本轮按照事前冻结假设开展新的独立实验，而不是继续调整旧M4.14候选参数：当本家已处于听牌切牌决策且牌墙临近耗尽，允许在保证最小严格向听数和部分有效进张的前提下，有限地提高**本人候选13张手牌按正式规则可计算出的最高有效番数**。这个指标与流局“查大叫”的本家最高有效番数定义一致，仍只是“如果确实按该手牌流局”的**可能支付等级**，并非未来流局事件、胜率、确定能听到的张数或局部行动价值。

## 冻结候选算法

仅对仓库现有 `MahjongAgent("challenge").discard(view)` 提供的本人授权 `_last_discard_scores` 进行离线研究。不重新计算完整手牌的最小向听搜索，不读取牌墙顺序或任何对手暗手。仅用本家可见手牌、公开定缺／副露、当前公开牌墙**剩余张数**及房间已核实有效番数上限推算当下手牌可能的终局听口。

预先冻结下列 **全部** 行动条件：

- 当前公开 `wall_count <= 32` 张，且**不是**已核实的天听玩家；在普通切牌后达到的最小严格向听数**必须是0（已听牌）**，有至少两种相同最小严格向听的合法切牌。
- 用终局规则同一个 `winning_tiles` 和 `score_win`，以本家当前合法13张牌及已公开的自身副露、定缺，得到各备选的**可能最高有效番数**。备选必须比原选提升**至少1番**。不能因不能确认的天听、天胡、地胡、杠后事件等凭空增加番数。
- 备选的公开可见剩余有效张数 `effective_tile_count` 不低于原选**60%**；理论合法听口类型数量至少保留**50%**；原评分中番数加权的剩余进张 `expected_fan_weighted_copies` 至少保留**65%**。
- 备选即时切牌的公开累加危险指数不允许比原选增加超过**0.15**；这不是放铳概率。若多个备选都符合，先比较最大有效番数，再比较合法听口类型数量，再比较已有的番数加权有效进张与有效张数，最后按公开危险指数和牌序稳定破局。
- 只改离线候选研究臂的`discard`。同一初始洗牌的基准臂完全执行原挑战级出牌，所有碰、杠、胡、换三张、定缺与血战流程保持一致。现有挑战级AI及正式Web页面和规则引擎**没有任何改动**。

这里的“听口类型数”是本人**可能结构性合法胡牌**种类，未知牌墙是否仍有可摸到的实体牌；“最大有效番数”对应实际规则下的听牌奖励定价，未来能否一直保持听牌、其它活跃玩家是否仍未听都未知。不会据此说“改切后必得2^fan积分”。

## 全新独立配对组与官方账本

这轮全新预先固定的开发组 **54000–54003**、独立保留组 **55000–55003**，不与之前M4.14/15/16使用的52000或53000种子重合。每个种子都让原挑战级轮换四个座位，再和完全相同开局的离线候选分别真实打一场四川血战到底完整比赛：**8个独立初始洗牌、32个坐席配对、64场完整108牌官方对局**。

必须记录并区分：基准挑战级总切牌次数、进入后32张临界窗口的切牌次数、切牌后是听牌的次数、候选策略真实改切次数、发生真实改切的**不同初始洗牌种子**、以及四座位簇的正式净分变化。每场由规则权威账本结算，逐位置验证 `official_net=win_points+kong_points+exhaustive_points`。零真实改切时，两条比赛路径的全部官方金额、公开事件及动作轨迹必须一致。

**两个独立样本组是本轮的探索性验证，不是大样本胜率证明。** 如候选根本不触发、只在极少数种子触发、收益方向不一致、或者某组出现净分下降，则维持“不具备上线证据”的结论。不调门槛挑漂亮数据，不自动将候选接入正式挑战级。

## 新文件及复现命令

- `src/mahtrain_core/ai_latewall_da_jiao_fan_paired.py`：临界牌墙公开视图、按规则计算的本人假设听口有效番数、冻结多条件合法同向听改切、两臂真实配对官方比分聚合。
- `tests/test_m417_latewall_da_jiao_fan_paired.py`：门槛冻结、不退向听、不修改核实天听、番值与有效进张限制、公开风险上界、无隐藏牌信息、非法候选拒绝、108实体牌和真实完整配对。
- `examples/audit_latewall_da_jiao_fan_paired.py`：分别运行两组、生成匿名真实配对结果JSON。
- `.github/workflows/m417-latewall-da-jiao-fan.yml`：M4.17新增测试与M4.16流局规则回归，各组四个独立洗牌每个四座位双臂；全项目Python 3.11/3.13及规则CI仍需全部通过后才可合并研究代码。

```bash
python -m unittest discover -s tests -p 'test_m417_latewall_da_jiao_fan_paired.py' -v
python examples/audit_latewall_da_jiao_fan_paired.py --cohort development --seeds 4 --output results/m417-development.json
python examples/audit_latewall_da_jiao_fan_paired.py --cohort holdout --seeds 4 --output results/m417-holdout.json
```

**研究边界：** 观察到的全局分数差会包括后续不同的摸牌、胡牌、杠钱与流局收费，不能推断成某一个改切动作的因果期望分数。四个座位轮换受同一初始洗牌相关，不是4个独立样本。绝不直接读取对手未公开的牌、当前未知的未来牌墙、真实点炮概率，也不更改正式最强AI。
