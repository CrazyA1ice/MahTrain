# M3.98：独立自然牌局中的碰杠机会覆盖与扩大反事实保留组

## 为什么需要 M3.98

M3.97 已证明可以安全地针对**首次真实操作机会**分叉只一次，之后打到权威正式终局，并隔离实时 AI 与未来墙牌。但是旧样本仅4个独立洗牌种子（每组2个），而且在保留组里根本没有遇到可选择的自身暗杠或补杠。不能把“没遇到操作机会”误称为“无收益差别”。

M3.98 不追逐挑出来的高杠频牌局，而是**连续编号、预先固定、没有按结局或是否杠筛选的自然种子组**，两套实验互相独立执行；将“覆盖率”与“改变一个操作之后的整局收益”严格分开。

## A · 自然碰杠机会覆盖（8+8独立种子）

开发组16000—16007、保留组17000—17007，每组8个独立初始洗牌种子，每种子四座位轮换，**64局真实、不可挑选的原挑战级终局牌局**。

- **每个操作窗口**用当事挑战级座位的授权 `private_view(seat)` 统计，而非根据它最终是否执行了杠倒推机会。
- 对手打牌：当合法可选 `peng` 或 `ming_gang` 且尚未合法胡牌时，统计可碰窗口、可明杠窗口、实际碰、实际明杠、实际过，以及这些窗口的墙牌阶段。
- 本家轮到自己：当可以 `an_gang` 或 `bu_gang` 且**没有已经确认可自摸胡**时，统计可暗杠／可补杠候选总数、至少有一个对应合法候选的窗口数、同时多个合法杠牌的窗口数、实际选择杠或不杠及墙牌阶段。
- 必须同时报告有操作机会的**座位位置数**与**所有操作窗口数**；不能按候选数量当作独立对局样本。例如一次有两组暗杠的窗口，候选数是2，窗口数仍是1。
- 每种子四席组成一个簇；每个真实结束的局面均严格进行完整108张牌守恒与正式胡牌、杠钱、流局结算账本三项独立零和校验。
- 导出仅包含公开类别、按席位统计的整数和官方净额；没有保留任何暗手、私有牌墙、可逆牌哈希。

**如8+8种子的保留组仍没有真正的自身杠机会，报告零覆盖。绝不重抽种子，绝不为获得想要的正负收益挑种子。**

## B · 扩大单次决策反事实（4+4独立种子）

开发组18000—18003、独立保留组19000—19003，各四座位轮换、分成“首次碰/明杠”和“首次暗杠/补杠”两类，**64个预先指定目标位置**。仍采用 M3.97 已通过的三种固定策略：原挑战级、强制过、强制执行第一个合法的积极操作。

- 所有分叉必须是同一洗牌、同一座位、同一事前合法视图；一旦强制动作与原动作相同，直接复用同一结果，不虚增干预数量。
- 其他座位决策和后续所有动作都由原策略执行；合法胡牌（包括抢杠胡与一炮多响）绝不强制过牌。
- 真实实验只比较最终**正式结算净积分**，并拆分胡牌、杠钱、流局分账及事件差；绝不是从牌效代理值计算的“期望”。
- 额外按**干预前就能看到的公开类别**（墙牌早/晚/尾、原策略过牌或行动）汇总各类实际机会数、真正改变的操作数、已实现的净积分差合计。该分层只是机制观察，样本很小时严禁当作策略训练集或泛化结论。
- 只按独立洗牌种子先平均4座位收益，再求种子均值。每组仅4个独立种子，`confidence_interval_95pct=null`，不以大量“窗口×选择×座位”伪装出统计精度。

## 为什么 A 与 B 不共用同一批种子

覆盖率调查估算真实自然机会的出现频次，反事实试验研究预先固定首次操作、以及改变这一动作能如何影响真实终局。使用**四段完全独立**的种子区间，避免一边检查稀有场景一边将适宜种子挪去计算收益的选择偏差。

在 Python 中运行：

```bash
python -m unittest discover -s tests -p 'test_m398_unselected_action_coverage.py' -v

# 自然机会统计：16独立种子×4座位=64局
python examples/compare_challenge_extended_action_coverage.py --mode coverage --output results/m398_coverage.json

# 更多独立种子中的首次决策成对反事实
python examples/compare_challenge_extended_action_coverage.py --mode paired --output results/m398_paired.json
```

工作流 `.github/workflows/m398-natural-action-coverage.yml` 分开运行两个并行任务，并将每个任务的**无暗牌 JSON 原始聚合与分席位审计结果**保存为 CI artifact，以便查证，不需要靠终端截图复刻数据。

## 严格的解释界限

即使研究中观察到部分干预可以提高某次已知洗牌世界的终局收益，也**绝不能把未来墙牌或别人的暗手作为实时 AI 输入**。原挑战级行为继续不变。只有在足够新的、未筛选的种子中获得相同方向的正式净积分收益，且不会扩大抢杠胡或花猪风险，才考虑进一步研究部署。

## 实际验收结果 · 2026年10月22日

**重要注意：** 保留组可补杠的11个窗口中，**9个来自单一种子17004**。因此11不等于11份独立验证证据，且同一座位可能在不同回合反复获得相同补杠候选。原挑战级只在其中2次选择补杠，其余9次过牌并不意味着存在9个失误：必须在**干预前已知的局面**下比较多步收益，不能按终局结果倒推在线决策。

开发组自身杠机会6个窗口全部是暗杠，保留组12个窗口中仅1个暗杠而11个补杠；说明小种子的**操作类型组成变化很大**，需要更多独立种子才能稳定估计机会率。

### C. 终局账本的真实差额（四席合计）

| 策略及组别 | 累计正式净积分差 | 胡牌分账差 | 杠钱分账差 | 流局分账差 |
|---|---:|---:|---:|---:|
| 开发：碰/明杠强制过 | +1100 | +100 | 0 | +1000 |
| 保留：碰/明杠强制过 | -603 | -1300 | -3 | +700 |
| 开发：碰/明杠强制积极 | +402 | 0 | +2 | +400 |
| 保留：碰/明杠强制积极 | -599 | -600 | +1 | 0 |
| 开发：自身杠强制过 | 0 | 0 | 0 | 0 |
| 保留：自身杠强制过 | -203 | -200 | -3 | 0 |
| 开发：自身杠强制积极 | +2 | 0 | +2 | 0 |
| 保留：自身杠强制积极 | -194 | -800 | +6 | +600 |

可以看到碰/明杠强制过的**开发组收益+1100绝大多数来自流局分账+1000**；保留组则**胡牌分账下降-1300**，虽有流局分账回补+700，最终净额仍然为负。这说明局面行为会改变对手结算路径，**不能仅拿即时碰牌收益衡量长期胜负**。

自身杠强制积极在保留组的公开事前阶段分层中，`critical:pass` 一次改动带来-197分，而 `early:pass` 一次改动带来+3分；但是只有**两次实际干预**，完全不能依据阶段制定新在线规则。这些属于研究现象，不是稳定统计规律。

### 研究结论与部署决定

- 通过全量真实四川规则、108张牌守恒、胡牌/杠钱/流局权威零和、操作前同一授权局面校验、合法抢杠胡保护、未筛选独立种子与未修改线上模型的回归检查。
- **两种改变首次碰/明杠的策略，在开发组均值均为正、在保留组均值均为负，方向不一致，暂不修改正式 AI。**
- 自身杠的真实干预总数很少，保留组强制不杠和强制积极杠都在本批种子中观察到净损失，但不能外推到“所有杠牌都应该保留原选择”。保留现有挑战级策略。
- 本轮每个收益组仅**4个独立洗牌种子**，没有计算伪95%置信区间；所有按公开阶段/原动作的分层都是描述性研究，不可利用观察到的正收益做事后择优规则。
- 后续 M3.99 建议重点研究**补杠、抢杠胡、尾牌风险**，采用新的、至少8个独立种子每组的预注册保留对照，并先核实“同一张补杠牌在不同回合重复被提供”的时间相关性，避免反复窗口造成虚假的样本量。
